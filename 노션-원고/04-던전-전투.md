# 🗺️ 04. 던전·전투

<callout icon="💡" color="gray_bg">
던전은 사람이 떠난 옛 작업장입니다. 재료를 모으고, **기억의 잔향**에서 새 룬을 탁본하고, 물이 차기 전(12분)에 돌아옵니다. 생물은 죽이지 않습니다. **놀라게 해서 재료를 "떨구게"** 합니다. 적을 쓰러뜨리는 게임이 아니라 사고를 수습하는 게임입니다.
</callout>

## 지역

지역 3곳 + 첫 던전의 잠긴 심층부. ✅ 모든 지역은 같은 물줄기, 같은 물때 규칙입니다.

| 지역 | 처음 가는 날 | 이야기와 모습 | 구역 | 이 지역만의 장난감 |
|---|---|---|---|---|
| **물레종이소** | 1일 | 종이·먹·풀을 다루던 제지소. 관 소리와 생물만 남음 | 원료 마당(1일) · 세척실(3일) · 건조실(4일) | 수문, 높은 길·낮은 길, 접힌 발판 |
| **잉크 광산** | 9일 (3막 주 무대 13~16일) | 먹의 원료 **먹돌**을 캐던 곳. 먹 가루가 바람에 날리고, 광차가 경사 때문에 저절로 조금씩 굴러가는 소리 | M1 반입장 · M2 선별 갱도 · M3 침전·기록실 | **광차**(당기고 튕기고 붙여서 짐 운반), **물문 3개**(달팽이가 붙어 있으면 닫힘, 떼면 지름길), 수동 바람막이, 먹 가루 흐름 |
| **봉랍 양봉장** | 17일 | 종이 벌집을 짓던 **종이벌**이 떠난 빈 양봉장. 빈 벌집 상자가 바람에 윙윙 울림 | Y1 둑·채집 정원 · Y2 가열 작업장 · Y3 바람 건조대·기록 홈 | **바람 길**(가벼운 것이 날아감), **밀랍 바닥**(끈적임), **가마**(뜨거운 열원), 잘 굴러가는 빈 벌집 상자 |
| **물레종이소 심층부** | 21일 | 건조실 바닥 **점검구** 아래의 옛 합동 작업장. 여백 공방과 똑같은 4공정 작업대가 먼지를 뒤집어쓰고 있음 | S1 배수 수로 · S2 합동 인쇄실 · S3 합동 도안실 | 20일 저녁 보린이 만든 손잡이로 점검구를 엶. 첫 방문에 **배수문**을 열면 다음부터 입구에서 바로 들어감 |

- 모든 지역의 가장 먼 곳에서 입구까지 기본 귀환은 **75초 이내**가 목표입니다. 🧪
- 매번 조금씩 바뀌는 상태 변주 13개: 물레종이소 5 · 광산 3(바람 반대, 물문 닫힌 날 등) · 양봉장 3(센바람, 가마 센불 등) · 심층부 2(김 낀 날 등).
- 공간을 넓혀 왕복 시간으로 10시간을 채우지 않습니다.

## 물때 — 던전 시계

| 입장 후 | 상태 | 소리 |
|---|---|---|
| 0~6분 | 물이 낮음 | 관 속 물 흐르는 낮은 소리 |
| 6분 | 물이 올라 길이 바뀜 | 제지소 **증기 기적** 한 번 "뿌-" |
| 9분 | 철수 경고 | 증기 기적 세 번 + 관 쇳소리 |
| **12분** | **종료. 모두 입구로 떠밀려 나오고, 물에 약한 것만 잃음** | 큰 물살 "쏴아" → 입구에서 "푸하" |

- 모든 지역이 같은 시계이고, 후반에도 빨라지지 않습니다. ✅
- 기본 귀환길은 항상 마법 없이 갈 수 있습니다.

## 가방 🧪

| 칸 | 한도 |
|---|---|
| 재료 가방 | 8칸, 칸마다 같은 재료 10개 |
| 스크롤 | 따로 6장. **등짐의 두루마리 통 6개**가 곧 한도라 동료가 내 남은 장수를 눈으로 봄 |
| 손판 (휴대 도안판) | 허리에 2개 = 완성 문장 2개 |

**현장 급조:** 손판의 문장으로 한 장을 즉석에서 만듭니다. 6초, 느리게 이동, 소리가 남. **봉인이 안 돼서 물때에 망가집니다.**

## 버팀과 구조

체력 숫자 대신 **위험 게이지**가 3단계로 보입니다: 여유 → 휘청임(화면 가장자리 붉은 종이 테두리, 모자가 비뚤어짐) → 쓰러짐(머리 위로 **종이학 세 마리**가 빙빙).

| 항목 | 시작값 🧪 |
|---|---|
| 충격 | 약 +15 / 중 +30 / 강 +45 (게이지 100이면 쓰러짐) |
| 열에 닿는 동안 | 초당 +8. 젖어 있으면 김이 나는 동안 0 |
| 떨어짐 | 2~4m 약, 4m 넘으면 중 |
| 회복 | 5초 동안 새 위험이 없으면 초당 10씩 내려감 |
| 무해 상태 | 젖음·빛·먹물·끈적임·가루는 게이지를 올리지 않음 (행동만 바꿈) |
| **친구 때문** | 게이지를 **최대 99**까지만. 친구 탓에 휘청일 순 있어도 쓰러지진 않음 ✅ |
| 한 번에 쓰러뜨리는 공격 | 없음. 보통 중 2번 + 약 1번 뒤 한 번 더 |

| 상황 | 규칙 ✅ |
|---|---|
| 맨손 구조 | 3초. 구조 직후 게이지 60에서 시작, 3초 보호 |
| 쓰러짐 | 45초 안에 구조받지 못하면 응급 복귀 |
| 응급 복귀 | 몸만 입구로, 짐은 현장에. 동료가 회수 가능. 그날 재입장 불가 |
| 혼자일 때 | 원정마다 1번, 8초 걸려 스스로 일어남 |
| 모두 귀환 | 남은 짐의 결과를 바로 정산 |
| 실패 | 빚·전투 승리·무사고를 요구하지 않음. 못 끝낸 것은 다음 날 |

## 생물 6종 — 떨굼

생물은 악당의 부하가 아니라 자기 방식대로 사는 동물입니다. **떨굼 조건**은 전부 이미 있는 속성·반응 조합이라, 플레이어는 문장으로 그 상태를 만듭니다. 떨군 개체는 그날 다시 안 나오고, 다음 날 돌아옵니다.

| 생물 | 사는 곳 | 하는 일·공격 | **떨굼** → 재료 | 웃긴 사고 |
|---|---|---|---|---|
| **먹물도롱뇽** | 세척실, 광산 침전실 | 빛을 싫어함. 목이 부풀면(1초) 앞 60°로 먹 분출 → 얼굴에 먹막 8초 | 몸이 어딘가에 **3초 붙어 있으면 꼬리를 떼고** 도망 → 먹주머니 | 넓게로 붙이면 옆 동료도 같이 바닥에 붙음 |
| **부풀달팽이** | 건조실 | 젖은 종이를 먹음. 먼저 공격 안 함. 놀라면 2.4m로 부풀어 통로를 막고 주변을 밀침 | 쪼그라들 때 남긴 **점액 웅덩이**를 운반통으로 뜸 → 탄성점액 | 부푼 달팽이에 튕겨라+너 → 거대한 공이 통로를 튀어 다님 |
| **화덕딱정벌레** | 건조실 화덕, 양봉장 가열 작업장 | 턱이 주황으로 밝아지면(1.5초) 4m 돌진 + 물기. 주변 바닥 달구기 | **젖어서 식은 뒤 다시 열**을 받으면 턱 껍데기가 "톡" → 발열턱 | 바닥에 붙은 동료에게 돌진하면 열 때문에 접착이 풀려 구조됨 |
| **물문달팽이** | 광산 선별 갱도 | 물문에 붙어 쉼(=물문 닫힘). 건드리면 껍질째 굴러 벽에 한 번 튕겨 되돌아옴 | 어지러운 동안 **껍질 고리**를 주움 → 둥근탄성껍질 | 양쪽 벽에 튕겨라 → 핀볼 |
| **풀옷도롱뇽** | 양봉장 | 등에 수지를 바르고 벌집 조각·빈 병을 붙여 위장. 붙은 소품을 던짐 | **열을 받으면** 풀옷이 녹아 벗겨짐 → 눌림수지 + 붙어 있던 소품(가끔 분실물) | 붙어라에 걸린 동료가 도롱뇽 등에 붙어 같이 돌아다님 |
| **책먼지나방** | 양봉장 건조대, 심층부 | 가장 밝은 것 주위를 맴돔. 가루를 털어 시야 방해 (위험 0) | 걸러라 막에 가루가 쌓이면 걷어서 → 숨털뭉치 | 빛나라+나+넓게를 쓴 파티를 나방 무리가 졸졸 따라옴 |

**감지** 🧪: 시야 앞 90° 8m(어두우면 4m, 빛나는 대상은 어두워도 8m). 청각은 세계 소음만(걷기 3m, 뛰기 6m, 급조 8m, 세게 12m). **목소리·핑·UI 소리는 듣지 않습니다.** ✅

공격은 모두 **예고 → 확정 → 실행 → 빈틈**. 한 구역에서 동시에 확정된 큰 공격은 1개까지. 귀환길 위에 20초 넘게 버티지 않습니다.

제작: 뼈대 3종(도롱뇽형·달팽이형·곤충형)으로 6종을 만듭니다.

## 기억의 잔향 — 새 룬 탁본

| 단계 | 하는 일 |
|---|---|
| 관찰 | **잔향인**(반투명 먹빛 사람)이 같은 실수를 30초마다 되풀이하는 걸 봄 |
| 해독 | 벽의 옛 도안판 세 칸 중 한 칸만 모르는 룬. 결과를 보고 뜻을 짐작 |
| 수습 | 공급 손잡이를 멈추고, 손·기본 도구·아는 룬으로 반복을 끊음. 배우려는 룬은 요구하지 않음 |
| 탁본 | 도안판이 빛나면 탁본지를 대고 3초 문지름. **이 순간 룬은 안전하게 기록됨** |
| 활자 | 공방의 빈 활자에 탁본지를 대면 새 활자가 됨 |

- 잔향인은 모두 다른 사람입니다(모자·도구·필체가 다름). 몇몇 방에선 두 잔향인이 서로의 실수를 고쳐 줍니다.
- 잔향 14개를 방 11개에 담습니다. 물레종이소는 방 3개를 두 번씩 다시 꾸며 씁니다.
- 위치는 고정. 못 끝내면 다음 날 같은 자리에서.
- 목록은 **05. 콘텐츠 도감**, 방별 반복 장면·수습 순서는 하위 페이지 **"공간·잔향 상세"**.

상세 설계는 하위 페이지 **"생물·전투 상세"**, **"공간·잔향 상세"**에 있습니다.
