## 플레이어 — 두루마리 행상단

| 항목 | 내용 |
| --- | --- |
| 정체 | 1\~4명의 **떠돌이 두루마리 행상.** 도시 도매상의 인쇄 스크롤을 떼어다 라벨만 보고 팔았고, 문장은 읽지 않았다 |
| 물레목에 남은 이유 | 김 서린 골목에서 수레가 배수로에 빠져 도매 스크롤이 전부 젖어 번졌다. 팔 것도 돈도 없는데, 비어 있는 공방이 하나 있다 |
| 목표 | 빚이나 세계 구원이 아니라 **"이번엔 읽고 판다"**는 자존심 회복. 25일 이후 실제 작업을 마친 뒤 옛 제작자들의 여백에 이름을 잇는 제작자가 된다 |
| 성장 | 되파는 사람 → 읽는 사람 → 만드는 사람 → 다음 사람을 위해 여백을 남기는 사람 |
| 모습 | 둥근 머리의 약 3.5등신. 조선 **보부상** 오마주: 패랭이 모자에 목화송이, 먹 묻은 앞치마, 등에 두루마리 통 6개 |
| 꾸미기 | 모자 8종·송이 8색·옷 색 8종(룬 7색과 겹치지 않는 차분한 색)·등짐 장식 12종·얼굴 소품 6종. **능력치 없음** |
| 행상단 이름·공방 인장 | 플레이어가 짓고 만듦. 인장은 봉인한 모든 상품·납품 상자·신문·간판에 찍힘 |

제목 *Scroll Peddler*(두루마리 행상)가 곧 플레이어입니다.

### 프롤로그 (약 2분, 건너뛰기 가능)
본편 첫날 30분과 **별도인 선택 2분**입니다. 처음부터 함께 보면 도입과 첫날 약 32분, 건너뛰면 첫날 약 30분입니다. 아래 막 날짜는 최초 가능일이고 관련 납품·단서가 실제 완료된 뒤 장면이 이어집니다.
1. 밤, 김 서린 골목. 행상 수레가 배수로에 빠져 있고 스크롤이 젖어 번졌다. 멀쩡한 상자 하나: **"도매 손전등 — 밝음 보장"**
2. 어두워서 한 명이 그걸 찢는다(첫 입력). 실제 문장은 **빛나라 `+` 나 `+` 넓게.** 행상단 전원이 연두빛으로 번쩍인다.
3. 지나가던 에다: "…가는 길에 말인데. 그거 손전등 아니고, 너희가 전등이야."
4. 빛나는 몸 덕에 골목이 환하다. 보린이 빈 공방 열쇠를 건넨다. "비어 있는 공방보다 쓰는 공방이 낫지."
5. 먼지 쌓인 여백 공방. 활자 서랍 18칸 중 **6칸에만 나무 활자**가 남아 있다. 뚜껑 안쪽 옛 글씨: "빈칸은 채우라고 있는 것."
→ "문장을 읽지 않으면 사고가 난다"를 30초 안에 웃기게 보여 줍니다. 트레일러 첫 장면 후보.

### 여백 메모 — 튜토리얼의 목소리
설명 창 대신 옛 제작자들이 설비마다 붙여 둔 **손글씨 쪽지**가 조작법을 알려 줍니다. 쪽지 끝에 가끔 다른 필체로 덧붙인 말이 있습니다.
> 판틀 메모: "칸 모양이 안 맞으면 억지로 넣지 말 것. 동그란 건 동그란 데."
> 다른 필체: "넣어 봤음. 안 들어감."
첫날부터 "여러 세대가 이어 쓴 기록"을 조용히 보여 주는 복선입니다. 간판 밑 옛 글귀: **"여백은 다음 사람 몫."**

## 옛 제작자 미스터리

| 질문 | 답 |
| --- | --- |
| 도안판의 표식은 뭔가? | '접힌 모서리' 모양의 **공동 확인 표식.** 만든 사람 칸이 아니라 함께 확인한 사람 칸에 찍힌다 |
| 옛 제작자는 한 사람인가? | 아니다. 여러 세대의 제작자·수리공·운반 작업자가 쓴 기록이다 |
| 기록은 왜 흩어졌나? | 작업장이 용도별로 나뉘면서 각자 필요한 장만 보관했다. 누가 일부러 망친 게 아니다 |
| 무엇을 복원하나? | **함께 쓰는 작업 도안.** 조명·고정·여과·회수를 각각 하는 문장들과, 대상·조건·실패·후속 손작업을 적은 기록. 새 마법이 아니다 |
| 우리 공방은 무엇을 보태나? | 옛 정답을 그대로 파는 게 아니라, 지금 주문에 맞춘 설명을 여백에 이어 적는다 |

**꼭 알아야 할 3가지:** 공동 표식의 뜻 → 두 수정본의 관계 → 마지막 장의 의도. 단서는 12조각(C01\~C12)으로 나눠 잔향·도안함·인물 대사·신문으로 전합니다. 놓친 단서는 다른 경로로도 다시 들을 수 있습니다.

## 손님의 사용이 다음 부탁으로 이어지는 세 연쇄
\[사실\] M01·M04·A16의 기존 사용 장면을 잇습니다. 상세 대사는 [대본 ② 인물·장면·신문](../claude-lead/W08b-대본-인물-장면-신문.md)에 둡니다.

| 의뢰 | 실제 사용과 의미 | 다음 부탁의 한 가지 변화 |
| --- | --- | --- |
| M01 에다 | 납품품 한 장으로 짐을 밝히고 양손으로 수레를 잡음 | 완료 뒤3\~5일, 오래 활자를 배운 뒤에만 물건 빛180초로 변경. 잠깐60초는 부족·오래360초는 적합 |
| M04 보린 | 접착이 나사를 조일 시간을 벌며 영구 고정은 손 수리로 남음 | 얇은 받침의 고정12초. 오래24초 판은 재사용 가능 |
| A16 카엘 | 시전자 자리에서 건너편 도구를 밝혀 점검 | 시작 거리만3m 이내로 변경,90초 조건은 유지. 멀리120초는 재사용 가능·잠깐60초는 부족 |

10\~25초는 검증 전 시작값입니다. 고객 재고의 실제 납품 문장 한 장을 한 번 소비하고 공방 재고를 다시 빼지 않습니다. 장면이 끝나도 효과는 원래 지속 시간을 지킵니다. 전원 카메라를 고정하지 않고, 못 본 사람에게 개인 목격을 주지 않습니다. 첫 M01 사용은 당일이고 서면 후기는 다음 아침입니다.

\[추천\] 새 대사는 기존 완료 대사를 대체합니다. 재주문은 같은 용도로3\~5일 뒤,하루1건·3건 중1건의 조건 하나만 변경하며 이미 아는 룬으로 풉니다. 이전 판도 조건을 만족하면 수정 없이 통과합니다.

**김과 가루:** P09는 열로 말리고 기존 송풍기로 김을 걷습니다. M16·A14는 가루 여과와 고정을 더해 기본3장입니다. 여과로 김을 없애지 않습니다.

## 엔딩
**조건:** ① 골목 문제 해결 ② 미스터리 3가지 이해 ③ 복원본을 지금 문법으로 만들어 확인 ④ **A20 옛 도안의 현장 검증**(세인)에서 복원본 첫 사용 확인

**조건이 아닌 것:** 빚 갚기, 전투 승리, 무사고, 호감도 만점, 친구 인원, 모든 문장 조합

| 장면 | 장소 | 내용 |
| --- | --- | --- |
| 1. 현재의 작업 | 심층부 합동 도안실 | 손없는 등불·이동 여과틀·임시 봉합 세 장. 임시 봉합이 틀을 붙드는 24초 동안 **행상단이** 보린 스승의 드라이버(분실물 8, 없으면 공방 드라이버)로 나사를 조인다. 1막의 보린과 같은 동작 |
| 2. 마지막 장 | 심층부 | 여러 필체의 확인란 11줄, 맨 아래 한 줄이 비어 있다. "다음 사람은 현장에서 다시 확인할 것." 탁본 |
| 3. 기록의 완성 | 공방(저녁) | 이솔: "옛날에도 끝난 도안은 아니었네요. 다음 작업까지 적을 자리가 있었어요." |
| 4. 빈칸 | 공방 | 이솔이 펜을 내민다. "여기, 빈칸이요. 오늘 확인한 일부터 적으면 되겠어요." 행상단 이름·인장과 실제로 확인한 작업 조건 한 줄이 마지막 확인란에 찍힌다 |
| 5. 첫 사용 | 길드 출장소 | 세인: "복원본, 사용 확인. 이후 수정 사항은 같은 항목에 이어 적겠습니다. …수고하셨습니다. 이건 적지 않겠습니다." |
| 6. 일상의 결말 | 골목(밤) | 에다가 5일에 이어 다시 멈춰 서서: "오늘은 종이가 말라 있네. 내일 쓸 것도 부탁할게." 축제 때 기부한 등불이 켜져 있으면 더 밝다 |
| 7. 다음 날 | 공방(아침) | 도안함 마지막 줄: "이후의 사용 기록은 여백 공방에서 계속한다." 간판 옆 여백에 행상단 이름. 영업은 계속된다 |

크레딧은 6과 7 사이. 배경은 이번 캠페인의 **신문 1면 사진들**이라 파티마다 다른 크레딧이 됩니다. 엔딩은 하나입니다.

마지막 조건 한 줄은 실제 A20의 접착 중 나사 조임, E14의 가루 길목 배치, E10의 당김 뒤 손으로 놓기 중 확인한 사실을 씁니다. 하지 않은 구조·사고는 만들지 않습니다. 에다의 첫 여유 있는 인사는 **5일 수리 뒤**이며 프롤로그의 잠깐 정지와 구분합니다.

엔딩 뒤에는 기존 미완료 재주문 / 활용법·분실물 / 인증·반복 발주 / 꾸미기·사진·축제 기록을 게시판에 모읍니다. 오늘 목표를 선택해 다음 준비로 이어갑니다. 약 10시간은 모든 콘텐츠 경험 목표이고 필수 엔딩 시간은 따로 측정합니다.

| **에다** | 야간 배달부 | 빨리 움직이지만 남의 손이 얼마나 바쁜지 먼저 본다 | "가는 길에 말인데." | 늘 걸으면서 말해서 대화 중에도 수레가 조금씩 멀어진다. "밝은 것"과 "눈부신 것"을 칼같이 구분 |
| **보린** | 수리공 | 새것 자랑보다 고친 자국을 반긴다 | "버티는 동안 고치면 돼." | 멀쩡한 것도 "고칠 데 없나" 두드려 본다. 수리 자국을 훈장처럼 자랑 |
| **리네** | 재료 상인 | 장점보다 불편한 점부터 말한다 | "단점부터 말할게." | 라벨에 단점이 더 크게 적혀 있다 ("단점: 젖음. 장점: 아직 안 젖음") |
| **도토** | 던전 관측원 | 추측을 즐기지만 틀리면 기꺼이 지운다 | "본 것까지만 적자." | 수첩이 줄 그은 가설로 새까맣다. 틀리면 신나서 줄을 긋는다 |
| **소미** | 빵집 주인 | 손맛을 믿지만 작업 조건은 꼼꼼히 나눈다 | "빵은 빵대로, 장부는 장부대로." | 모든 걸 나눠서 말한다. 주문에 늘 빵을 끼워 보낸다 |
| **카엘** | 모험가 (길잡이) | 처음엔 물건 이름만 보다가 점점 쓸 위치를 설명한다 | "제가 쓸 자리는요." | 초보 시절 등불을 얼굴에 붙인 전력이 있다. 동료를 자꾸 빛나게 만든다 |

| **세인** | 길드 접수원 | 서류를 좋아하는 이유: 다음 사람이 같은 설명을 반복하지 않게 | "확인한 항목부터 적겠습니다." | 사고를 무표정으로 분류한다 ("천장에 붙은 동료 1명, 회수 작업으로 분류") |
| **이솔** | 길드 기록원 | 빈칸을 성급히 채우지 않고 남은 증거를 차분히 읽는다 | "여기까지는 기록에 있어요." | 밖에서도 속삭인다. 빈칸을 절대 추측으로 채우지 않는다 |

## 후기와 신문
\[추천\] 안전한 주에도 실제 납품·무료 시험·고객 사용·마을 변화로 지면을 채웁니다. 직접 관찰 / 납품 규격 판정 / 사용 미확인을 구분하고, 근거가 없으면 중립 공지를 씁니다. 화제는 정상 작업의 문장·반응·수습을 기록하며 고의로 동료를 방해한 횟수를 보상하지 않습니다. 틀과 필수 근거는 [대본 ③ 남은 글](../claude-lead/W08c-대본-남은글.md)에 둡니다.

| 체계 | 규칙 |
| --- | --- |
| 손님 후기 | 12개 문장 틀(R01\~R12). 기록에 있는 결과만 채웁니다. 지어내지 않습니다 |
| 주간 신문 | 12개 문장 틀(N01\~N12). 5일마다, 기사 2개 `+` 다음 주 수요 1개 |
| 말투 | 기본은 **건조하고 중립적.** "독해 부족" 같은 농담은 손님이 자기 실수를 털어놓을 때만 |
| 실제 파티 사건 | 실제로 쓴 문장·이전 상태·반응·수습 기록으로 씁니다 |
| 화면 밖 손님 | 납품 문장·주문 조건으로 판정했다고 구분. 관찰하지 않은 전투·구체적 시간·반동 거리를 기록하지 않습니다 |
| 기록 없음 | "미확인·미사용"으로 표시. 난수로 평판을 깎지 않습니다 |
| 평판 | 마을: 첫 거래 → 단골 → 지정 공방. 길드: 등록 → 신용 → 지정 ([07. 경제·밸런스](07-경제-밸런스.md)) |
