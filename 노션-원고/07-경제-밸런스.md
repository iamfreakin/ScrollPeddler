## 계약 납품과 자유 판매
**주문을 만들었다고 하루 판매 한도로 잘라 버리지 않습니다.** 계약은 수락한 문장별 장수, 자유 판매는 별도의 정상 수요로 셉니다.

| 항목 | \[추천\] 규칙 |
| --- | --- |
| 인원 배수 | 1·2·3·4인 = 1·1.5·2·2.5 |
| 계약 장수 | **문장 줄마다** 기본 장수×인원 배수를 올림한 뒤 합산 |
| 자유 판매 정상 수요 | 하루 파티 **2·3·4·5장**. 계약 납품과 별개 |
| 수락 시 확정 | 인원·문장별 장수·조건·총보상. 접속·이월로 다시 계산하지 않음 |
| 분할 납품 | 적합품을 상자에 보관해 다음 날 이어 납품. 전량·부재료 완료 때 대금·보너스·평판 한 번 |
| 자유 판매 초과품 | 자동 판매하지 않고 남김. 원하면 임시 매입가에 처분 |
| 부재료 | 해당 7건에 파티 1개씩. 값은 총보상에 포함 |

\[추정\] A06의 기본 **3`+`1`+`1장**은 1·2·3·4인에서 **5·9·10·14장**입니다. 2인은 5`+`2`+`2장입니다. 합계에 한 번만 배수를 곱해 8장으로 바꾸지 않습니다.

## 돈 (G)

| 항목 | \[추천\] 값 |
| --- | --- |
| 시작 공용 자금 | 1인 120G · 2인 180G · 3인 240G · 4인 300G |
| 한 장 원가 C | 종이 2G `+` 기본 먹 1G `+` 동사 먹 m회분. 잠깐 m=1, 다른 수식 m=2, 주변 대상 `+`1 |
| 동사 먹 1회분 구매가 | 빛 3G · 접착 4G · 당김 5G · 여과 6G · 탄성 24G · 가열 28G · 차광 32G |
| 자유 판매가 F | 1.25×C`+`8G, 5G 단위로 올림 |
| 계약 총보상 | 문장별 납품량×제시 F의 합 `+` B. B 10·20·30·40G는 **주문당 한 번** |
| 수요 초과품 임시 매입 | C×0.6, 정수 내림. 처분은 선택 |
| 상인 완제품 | F`+`10G. 자체 제작 의뢰의 제작 실적·보너스로 치지 않음 |
| 설비 | 서랍 240G · 시험 기록대 680G · 수신기 1,580G |

\[추정\] 빛나라`+`물건`+`잠깐의 C는 2`+`1`+`3=6G, F는 1.25×6`+`8=15.5G를 올림해 **20G**입니다. 채집 재료도 표준 C는 같지만 현금에서 빼는 것은 실제 구매비뿐입니다.

**이중 차감 금지:** 동료를 구하느라 한 장을 쓰면 제품과 그 먹을 한 번 소비합니다. 예상 판매가를 현금에서 또 빼지 않습니다. 인쇄 시 표준 C와 실제 구매비를 둘 다 현금에서 차감하지 않습니다. 고객 사용 장면은 이미 납품한 고객 재고에서 소비하고 공방 재고를 다시 빼지 않습니다.

## 재료 수급과 상인

| 항목 | \[추천\] 기준 |
| --- | --- |
| 목표 | 연속 3일의 (새 안전 반출`+`실제 구매)÷(고유`+`재주문`+`화제·반복`+`자유`+`탐험 사용`+`실제 파손) = **1.0\~1.15** |
| 단위 | 종이·기본 먹은 각각 기록하고 동사 먹은 전체/동사별 회분으로 기록. 일반 동사 원료 1개=4회분, 몬스터 먹 원료 1개=2회분 |
| 몬스터 상인 | **하루 합계 2회분 `+` 5일 주간 합계 5회분**, 1\~4인 파티 공용 |
| 합산 | 몬스터 원료·먹·완제품이 두 한도를 공유. 원료 1개=2회분, 제품은 m 차감 |
| 일반 상인 | 종이·기본 먹 40/60/80/100장·회분, 일반 원료는 품목별 먹 8/12/16/20회분 상당 |
| 갱신 | 일일은 공용 마감 때 한 번, 주간은 신문과 같은 5일 구간 시작 때 한 번 |
| 방지 | 재접속·인원 교대·조기 귀환·되팔기로 한도 초기화 없음 |
| 부재료 | 먹 환산 없이 개수·납품·판매를 따로 기록 |

자연 자원을 최초 확보하면 전체 소유 유입을 한 번 기록합니다. 공방에 돌아온 새 채집량은 별도의 안전 반출 지표입니다. 확보와 반출을 더해 공급으로 세지 않습니다. 생물의 떨굼 조건을 만족시켜도 시간·종류·안전 반출을 거쳐야 공방 공급입니다. **개체당 하루 1회 떨굼**이며 부풀달팽이 2개체는 점액 2개=먹 4회분입니다. 이전 두 번 채취보다 최대 4회분 줄었습니다. 책먼지나방은 3\~5마리 **무리당 숨털뭉치 1개**이고 몬스터 먹을 주지 않습니다.

\[추정\] 기존 1인 3\~4주 예시의 몬스터 먹 12\~13회분에 상인 5회분은 최대 **약 38\~42%**입니다. 필요한 품목과 돈이 있다는 계산이며 실제 구매율이 아닙니다. 다른 재주문·자유 판매·협동 문장에는 다시 계산합니다. 공급이 충분하다는 판정은 플레이 검증 전에는 내리지 않습니다.

**소비를 나눠 기록합니다:** 고유·재주문·화제/반복·자유·탐험·파손은 별도 칸입니다. 갈기·인쇄·봉인·예약은 내부 가공이며 그때와 납품·사용 때 먹을 두 번 세지 않습니다. 기존 봉인품의 귀환은 새 공급이 아닙니다. 새 채집품이 파손됐다면 안전 반출량에 넣지 않습니다. 분모 0인 동사는 비율 대신 재고를 봅니다.

전체 보유량 변화=최초 확보·실제 구매−납품·판매·사용·실제 파손입니다. 갈기·인쇄·장소 이동은 내부 전환이며 총량을 늘리지 않습니다. 비축 사용·현장 사용 때 안전 반출률이1보다 작을 수 있으므로 전체 장부와 함께 해석합니다.

| 길드 지정 | 인증 3차`+`고유 길드 12건 | 특집·인장 금테·액자 |

재주문 완료를 고유 의뢰 건수에 중복 더하지 않습니다. 2·3차 인증을 안 봐도 이야기·엔딩은 막히지 않습니다.

선택 지출처 약 **3,960G**(의상·소품 1,500G, 2층 300G, 공방 장식 1,100G, 골목 등불 1,000G, 사진기 60G)를 유지합니다. 매주 신문과 함께 꾸미기 신상품 2\~3개를 보여 주고, **저축도 허용**합니다. 1인이 전부 사거나 4인이 얼마를 남긴다는 판정은 실제 수입 뒤 확인합니다. 세금·빚·필수 유지비는 추가하지 않습니다.

## 난이도와 남은 확인

| \[추천\] 올릴 것 | 유지할 것 |
| --- | --- |
| 주문의 대상·지속·범위·사거리 판단 | 물때 12분, 기존 룬 18개 수치 |
| 상태 조합과 선택 경로·채집 순서 | 같은 반응, 손 도구·기본 귀환길 |
| 변경 재주문과 작업 복구 | 저장 도안 재사용·무료 시험·분할 납품 |

모르는 룬이 필요한 주문은 수락 전 대기, 미완료 납품은 이월합니다. 잔액 30G 미만 또는 일반 제작이 불가능하면 지급 재료 2장 가공 주문(12G, 파티 하루 2건)을 이용할 수 있습니다. 지급분은 다른 용도로 돌리지 않습니다.
