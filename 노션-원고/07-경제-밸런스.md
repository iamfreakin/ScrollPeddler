# 💰 07. 경제·밸런스

<callout icon="🧪" color="gray_bg">
이 페이지의 숫자는 **모두 시작값**입니다. 만들어 보고 조정합니다. 지켜야 할 원칙은 세 가지입니다: ① 몬스터 재료는 던전이 주 공급원 ② 상인은 시간을 아끼는 선택 ③ 같은 손실을 두 번 빼지 않음.
</callout>

## 돈 (G)

| 항목 | 값 |
|---|---|
| 시작 공용 자금 | 1인 120G · 2인 180G · 3인 240G · 4인 300G |
| 한 장 원가 C | 종이 2G + 기본 먹 1G + 동사 먹 m회분. 잠깐은 m=1, 나머지 수식은 m=2, 대상 '주변'은 +1 |
| 동사 먹 1회분 | 빛 3G · 접착 4G · 당김 5G · 여과 6G · 탄성 24G · 가열 28G · 차광 32G |
| 자유 판매가 F | 1.25 × C + 8G, 5G 단위로 올림 |
| 의뢰 보상 | 납품량 × F + 보너스 10·20·30·40G (조건 난도별, 수락 전에 표시) |
| 수요를 넘은 판매 | C × 0.6 (내림) |
| 상인 완제품 | F + 10G. 산 물건은 제작 실적·보너스로 치지 않음 |
| 설비 | 서랍 240G · 시험 기록대 680G · 수신기 1,580G |

**예:** 빛나라+물건+잠깐 = 2 + 1 + 3 = 6G → 판매가 1.25×6+8 = 15.5 → **20G**

**이중 차감 금지:** 동료를 구하느라 상품 한 장을 쓰면, 예상 판매가를 현금에서 또 빼지 않습니다. 구매비·원료·파손을 두 번 세지 않습니다.

## 재료 수급

| 항목 | 기준 |
|---|---|
| 목표 | 3일 동안 (새로 가져온 재료 + 산 재료) ÷ (판매·납품·탐험 사용·파손) = **1.0~1.15** |
| 단위 | 모든 재료·먹·제품을 동사 먹 회분으로 환산. 원료 1개 = 먹 4회분, 몬스터 원료 1개 = 2회분 |
| 인원 배수 | 1·2·3·4인 = 1·1.5·2·2.5배. 중반 채집 목표는 일반/몬스터 원료 2/2 · 3/3 · 4/4 · 5/5개 |
| 몬스터 재료 상인 | 인원과 상관없이 하루 합계 2회분만. 원료·먹·완제품이 한도를 나눠 씀 |
| 일반 상인 | 종이·기본 먹 40·60·80·100개, 일반 원료는 품목마다 먹 8·12·16·20회분 |
| 갱신 | 하루 마감 때 한 번. 재접속·조기 귀환으로 다시 채워지지 않음 |
| 부재료 7종 | 먹으로 환산하지 않고 따로 기록 |

## 난이도

| 올라가는 방식 | 바꾸지 않는 것 |
|---|---|
| 새 룬의 대가 (넓게는 약해지고, 세게는 시끄럽고, 멀리는 흔들림) | 물때 12분 |
| 젖음·가루·접촉·범위가 겹침 | 룬 18개의 수치 (몰래 약화하지 않음) |
| 선택 채집과 귀환 동선 | 같은 반응 규칙, 기본 귀환길 |

진행이 막히지 않게: 모르는 룬이 필요한 주문은 수락 전 상태로 두고, 못 끝낸 납품은 다음 날로 넘기고, 비상 가공 주문을 둡니다.

## 의뢰 보상

의뢰 32건마다 1인 납품 장수·보너스·보상을 정했습니다. 협동이면 장수를 1.5·2·2.5배(올림). 전체 표는 하위 페이지 **"경제 마감 상세"**에 있습니다.

| 항목 | 값 🧪 |
|---|---|
| 고유 의뢰 32건 합계 (1인) | 68장, **약 2,900G** |
| 가장 작은 의뢰 | M01·M02 (2장, 50G) |
| 가장 큰 의뢰 | A19 읽을 빛만 남기기 (가려라 2장, 190G) |
| 하루 평균 | 고유 의뢰만 약 116G. 나머지는 재주문·자유 판매·화제 주문이 채움 |

| 고유 의뢰 밖 수입 | 규칙 |
|---|---|
| 재주문 | 완료한 손님이 3~5일 뒤 같은 용도로. 보너스 10G, 하루 1건 (25일에 약 12건) |
| 자유 판매 | 진열대, 정상 수요 안에서 F |
| 화제 주문 | 주 1건. 보너스 30G + 화제 보너스 20G |
| 반복 발주 | 길드 신용 이후. 게시판의 3일짜리 계약(한 문장 ×4장, 보너스 30G), 동시에 1건 |
| 분실물 | 10~30G 또는 꾸미기 |

## 평판과 길드 등급

능력치 혜택은 없습니다. 꾸미기와 기능 개방만 있습니다.

| 축 | 단계 | 조건 | 혜택 |
|---|---|---|---|
| 마을 | 단골 | 마을 의뢰 4건 (보통 5~6일) | 인물별 작은 선물, 마을 소품 변화, 화제 주문에 마을 사람 등장 |
| 마을 | 지정 공방 | 마을 의뢰 10건 (보통 16~18일) | "물레목 지정" 명판, 소미의 빵, 축제 무대 첫 순서 |
| 길드 | 등록 | 인증 1차 통과 | 게시판 의뢰 수락, 인장 테두리 |
| 길드 | 신용 | 인증 2차 + 길드 의뢰 5건 | 반복 발주 게시판, 길드 챙모자 |
| 길드 | 지정 | 인증 3차 + 길드 의뢰 12건 | 신문 특집, 인장 금테, 출장소 액자 |

2·3차 인증을 안 봐도 이야기와 엔딩은 막히지 않습니다.

## 주별 먹 수요 (1인, 회분) 🧪

| 주 | 의뢰 | 재주문·화제·자유 | 탐험 사용 | 합계 | 공급 목표 (×1.0~1.15) |
|---|---:|---:|---:|---:|---|
| 1주 | 14 | 8 | 15 | 37 | 37~43 |
| 2주 | 25 | 12 | 20 | 57 | 57~66 |
| 3주 | 26 | 14 | 22 | 62 | 62~71 |
| 4주 | 28 | 14 | 24 | 66 | 66~76 |
| 5주 | 19 | 12 | 22 | 53 | 53~61 |

- 일반 먹(빛·붙·당·걸)은 원료 1개 = 4회분이라 넉넉합니다.
- 몬스터 먹(튕·달·가)은 3~4주에 주 12~13회분이 필요하고, 상인 주 10회분 + 떨굼으로 주 20회분 이상이 가능해 감당됩니다.
- 이 표가 **슬라이스 경제 검증의 기준표**입니다. 어긋나면 재주문 빈도와 탐험 사용, 그다음 떨굼 수를 조정합니다. 룬 수치·물때는 건드리지 않습니다.

## 후반에 돈 쓸 곳

25일 끝에 1인 약 1,800G, 4인 약 8,300G가 남는다는 추정이라, 능력치 없는 **선택 지출처** 약 3,960G를 둡니다.

| 지출처 | 합계 |
|---|---:|
| 모자·옷 색·등짐 장식·얼굴 소품 | 약 1,500G |
| 2층 개방 | 300G |
| 공방 장식 20종 | 약 1,100G |
| 골목 등불 기부 (100G × 10) | 1,000G |
| 사진기 | 60G |

1인은 다 사기 전에 엔딩을 보고, 4인은 남습니다. **4인 저축은 허용**합니다. 꾸미기 상점은 리네 가게 옆 선반이고, 매주 신문과 함께 신상품 2~3개가 들어옵니다.
