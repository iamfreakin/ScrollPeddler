# 🤝 09. 협동·저장

<callout icon="💡" color="gray_bg">
공방은 **방을 연 사람(호스트)의 것**입니다. 친구(게스트)는 도안 사본과 발견 기록만 자기 게임으로 가져갑니다. 호스트가 나가면 모두 멈추고, 멈춘 동안에는 시간이 흐르지 않습니다. ✅
</callout>

## 누구 공방인가

| 항목 | 규칙 |
|---|---|
| 호스트 공방이 갖는 것 | 돈·재고·설비·룬 해금·의뢰·이야기 진행 |
| 게스트가 가져가는 것 | 도안 사본·발견 기록만. 모르는 룬은 자기 공방에서 다시 배워야 함 |
| 합치지 않는 것 | 다른 공방의 돈·해금을 자동으로 합치지 않음 |

## 접속과 중단

| 상황 | 규칙 |
|---|---|
| 출발 뒤 새로 들어옴 | 공방 일은 가능. 그날 이미 떠난 원정에는 못 들어감 |
| 원정 중 끊겼다가 재접속 | 새 참가자가 아님. 출입·쓰러짐·자력 회복·짐 기록을 이어받음 |
| 자리 예약 | 90초 🧪. 지나도 물품·진행이 지워지진 않음 |
| 호스트가 나감 | **모두 중단, 기록 보호.** 자동으로 호스트를 넘기지 않음. 중단 동안 물때·쓰러짐·날짜가 흐르지 않음 |

## 돈 쓰는 권한

- 호스트가 "공동 운영 예산"을 정하고, 그 안에서는 누구나 구매합니다.
- 설비 구매나 예산 초과 지출은 건마다 확인합니다.
- 예산을 사람마다 복사해 주지 않습니다.

## 동시 작업

- 인쇄를 시작한 묶음은 시작할 때의 도안 버전과 예약한 재료를 유지합니다.
- 취소하거나 나가면 아직 안 쓴 예약만 풀립니다.
- 남이 도안을 고쳐도 이미 시작한 제품은 바뀌지 않습니다.

## 저장

| 항목 | 규칙 |
|---|---|
| 언제 | 중요한 사건이 확정될 때 + 15초마다 🧪 |
| 무엇을 | 공방과 던전을 **같은 시점**으로. 물때·출입·버팀·쓰러짐·물품 위치·예약·자력 회복·세계 변화, 준비 중인 마법까지 |
| 보관 | 마지막 정상본 + 그 이전 정상본 |
| 소유 | 공방 기록과 개인 프로필을 분리 |
| 수치 패치 | 이미 만든 제품도 최신 수치를 따름. 문장·도안·출처는 그대로 보존 |

저장 기능은 본편 단계에서 만듭니다. 스파이크 1에는 넣지 않습니다.
