## 누구 공방인가

| 항목 | 규칙 |
| --- | --- |
| 호스트 공방이 갖는 것 | 돈·재고·설비·룬 해금·의뢰·이야기 진행 |
| 게스트가 가져가는 것 | 도안 사본·발견·기여 일지. 자기 공방에서 모르는 룬은 다시 배우기 전 제작 불가 |
| 합치지 않는 것 | 다른 공방의 돈·해금을 자동으로 합치지 않음 |

## 돈 쓰는 권한
- 호스트가 "공동 운영 예산"을 정하고, 그 안에서는 누구나 구매합니다.
- 설비 구매나 예산 초과 지출은 건마다 확인합니다.
- 예산을 사람마다 복사해 주지 않습니다.

## 동시 작업·장별 인쇄 완료
계획 몫은 경고이며 실제 인쇄 예약은 중복 소비를 막습니다. 시작한 묶음은 그 도안 버전·예약 재료를 유지합니다. **완료한 장은 소비와 완제품을 한 번 확정하며, 취소는 미완료 장의 예약만 해제합니다.** 일시 단절·호스트 중단만으로 예약을 풀지 않습니다. 다른 사람이 도안을 고쳐도 진행 중 제품은 바뀌지 않습니다. [공방 손맛 상세](../claude-lead/W02-공방-손맛.md)에서 인쇄 완료·취소 표를 관리합니다.

## 각자 남기는 공방일지

| 기록 | 남기는 조건 |
| --- | --- |
| 내가 시험한 문장 | 직접 조립·발동하고 시험 결과를 확인 |
| 원정 공유 발견 | 발견 확인 사건 당시 던전 안에 있던 원정 참가자. 직접 조작·관찰한 사람은 출처로 따로 표시 |
| 제작·납품 기여 | 관련 작업 기록 또는 완료 때 참여. 공방에서 일한 사람의 기여도 여기에 남음 |
| 캠페인 기념 | 복원 작업·첫 사용·마지막 정산에 실제 참여한 기록과 인장 |

공방 작업자·먼저 귀환한 사람은 새 현장 발견을 자신의 목격 사실로 받지 않습니다. 공용 도감 열람은 가능하고 개인 일지에는 제작·납품 기여를 남깁니다. 같은 원정에 있되 같은 방을 못 본 동료의 기록은 공유 발견이라고 표시합니다. 서버의 같은 사건 판정으로 기록하며 새 경험치·재화는 추가하지 않습니다.

## 말 없이 협동하기
기본 핑 6개와 **재료·수량 요청**은 1일차부터 공방·던전 사이에 전달됩니다. 요청은 발견한 재료만, 동시 3개·같은 사람 2초 재전송 간격으로 시작합니다. 같은 공동 목표는 합치고 완료·취소 상태를 공유합니다. 6일차 실전화 컵은 별도의 음성 장치입니다.

동료가 만든 접착·먹막을 손으로 제거한 뒤, **풀린 플레이어**에게 동료의 같은 상태 재부여 보호 2초를 시험합니다. 자신이 떼든 다른 동료가 떼든 같습니다. 생물·환경·자기 문장은 보호하지 않고 당김은 별도 관찰합니다.

## 저장

| 항목 | 규칙 |
| --- | --- |
| 언제 | 중요한 사건이 확정될 때 `+` 15초마다 🧪 |
| 무엇을 | 공방과 던전을 **같은 시점**으로. 물때·출입·버팀·쓰러짐·물품 위치·계획/확정 예약·자력 회복·세계 변화·준비 마법, 고객 재고 소비·요청 완료·개인 기여·손 수습 보호까지 |
| 보관 | 마지막 정상본 `+` 그 이전 정상본 |
| 소유 | 공방 기록과 개인 프로필을 분리 |
| 수치 패치 | 이미 만든 제품도 최신 수치를 따름. 문장·도안·출처는 그대로 보존 |

저장 기능은 본편 단계에서 만듭니다. 스파이크 1에는 넣지 않습니다.

## 접속·거래·저장 예외15개
\[사실\] 호스트는 세계·돈·공동 재고·진행을 저장한다. 개인은 도안·기여·참여 발견을 가진다. 게스트 돈·물품·미해금 룬을 가져오지 않는다. 공동 발견은 사건 시점 원정 참여자,직접 해독자는 별도다. 호스트 정상 종료는 두 공간 공동 저장·중단,비정상 종료는 마지막 정상본이다.

90초는 재접속자의 **자리 예약**이며,90초에 물품·도안·참여 기록을 삭제하는 시간이 아니다. 아래는 v2.2에 적용한 설계 규칙이며 실제 재접속·복원 검증은 별도다.

| --- | --- | --- | --- |

| 15 | 호스트 충돌·개인 전달 중 단절 | 마지막 정상 공동 시점 복원·사건ID 중복 방지 | 호스트 성공 저장에 남은 개인 기록 재전달. 개인 최신 가방과 호스트 옛 재고 혼합 안 함 |

### 90초 이후의 참여 유지
\[추천\] 자리 예약 만료와 원정 참여 종료를 분리한다. 일시 단절은 해당 원정 물때 종료까지 참여 기록·같은 몸을 유지한다. 빈자리로 복귀하면 같은 진행을 이어받으며 자력 회복 횟수를 초기화하지 않는다. 원정 종료 뒤에는 공방으로 돌아온다.

자발적 퇴장은 참여 종료다. 새 게스트가4인 자리를 채우면 단절자는 연결해 조작할 수 없지만,그 사람의 확보품은 현장/종료 판정을 따른다. 새 게스트는 공방에 있으므로 그날 던전 발견의 참여자로 바뀌지 않는다. 단절자의 몸·회복·피해는 기존 단절 규칙을 따르며 무적 보관함을 새로 만들지 않는다.

물때 끝에 취약품/강한 확보품을 한 번 정산하고 참여를 종료한다.90초 자리 해제만으로 몸·짐을 지우거나 “전원 귀환”을 판정하지 않는다. 실제 몸의 대기 표현·공방 복귀 위치는 T1/T8에서 동일 상태로 구현할 검증 항목이다.

### 영속 저장 실패의 공동 중단
\[추천·v2.2 적용\] 디스크 저장 실패를 확인하면 두 공간을 공동 일시 중단한다. 물때·효과·공정·새 거래 승인을 함께 멈추고,기존 메모리의 확정 거래를 임의 환불하지 않는다. “저장 문제로 잠시 멈춤 / 마지막 정상 저장 시점 / 재시도”를 표시한다.

| 구분 | 처리 |
| --- | --- |
| 이미 메모리에 확정 | 같은 거래를 재실행하거나 뒤집지 않음. 현 상태의 공동 저장 재시도 |
| 승인 전 새 거래 | 중단 중 보류·거부. 소비와 성공 화면 없음 |
| 저장 성공 | 공동 시점·개정 확인 뒤 재개,개인 기록 전달 |
| 계속 실패 | 마지막 정상 시점과 보존되지 못한 구간 표시. 정상 종료 재시도 또는 마지막 정상본 다시 읽기 선택 |
| 강제 종료 | 마지막 정상본 복원. 그 이후 메모리 상태까지 보존됐다고 약속하지 않음 |

이는 현재 “실패 안내·재시도”의 구체적인 추천 변경안이다. 저장 실패 중에도 물때와 거래를 계속 진행시키는 안보다 정산 경계가 명확하다. 실제 저장 성공·원자성·복구 성능을 문서만으로 보장하지 않는다.

## 호스트 종료와1.0 범위
호스트 정상 종료는 공방·던전 공동 저장 후 전체 중단입니다. 중단 동안 물때·쓰러짐·날짜는 흐르지 않습니다. 비정상 종료는 마지막 정상 공동 시점으로 돌아갑니다. 자동 호스트 이전·전용 서버는1.0에서 제외합니다. 근처 음성과 말 없이 협동하는 요청 UI는 [08. 조작·화면·소리](08-조작-화면-소리.md)에서 관리합니다.
