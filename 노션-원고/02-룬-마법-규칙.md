### 수식 5 — 어떻게

| 룬 | 영어 | 준비 시간 | 지속 | 먹 | 장점 / 대가 |
| --- | --- | --- | --- | --- | --- |

숫자는 모두 🧪 시작값입니다. 한 장에 종이 1 + 기본 먹 1 + 동사 먹이 들고, 대상이 '주변'이면 동사 먹 1회분이 더 듭니다.

영어도 같은 순서로 읽습니다: `붙어라 + 너 + 오래` = `Stick + You + Long`. 활자에는 문양 + 해당 언어 글자가 찍히고, 문양은 언어와 상관없이 같습니다.

## 제작·발동의 공통 경계
\[사실\] 문장은 동사1`+`대상1`+`수식1이다. 7×6×5=210문장 모두 제작 가능하며, 210개가 모두 다른 효과는 아니다. 너는 가리킨 동료 또는 생물이다. 휴대 도안판2칸에는 완성 문장2개를 복사한다. 현장 급조6초는 원료 준비를 포함하며 봉인은 없다.

| 구분 | 결과 |
| --- | --- |
| 찢기 승인 | 한 장 소비. 물건·나·너는 개체, 바닥·벽은 면과 위치를 잠금 |
| 지연 뒤 발동 | 같은 대상으로 발동. 대상 소실·거리 이탈·차폐는 읽을 수 있는 무효. 환불·자동 재조준 없음 |

| 주변 | 발동 시 시전자 위치를 중심으로 선택. 선택 후 따라다니는 오라가 아님 |

## 상태8개와 반응S1\~S6

| 상태8 | 적용 경계 \[사실/추천\] |
| --- | --- |
| 젖음 | 사람·생물·소품·표면에 남은 물기. 물에 취약한 재고의 파손과 몸의 젖음을 별도로 판정 |
| 열 | 대상에 공급·남아 있는 열. 말림에 쓴 열을 다시 접착 해제에 쓰지 않음 |
| 빛 | 해당 몸·소품·면의 광원. 몸이 빛난다고 재고가 모두 빛나는 것은 아님 |
| 먹물 | 먹막·웅덩이의 위치와 차광. 물 취약 재료인 먹주머니와 상태 먹막은 다른 대상 |
| 끈적임 | 실제 접촉 결합. 면 효과와 몸 직접 효과를 구분 |
| 탄성 | 새 충돌의 반발. 같은 접촉을 매 틱 새로운 충돌로 세지 않음 |
| 가루 | 떠다니는 입자·막에 포집된 가루. 김과 다른 상태 |
| 바람 | 기존 송풍기·환경 바람. 현재 룬에 바람 생성 기능 없음 |

| 반응 | 판정 | 잘못 이해하기 쉬운 경계 |
| --- | --- | --- |
| S1 | 젖음`+`등심 성질→더 밝음 | 젖은 모든 생물이 자동 발광하지 않음 |
| S2 | 남은 열→접착 해제 조건 | 물만으로 해제 안 됨. 해제 열량 미결 |
| S3 | 먹막→기존 빛 차광 | 빛을 재시전해도 먹막이 자동 지워지지 않음 |
| S4 | 탄성`+`새 충돌→반발 | 접착은 별도. 접촉 유지 중 자동 재발사 없음 |
| S5 | 바람`+`가루→이동·확산 | 김은 여과 대상이 아님 |
| S6 | 젖음`+`열→말림·김 | S6 먼저, 남은 열만 S2와 실제 열 위험에 사용 |

같은 대상에 등심 발광과 먹막이 겹치면 S1의 밝기 상태를 계산한 뒤 S3로 보이는 빛을 가린다. 먹막을 걷으면 남아 있는 발광이 드러난다.

\[추천\] 열 사례는 ①물기 일부만 마름 ②전부 말랐지만 해제 열 부족 ③말림 뒤 접착도 해제의 세 결과로 시험한다. 김·남은 열·결합 여부를 같은 원인 카드로 기록한다. 물리 단위 없이 “한 장이면 언제나 해제”라고 보장하지 않는다.

## 손으로 수습하기
접착·먹막은 보통2초, 강한 접착은3초 손으로 제거합니다. 동료 원인의 접착·먹막을 손으로 푼 뒤 **풀려난 사람**에게 같은 동료 원인의 상태 재부여를2초 막습니다. 자기 손·다른 동료 손 모두 해당합니다. 생물·환경·자기 문장·당김까지 막는 면역으로 확대하지 않습니다. 같은 종류 재시전으로 손 수습 진행을 계속 초기화하지 않습니다.

자연 사고6가지와 전투·구조는 [생물·전투 상세](../claude-lead/W04-생물-전투.md)에서 관리합니다.

| --- | --- |
| 물에 약한 재료3종 | K01 바탕 종이·K05 말린 되감이풀·K07 먹주머니 파손. 갈아 둔 당김·차광 먹도 원료 취약성을 따름 |
| 미봉인 완제품(공방 미포장품·현장 급조품) | 종이처럼 파손. 휴대 도안판 급조는 봉인을 하지 않음 |
| 공방 봉인 완제품 | 물때 보존. 포장 공정이 봉인을 맡음 |
| 물에 강한 확보품 | 가방·손·바닥·수레의 위치와 무관하게 입구 공동 회수 |
| 미채집/공방 재고 | 미채집 재료는 자동 지급하지 않으며 정상 반출한 공방 재고는 지우지 않음 |

침수·귀환의 전체 정산은 [04. 던전·전투](04-던전-전투.md)를 따릅니다. 바람 생성·가루 젖기/뭉침 같은 추가 반응은 후속 후보이며 현재 S1\~S6에 넣지 않습니다.
