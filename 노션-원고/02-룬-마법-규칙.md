# ✍️ 02. 룬 마법 규칙

<callout icon="💡" color="gray_bg">
스크롤 한 장 = **[동사] + [대상] + [수식]** 세 룬으로 쓴 문장입니다. 7 × 6 × 5 = **210문장**. 엉뚱한 문장도 만들어지고 그대로 작동합니다. 확률로 다른 마법이 나오는 실패는 없습니다. ✅
</callout>

## 예시

| 문장 | 결과 |
|---|---|
| 빛나라 + 물건 + 오래 | **손없는 등불.** 짐에 붙여 6분 동안 밝힘 |
| 붙어라 + 물건 + 잠깐 | **꼼짝 도장.** 맞댄 부품을 4초 고정 |
| 당겨라 + 너 + 잠깐 | **동료 회수줄.** 조준한 동료를 내 쪽으로 1초 당김 |
| 붙어라 + 너 + 오래 | 장난. 동료가 다음에 닿는 물건에 오래 붙음 |
| 빛나라 + 나 + 넓게 | 사고. 나와 주위 2m의 동료·몬스터가 전부 빛남 |

## 룬 18개

### 동사 7 — 무엇을 하나

| 룬 | 영어 | 효과 | 기본 지속 🧪 | 먹 원료 | 색 |
|---|---|---|---:|---|---|
| 빛나라 | Glow | 빛을 냄 | 120초 | 등심이끼 | 연두 |
| 붙어라 | Stick | 다음에 닿는 것과 붙음 | 8초 | 눌림수지 | 호박 |
| 당겨라 | Pull | 기준점 쪽으로 당김 | 2초 | 말린 되감이풀 | 초록 |
| 튕겨라 | Bounce | 새로 부딪히면 튕겨 냄 | 8초 | 탄성점액 | 청록 |
| 달궈라 | Heat | 열을 줌. 물기부터 말림 | 4초 | 발열턱 | 주황 |
| 가려라 | Blot | 빛·글씨·시야를 먹막으로 덮음 | 20초 | 먹주머니 | 먹색·짙은 남보라 |
| 걸러라 | Filter | 떠다니는 가루를 붙잡음 (산소·해독 아님) | 30초 | 숨돌 | 회청 |

### 대상 6 — 어디에

| 룬 | 영어 | 기본 범위 🧪 | 넓게를 붙이면 |
|---|---|---|---|
| 물건 | Thing | 조준한 소품 하나 | 주위 2m의 소품들 |
| 바닥 | Floor | 조준한 바닥 반경 0.75m | 이어진 바닥 반경 1.5m |
| 벽 | Wall | 조준한 벽 반경 0.75m | 이어진 벽 반경 1.5m |
| 나 | Me | 나 자신 | 내 주위 2m의 생물 |
| 너 | You | 조준한 생물 하나. **동료든 몬스터든 구분 없음** | 그 생물 주위 2m의 생물 |
| 주변 | Around | 발동 위치 반경 2m의 생물·소품·표면 전부 | 반경 4m |

### 수식 5 — 어떻게

| 룬 | 영어 | 준비 시간 | 지속 | 먹 | 장점 / 대가 |
|---|---|---:|---:|---:|---|
| 잠깐 | Brief | 0.2초 | 기본의 절반 | 1회분 | 싸고 빠름 / 짧음 |
| 오래 | Long | 2초 | 기본의 3배 | 2회분 | 오래 감 / 준비 중에 상황이 바뀜 |
| 넓게 | Wide | 0.5초 | 기본 | 2회분 | 범위 확대 / 세기 0.65배, 동료도 휘말림 |
| 세게 | Hard | 0.5초 | 기본 | 2회분 | 세기 1.5배 / 반동·큰 소음 |
| 멀리 | Far | 0.8초 | 기본 | 2회분 | 사거리 4m → 12m / 조준이 흔들림 |

숫자는 모두 🧪 시작값입니다. 한 장에 종이 1 + 기본 먹 1 + 동사 먹이 들고, 대상이 '주변'이면 동사 먹 1회분이 더 듭니다.

영어도 같은 순서로 읽습니다: `붙어라 + 너 + 오래` = `Stick + You + Long`. 활자에는 문양 + 해당 언어 글자가 찍히고, 문양은 언어와 상관없이 같습니다.

## 스크롤 쓰는 순서 ✅

**찢기 → 한 장 소비·대상 고정 → 준비 시간 → 발동**

| 규칙 | 내용 |
|---|---|
| 대상 고정 | 찢는 순간 대상이 정해집니다. 대상이 사라지거나 범위를 벗어나도 다른 대상으로 바뀌지 않고, 스크롤도 돌려주지 않습니다 |
| 주변·넓게 | 범위 안에 누가 있는지는 **발동하는 순간** 정합니다. 나를 따라다니는 오라가 아닙니다 |
| 당겨라 기준점 | **찢은 순간 내가 서 있던 자리.** 그 뒤에 내가 움직여도 따라오지 않습니다 |
| 겹침 | 같은 효과가 겹치면 가장 센 것 하나만 적용하고, 각자 원래 끝나는 시각을 지킵니다 |
| 끝난 뒤 | 효과가 끝나도 옮겨진 물건·퍼진 가루는 제자리로 돌아오지 않습니다 |
| 맨손 수습 | 접착막·도장 떼기 2초, 강한 접착만 3초. 뗀 막은 바로 다시 붙지 않습니다 |
| 배움 | 배우지 않은 룬은 도안을 가져와도 만들 수 없습니다 |

**없는 것:** 벽 부수기, 허공에 고정, 자동 길찾기, 바람 룬, 룬 합성. ✅

## 속성 8개와 반응

젖음 · 열 · 빛 · 먹물 · 끈적임 · 탄성 · 가루 · 바람. 사람·몬스터·물건·바닥 모두 **같은 규칙**을 씁니다. 무게·고정 여부·열에 강한지에 따라 결과량만 달라집니다.

| 반응 | 결과 | 첫 실험 |
|---|---|---|
| S1 젖음 + 등심 성질 | 더 밝게 빛남 (젖은 생물이 전부 빛나는 건 아님) | 포함 |
| S2 열 + 끈적임 | 남은 열로 접착이 풀림 | 포함 |
| S3 먹물 + 빛 | 먹막에 덮인 빛이 어두워짐. 막을 떼면 돌아옴 | 포함 |
| S4 탄성 + 새 충돌 | 튕겨 나감. 무한 가속 없음, 접착을 저절로 풀진 않음 | 포함 |
| S5 바람 + 가루 | 가루가 날려 시야를 가림 | 포함 |
| S6 젖음 + 열 | 물기를 먼저 말리며 김이 남. 남은 열만 S2로 넘어감 | 포함 |
| R7 젖음 + 가루 / R8 바람 + 젖음 | 가루가 가라앉음 / 천천히 마름 | 나중에 |

처리 순서: **S6 → S2**, **S1 → S3**. 같은 사건을 반복해서 자원이 생기지 않게 막습니다.

## 물때와 물에 약한 것

던전은 입장 12분 뒤 물이 차서 모두 입구로 떠밀려 나옵니다. 이때 **물에 약한 것만** 잃습니다. ✅

| 물에 약함 (잃음) | 괜찮음 (남음) |
|---|---|
| 바탕 종이 | 기본 먹, 등심이끼, 숨돌, 눌림수지, 탄성점액, 발열턱 |
| 말린 되감이풀 | 공방에서 **봉인한** 완제품 |
| 먹주머니 | 공방 재고·돈·설비·룬·도안 |
| 현장에서 급조한(봉인 안 된) 스크롤 | 부재료 7종 |

- 가방에 있든, 손에 들었든, 바닥에 내려놓았든 같은 판정입니다.
- 물에 강한 재료는 입구에서 함께 회수합니다.
- 물을 한 번 맞았다고 가방이 바로 망가지진 않습니다. 12분 종료 때만 판정합니다.
