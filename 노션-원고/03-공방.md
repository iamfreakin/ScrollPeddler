# 🏠 03. 공방

<callout icon="💡" color="gray_bg">
공방은 게임의 **절반**입니다. 주문을 받고, **나무 활자로 문장을 조판**하고, 인쇄해서, 봉인한 뒤 팔거나 들고 나갑니다. 주문지·먹병·판·납품 상자가 전부 **손에 드는 물건**이라, 협동은 "건네주기"에서 저절로 생깁니다. 고정 직업은 없습니다.
</callout>

## 4공정과 손에 드는 물건

| 공정 | 물건과 손동작 | 여기서 하는 판단 |
|---|---|---|
| **A 응대·장부** | 손님 종 "딸랑" → 주문지가 나옴 → **수락 도장 쾅** → 조판대 위 **주문 줄**에 집게로 걸기. 장부, 돈통 | 어떤 주문을 받을지 |
| **B 먹·재료** | 재료 서랍 → **맷돌 벼루**에 원료를 넣고 손잡이를 누르고 있으면 동사 색 **먹병**이 참(8회분). 둘이 같이 돌리면 빨라짐 | 무엇을 얼마나 준비할지 |
| **C 조판·인쇄** | **활자 서랍**(18칸)에서 활자를 집어 **판틀** 세 칸에 "달칵" → 손잡이를 내려 **판**을 굳힘(= 도안 저장) → 판을 **인쇄기**에 꽂고 수량 다이얼 → 큰 손잡이를 당기면 3초에 한 장 | 대상·수식·원가·부작용 |
| **D 검사·봉인·출고** | **검사 틀**이 주문 조건과 대조 → **봉인대**에서 공방 인장을 1초 누르면 밀랍 "척" → 납품 상자 / 진열대 / 탐험 선반 | 팔 것 vs 들고 갈 것 |

- 활자 모양: 동사 = 둥근 활자, 대상 = 네모 활자, 수식 = 도장형 활자. 모양이 다른 칸엔 안 붙지만, 엉뚱한 문장은 막지 않습니다.
- 드래그 정밀도·타이밍 실패는 없습니다. 모든 손동작에는 같은 자리에서 쓰는 **메뉴 대체**가 있습니다(접근성·숙련자 속도).
- 판은 도안의 "몸"입니다. 동료에게 건네면 "이걸로 찍자"는 뜻이고, 판을 고치면 새 버전이 됩니다. 인쇄 중인 묶음은 시작할 때의 판을 유지합니다.
- 4명이 한 제품을 차례로 만져야 완성되는 구조는 두지 않습니다. 판틀은 2개, 인쇄기는 판 3개까지 줄 세우기.
- 먼저 귀환한 사람은 던전이 끝나기 전에도 공방 일을 합니다.

## 제작 흐름

1. **주문 읽기.** 손님은 "불편"을 말합니다. 필요한 효과만 맞으면 다른 문장도 인정합니다.
2. **조판.** 활자 세 개를 판틀에 끼우고 판을 굳힙니다. 이름은 문장으로 자동 제안됩니다.
3. **시험.** 시험 옆방에서 공짜 시험지로 써 봅니다. 시험 인형 **"멀쩡이"**, 상자·물 양동이·풀 드럼·가루 주머니·작은 화로로 반응을 미리 봅니다. **시험지는 문턱을 넘으면 백지가 됩니다.**
4. **인쇄.** 먹·종이가 부족하면 해당 색 램프가 깜빡이고 이유가 뜹니다.
5. **검사·봉인.** 봉인은 추가 비용·미니게임 없는 포장 공정입니다. **납품과 진열은 봉인품만** 받습니다. 봉인품은 물때에 안전합니다.

시간 목표 🧪: 새 문장 30초(입력 10~15초 포함), 판 굳히기 2초, 인쇄 설정 4초 + 3초/장, 두 장 봉인 8초.

## 파는 길

| 길 | 내용 |
|---|---|
| 의뢰 납품 | 마을 주문 상자는 **해 질 녘 에다**가, 길드 주문 상자는 **무로**가 가져갑니다. 다음 날 아침 후기 벽에 결과가 붙습니다 |
| 자유 판매 | 진열대에 봉인품을 올리면 가격표가 붙고, 개점 중 손님(이름 없는 NPC 4종)이 집어 가며 돈통에 동전을 넣습니다. **모두 던전에 가 있어도 판매는 계속됩니다** |
| 길드 의뢰 | 마을 게시판에서 의뢰지를 떼어 와 주문 줄에 겁니다. 수신기 설비를 사면 종이관 우편으로 "퐁" 들어옵니다 |
| 상인 리네 | 재료와 완제품을 삽니다. 시간을 아끼는 선택이고, 몬스터 재료는 조금만 비싸게 팝니다 |

## 공방 사고 — 쏟은 먹

먹병을 **던지거나 떨어뜨리면** 깨지고(내려놓을 땐 안 깨짐), 반경 1m에 20초 동안 그 먹의 성질이 번집니다. 걸레로 2초면 닦입니다.

| 쏟은 먹 | 벌어지는 일 |
|---|---|
| 빛나라 | 밟은 발이 빛남 |
| 붙어라 | 발·물건이 붙음 (손으로 2초) |
| 튕겨라 | 모두가 통통 튐 |
| 달궈라 | 뜨거움 (아군 원인이라 쓰러지진 않음), 젖어 있으면 김 |
| 가려라 | 먹 발자국, 조명을 덮음 |
| 당겨라·걸러라 | 색 얼룩만 |

- 설비는 망가지지 않습니다. 사고는 사람과 소품에만 납니다.
- 재고 스크롤을 공방에서 찢는 것도 가능합니다. 손님이 맞으면 다음 날 "공방 방문 후기"가 붙습니다. 예: "공방 방문 중 발광했습니다. 제품 설명과 일치합니다."

## 인원별 하루

| 인원 | 흐름 예 |
|---|---|
| 혼자 | 주문 받기 → 먹 갈기 → 조판·시험 → 인쇄 줄 세우고 봉인·포장 → 출정. 자동 분류(켜고 끔)와 인쇄 대기열이 도와줌 |
| 2인 | 한 명은 카운터·먹, 한 명은 조판·인쇄·봉인. **먹병을 건네는 순간**이 협동의 접점 |
| 4인 | 카운터·납품 / 먹 / 조판·인쇄 / 시험·봉인·탐험 준비로 자연스럽게 흩어짐. 할 일 없으면 게시판·장보기·시험실 놀기·2층 꾸미기 |

| 권장량 🧪 | 1인 | 2인 | 3인 | 4인 |
|---|---:|---:|---:|---:|
| 받을 주문 | 2건 | 3건 | 4건 | 5건 |
| 판매 | 4장 | 6장 | 8장 | 10장 |
| 탐험 준비 (파티 합계) | 4장 | 6장 | 8장 | 10장 |

## 성장

| 종류 | 내용 |
|---|---|
| 활자 서랍 | 18칸 중 처음엔 6칸만. 던전에서 탁본한 룬으로 새 활자를 부어 채웁니다. **서랍이 곧 진행표** |
| 설비 🧪 | 재료 서랍 240G · 시험 기록대 680G(두 판의 시험을 나란히 되감아 재생) · 거래처 수신기 1,580G(종이관 우편) |
| 평판 | 마을: 첫 거래 → 단골(마을 의뢰 4건) → 지정 공방(10건). 길드: 등록 → 신용 → 지정(인증 시험 + 길드 의뢰 5·12건). 자세한 건 **07. 경제·밸런스** |
| 꾸미기 | 2층 개방, 장식·기념품(탁본지, 신문 1면 액자). 능력치 없음 |

## 공간

- 공방: 정문에서 교차점을 두고 A(남서)·B(북서)·C(북동)·D(남동), C 옆에 시험 옆방. 입구에서 핵심 시설까지 약 15초. 🧪
- 마을: 중심 마당을 기준으로 공방(남)·상점(서)·게시판(동)·출정길(북).

| 항목 | 통과 신호 |
