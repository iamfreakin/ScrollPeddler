# 🎯 01. 게임 개요

<callout icon="💡" color="gray_bg">
친구 1~4명이 **두루마리 행상단**이 되어, **룬 세 개로 문장을 써서 스크롤을 만들고**, 팔거나 들고 던전에 갑니다. 잘못 쓴 문장도 그대로 작동해서 사고가 나고, 그 사고를 같이 수습하는 게 이 게임의 웃음입니다.
</callout>

## 핵심 재미 4가지

| 재미 | 어떻게 생기나 |
|---|---|
| **엉뚱한 문장** | 스크롤은 [동사]+[대상]+[수식] 문장입니다. 틀린 문장도 만들어지고 그대로 작동합니다. 확률로 실패하지 않아서, 사고가 나면 "누가 무슨 문장을 썼는지" 읽을 수 있습니다 |
| **팔 것 vs 쓸 것** | 같은 스크롤을 팔 수도, 던전에 들고 갈 수도 있습니다. 동료를 구하느라 쓴 한 장은 정산서에 건조하게 남습니다 |
| **사고 수습** | 친구의 마법에 붙고, 튕기고, 가려집니다. 마법 없이 맨손으로도 풀 수 있습니다 |
| **마을이 바뀐다** | 납품한 스크롤이 쓰인 결과가 손님 후기·주간 신문·마을 풍경으로 돌아옵니다 |

## 무대

| 장소·사람 | 설명 |
|---|---|
| **플레이어** | 남이 만든 스크롤을 읽지도 않고 팔던 떠돌이 **두루마리 행상단.** 젖은 골목에서 짐을 다 망치고 빈 공방에 눌러앉아, 처음으로 직접 만들어 팝니다 |
| **물레목 마을** | 종이를 만들며 살던 작은 마을. 밤마다 골목이 젖는 문제로 이야기가 시작됩니다 |
| **여백 공방** | 오래 비어 있던 스크롤 공방. 간판 밑 옛 글귀: "여백은 다음 사람 몫." 나무 활자로 문장을 조판하고, 찍고, 봉인해서 팝니다 |
| **던전** | 버려진 옛 작업장들. 물레종이소 → 잉크 광산 → 봉랍 양봉장 → 물레종이소 심층부 |

## 하루 한 판 (대표 24분)

| 시간 | 하는 일 | 고민거리 |
|---|---|---|
| 0~2분 | 주문·신문·재고 확인 | 어떤 주문을 받을지, 무엇을 살지 |
| 2~6분 | 문장 설계·시험·먹 준비·인쇄 | 대상·수식·원가·부작용 |
| 6~8분 | 검사·봉인·출고·출발 준비 | 팔 것과 들고 갈 것 나누기 |
| 8~11분 | 던전 가까운 구역 | 빨리 챙길지, 안쪽으로 갈지 |
| 11~17분 | 재료·몬스터·기억의 잔향 | 새 룬 배우기, 채집, 동료 구조 |
| 17~20분 | 물때 경고·철수 | 물에 약한 재료를 먼저 챙기기 |
| 20~22분 | 귀환·추가 제작·봉인 | 오늘 납품할 것, 내일 재고 |
| 22~24분 | 정산·후기·다음 주문 | 쓴 것·잃은 것·번 것 확인 |

- 공방 약 12분 + 던전 최대 12분. 🧪
- **함께 출발하고, 먼저 돌아와도 됩니다. 그날은 다시 못 들어갑니다.** 먼저 온 사람은 공방 일을 합니다. ✅
- 첫날은 조작 배우기를 포함해 30분입니다. ✅

5영업일이 한 주이고, 주마다 신문이 나옵니다. 25일째에 강제로 끝나지 않고, 엔딩 뒤에도 영업을 계속합니다.

| 3막 | 13~20일 | 두 수정본이 한 작업의 앞뒤였다 | 잉크 광산, 봉랍 양봉장(17일) |
