# 🎮 08. 조작·화면·소리

<callout icon="💡" color="gray_bg">
원칙은 하나입니다. **"왜 그렇게 됐는지 읽을 수 있게."** 정밀한 손놀림을 요구하지 않고, 사고가 나면 원인을 문장 → 이전 상태 → 반응 → 결과 순서로 보여 줍니다.
</callout>

## 화면 원칙 ✅

1. **UI는 종이입니다.** 모든 창은 쪽지·장부·신문처럼 보이고, 확인은 도장, 경고는 붉은 인주, 닫기는 종이를 접는 동작.
2. **공방에서는 설비를 바라보는 게 곧 화면입니다.** 조판대 앞에 서면 판틀이 가까워지고 옆에 설명 쪽지가 붙습니다. 전체 화면 메뉴는 장부·신문·정산서·설정뿐.
3. **던전 화면은 네 모서리만 씁니다.** 가운데는 조준과 세계를 위해 비웁니다.
4. **로비가 따로 없습니다. 공방이 로비입니다.** 친구가 들어오면 공방 문을 두드리고 들어옵니다.

## 기본 조작 🧪

모든 키는 바꿀 수 있고, "누르고 있기"는 "한 번 눌러 켜고 끄기"로 바꿀 수 있습니다.

| 행동 | 키보드·마우스 | 패드 |
|---|---|---|
| 이동 / 보기 | WASD / 마우스 | 왼쪽 / 오른쪽 스틱 |
| 상호작용·집기·놓기 | E | X |
| **찢기** | **왼쪽+오른쪽 클릭 동시**, 또는 F 누르고 있기 0.2초 | RT+LT, 또는 RB 누르고 있기 |
| 스크롤 바꾸기 | 휠 / 1~6 | 십자 좌우 |
| 손판 급조 | G 누르고 있기 (6초) | Y 누르고 있기 |
| 던지기 | E 누르고 있다가 놓기 | X 누르고 있다가 놓기 |
| 원인 카드 | R | 십자 위 |
| 핑 휠 | 가운데 클릭 또는 Q 누르고 있기 | LB 누르고 있기 |
| 가방 / 장부 | I / Tab | 보기 버튼 / 십자 아래 |
| 누르고 말하기 (설정 시) | V | 없음 (항상 켜짐 기본) |
| 사진 찍기 | 사진기를 든 채 왼쪽 클릭 | RT |

- 찢기를 양쪽 클릭 동시로 둔 이유: 두 손으로 찢는 느낌. 한 손 입력 대체는 필수입니다.
- 한 번 누르면 한 번만 실행합니다. 눌러 둔다고 스크롤이 연달아 찢기지 않습니다.

```

│   활자     │  (●빛나라)  [■물건]  (✿잠깐)  │   │ 빛나라+물건+잠깐│
│   서랍     └───────────────────────────────┘   │ 대상: 조준 소품 1│
│  ●●●○○○○                                        │ 준비 0.2초      │
│  ■■□□□□                                         │ 지속 60초       │
│  ✿○○○○                                          │ 먹: 빛 1회분    │
│  (빈 칸 = 아직 모르는 룬)                          │ 원가 6G · 판매가 20G│
│   [시험지 뽑기]  [판 굳히기]  [판 선반에서 불러오기] └────────────┘│
└──────────────────────────────────────────────────────────────┘
```

주문 조건 옆에 ✔ 또는 ✘가 찍히지만 **엉뚱한 문장도 굳힐 수 있습니다.** 편집 중인 사람 이름표가 판틀 모서리에 붙습니다.

**던전 표시**

```
┌────────────────────────────────────────────────────────────────┐
│ 행상단                       물때 ◔ 07:42  "물때 상승"          │
│ ● 준(세척실) 휘청임           ─────●───── (6·9·12 눈금)         │
│ ● 민(건조실)                                                    │
│ ◌ 서(공방·오늘 재입장 불가)                                      │
│ 내 상태                               +                         │
│ [붙음 3.2초 ·E 떼기]              [대상: 부풀달팽이 · 너]         │
│                                         손판 ①빛+물건+오래 ②붙+너+잠깐│
│ 핑 ▸ 여기·위험·도와줘·가져가·돌아가자·준비됐어    [손: 되감는 손 ×2]  │
│                                          등짐 ▮▮▮▮▯▯ (4/6)      │
└────────────────────────────────────────────────────────────────┘
```

물때 시계는 물레 바퀴 모양. 동료 상태는 글자 + 모양(● 정상 / ◐ 휘청임 / ✖ 쓰러짐 / ◌ 귀환). 물에 약한 물건을 들고 9분이 넘으면 파란 물방울 표시.

**정산서**

```
┌──────────── 여백 공방 · 12일차 정산 ────────────┐
│ 현금                                             │
│   의뢰 대금   M10 +70G · A06 +150G                │
│   자유 판매   +20G                                │
│   구매       −46G                                 │
│   ─────────────── 오늘 현금  +194G   [도장: 흑자] │
│ 상품 사용                                         │
│   동료 구조에 사용: '당겨라+너+잠깐' 1장            │
│   (예상 판매가 20G — 참고, 현금에서 빼지 않음)      │
│ 물때                                              │
│   보존: 등심이끼 2 · 봉인 스크롤 3                   │
│   파손: 먹주머니 1 · 미봉인 '붙어라+물건+잠깐' 1     │
│ 사건                                              │
│   발광 4 · 접착 2 · 튕김 1 · 구조 1                  │
│                              [접어서 닫기]         │
└──────────────────────────────────────────────┘
```

현금·사용·파손을 다른 칸에 적고(이중 차감 금지), 보존과 파손을 나란히 보여 줍니다.

**출정 준비대**

```
┌──────────── 출정 준비 ────────────┐
```

## 스크롤 쓰는 화면

| 단계 | 보이는 것 |
|---|---|
| 꺼내기 | 손의 종이에 **실제 세 룬**, 남은 장수, 봉인 여부 |
| 조준 | 후보는 점선 윤곽과 이름. "사거리 밖·대상 없음·고정됨" 같은 이유를 글자로 |
| 찢기 | 두 손이 종이를 찢고, 점선이 잠금 표시로 바뀜 |
| 준비 중 | "[대상] · 발동까지 N초" + 채워지는 막대 |
| 효과 중 | "[동사] · 효과 남음 N초" + 줄어드는 막대 (준비 막대와 모양이 다름) |
| 끝남 | 효과는 끝나도 옮겨진 물건은 그대로라는 걸 분명히 |

## 원인 카드 (R)

사고가 나면 **문장 → 이전 상태 → 반응 순서 → 결과 → 수습 방법**을 한 장으로 보여 줍니다. 만든 사람과 쓴 사람을 구분하고, 기록에 없는 책임을 만들지 않습니다.

## 말 없이 알리는 핑 6개

| 핑 | 알리는 것 |
|---|---|
| 여기 | 가리킨 위치·물건 |
| 위험 | 확인된 위험 상태 (뜨거움, 접착 등) |
| 도와줘 | 내 위치와 붙잡힌 이유 |
| 가져가 | 놓아둔 물품 이름 |
| 돌아가자 | 남은 물때 (강제 귀환 아님) |
| 준비됐어 | 출발 준비 완료 |

## 첫날 30분 (온보딩)

| 시간 | 배우는 것 |
|---|---|
| 0~2분 | 보기·이동·집기·내려놓기 |
| 2~4분 | 주문 장부 읽기 |
| 4~8분 | 룬 세 개로 문장 만들기 |
| 8~10분 | 꺼내기·조준·찢기·맨손으로 떼기 (시험판) |
| 10~12분 | 도안 저장·인쇄·봉인 |
| 12~14분 | 원정 준비 (휴대 도안 2개, 가방, 물에 약한 것, 재입장 불가) |
| 14~20분 | 채집·운반·현장 사용·핑 |
| 20~26분 | 물때 변화·급조·철수 판단 |
| 26~30분 | 반출 정리·정산·후기·다음 주문 |

- 첫날에 모든 룬을 가르치지 않습니다. 새 룬은 배우는 날 현장에서 짧게 안내합니다.
- 긴 설명은 출발 전과 귀환 후에만. 던전에서 도움말이 물때를 멈추지 않습니다.
- 2회차부터는 "처음부터 / 핵심만 / 건너뛰기"를 고를 수 있습니다.

## 접근성

| 항목 | 내용 |
|---|---|
| 색에만 기대지 않기 | 룬은 모양·문양·이름을 함께. 색을 빼도 구분 가능해야 함 |
| 글자 🧪 | 1080p에서 핵심 글자 24px, 자막 32px 출발, 100~200% 확대 |
| 자막 | 대사 자막 기본 켬. 중요한 소리도 "왼쪽: 접착막 풀림"처럼 글자로 |
| 입력 | 모든 키 재지정, 누르기 유지 → 한 번 누르기로 바꾸기, 한 손 배치 |
| 조준 보조 | 끄기·약하게·강하게 |
| 흔들림·섬광 | 줄이기·끄기 |
| 선택 읽어주기 | 고른 룬·문장을 짧게 읽어 줌 |

설정은 게임 규칙(물때·몬스터 청각)을 바꾸지 않습니다.

## 근처 음성 채팅 ✅

| 항목 | 규칙 🧪 |
|---|---|
| 들리는 거리 | 3m까지 원래 크기, 25m에서 0. 3D 방향으로 들림 |
| 벽 | 벽·문 너머는 먹먹하게 |
| 공방 ↔ 던전 | 서로 안 들림. **실전화 컵**으로만 연결 |
| 쓰러짐 | 속삭임 거리(8m)로 줄어듦. 가까이 와서 들어 줘야 함 |
| 게임 영향 | **없음. 몬스터는 목소리를 듣지 않습니다.** 마이크 없는 사람도 똑같이 플레이 |
| 방식 | 기본 "항상 켜짐 + 목소리 감지", 설정에서 누르고 말하기. 사람별 음소거, 스트리머 모드 |
| 초대 | Steam 친구만. 1.0에 공개 매칭 없음 |

**상태가 목소리를 바꿉니다** (끄기 가능): 여과막 → 마스크 목소리 · 먹막 → 입 가린 목소리 · 튕기는 중 → 높낮이 출렁 · 끌려감 → 지나가며 음이 휨 · 물때에 떠밀림 → 보글보글 1.5초.

**실전화 컵:** 종이컵 두 개를 되감이풀 실로 이은 장난감 전화. 6일차 아침 보린의 선물. 공방 벽의 본 컵 + 각자 허리의 작은 컵으로, **먼저 귀환한 동료(공방)와 던전 동료가 대화**합니다. 컵을 드는 동안엔 양손 찢기를 못 합니다.

**외치기 연출:** 찢는 순간 소리 내어 외치면 룬 글자가 두 배로 번쩍입니다. 효과는 같습니다. 음성 인식 발동은 1.0 밖입니다.
