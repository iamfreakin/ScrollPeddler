## 화면 원칙 ✅
1. **UI는 종이입니다.** 모든 창은 쪽지·장부·신문처럼 보이고, 확인은 도장, 경고는 붉은 인주, 닫기는 종이를 접는 동작.
2. **공방에서는 설비를 바라보는 게 곧 화면입니다.** 조판대 앞에 서면 판틀이 가까워지고 옆에 설명 쪽지가 붙습니다. 전체 화면 메뉴는 장부·신문·정산서·설정뿐.
3. **던전 화면은 네 모서리만 씁니다.** 가운데는 조준과 세계를 위해 비웁니다.
4. **로비가 따로 없습니다. 공방이 로비입니다.** 친구가 들어오면 공방 문을 두드리고 들어옵니다.

## 기본 조작 🧪
모든 키는 바꿀 수 있고, "누르고 있기"는 "한 번 눌러 켜고 끄기"로 바꿀 수 있습니다.

| 행동 | 키보드·마우스 | 패드 |
| --- | --- | --- |
| 이동 / 보기 | WASD / 마우스 | 왼쪽 / 오른쪽 스틱 |
| 상호작용·집기·놓기 | E | X |
| **찢기** | **왼쪽`+`오른쪽 클릭 동시**, 또는 F 누르고 있기 0.2초 | RT`+`LT, 또는 RB 누르고 있기 |
| 스크롤 바꾸기 | 휠 / 1\~6 | 십자 좌우 |
| 손판 급조 | G 누르고 있기 (6초) | Y 누르고 있기 |
| 던지기 | E 누르고 있다가 놓기 | X 누르고 있다가 놓기 |
| 원인 카드 | R | 십자 위 |
| 핑 휠 | 가운데 클릭 또는 Q 누르고 있기 | LB 누르고 있기 |
| 가방 / 장부 | I / Tab | 보기 버튼 / 십자 아래 |
| 누르고 말하기 (설정 시) | V | 없음 (항상 켜짐 기본) |
| 사진 찍기 | 사진기를 든 채 왼쪽 클릭 | RT |

- 찢기를 양쪽 클릭 동시로 둔 이유: 두 손으로 찢는 느낌. 한 손 입력 대체는 필수입니다.
- 한 번 누르면 한 번만 실행합니다. 눌러 둔다고 스크롤이 연달아 찢기지 않습니다.

## 스크롤 쓰는 화면

| 단계 | 보이는 것 |
| --- | --- |
| 꺼내기 | 손의 종이에 **실제 세 룬**, 남은 장수, 봉인 여부 |
| 조준 | 후보는 점선 윤곽과 이름. "사거리 밖·대상 없음·고정됨" 같은 이유를 글자로 |
| 찢기 | 두 손이 종이를 찢고, 점선이 잠금 표시로 바뀜 |
| 준비 중 | "\[대상\] · 발동까지 N초" `+` 채워지는 막대 |
| 효과 중 | "\[동사\] · 효과 남음 N초" `+` 줄어드는 막대 (준비 막대와 모양이 다름) |
| 끝남 | 효과는 끝나도 옮겨진 물건은 그대로라는 걸 분명히 |

## 원인 카드 (R)
사고가 나면 **문장 → 이전 상태 → 반응 순서 → 결과 → 수습 방법**을 한 장으로 보여 줍니다. 만든 사람과 쓴 사람을 구분하고, 기록에 없는 책임을 만들지 않습니다.

동료가 만든 접착·먹막에서 손으로 풀린 플레이어에게 같은 동료 상태 재부여 보호 2초를 시험합니다. 다른 동료가 대신 해제해도 보호받는 사람은 풀린 사람입니다. 작은 종이 표시로 이유와 남은 시간을 보여 주며 생물·환경·자기 효과의 전면 면역처럼 표시하지 않습니다.

## 말 없이 알리는 핑 6개

| 핑 | 알리는 것 |
| --- | --- |
| 여기 | 가리킨 위치·물건 |
| 위험 | 확인된 위험 상태 (뜨거움, 접착 등) |
| 도와줘 | 내 위치와 붙잡힌 이유 |
| 가져가 | 놓아둔 물품 이름 |
| 돌아가자 | 남은 물때 (강제 귀환 아님) |
| 준비됐어 | 출발 준비 완료 |

### 재료·수량 요청은 첫날부터
기존 주문·재료·준비 화면에서 **“눌림수지 2개 필요 — 주문 준비”**를 한 번 눌러 보냅니다. 발견한 재료만 선택하고 수량을 고칠 수 있습니다. 같은 공동 목표의 같은 재료는 합치며, 다른 목표는 용도를 보존해 중복 예약량을 알려 줍니다. 목표 충족·취소 상태를 공유합니다.

시작값은 동시 3개·같은 사람 2초 재전송 간격입니다. 재료명·문양·수량을 함께 쓰고 공방·던전 사이에도 전달합니다. 맵에는 발견한 곳을 요청할 때만 표시하고 미발견 산지를 자동 안내하지 않습니다. 6일차 컵이 없어도 물류 의사소통은 가능합니다.

### 재고 계획과 공방일지
재고·준비 화면에는 **사용 가능 재고 / 주문 필요량 / 탐험에 남길 양 / 부족량**을 나란히 둡니다. 계획 예약을 다른 용도로 쓰면 한 번 확인하고 갱신합니다. 진행 중 인쇄 묶음의 확정 예약은 다른 곳에서 소비할 수 없으며 취소 시 미소비분만 풀립니다.

개인 공방일지는 기존 도감 탭에서 자신이 시험한 문장·원정 공유 발견·직접 확인·공동 제작/납품·캠페인 기념을 보여 줍니다. 발견 당시 던전 참가자와 직접 관찰자는 구분합니다. 공방 작업자·먼저 귀환한 사람에게 새 현장 목격 기록을 주지 않습니다. 호스트 돈·해금은 개인 기록으로 복사하지 않습니다.

## 첫날 30분 (온보딩)
본편은 시작6룬으로 각자 조립·찢기·대상 변경을 완료합니다. 공개36분 데모의 시작7룬·넓게 소개는 별도 편집안이며 본편 날짜 해금에 섞지 않습니다. 무료 시험은 실제 재고·납품 완료를 만들지 않습니다.

| 시간 | 배우는 것 |
| --- | --- |
| 0\~3분 | 집기·놓기, 각자 M01의 짐 대상 조건 확인 |
| 3\~5분 | 기존 판틀 2개에서 차례로 자기 시험용 문장 조립 |
| 5\~7분 | 각자 무료 시험 → 물건/나의 차이 관찰 → 대상 한 칸 수정 |
| 7\~10분 | 공동 판 선택·먹 준비·M01 2·3·4·5장 묶음 인쇄(1\~4인) |
| 10\~12분 | 검사·인장·봉인·상자 넣기. 공동 제작으로 중복 보상 없음 |
| 12\~14분 | 원정 준비 (휴대 도안 2개, 가방, 물에 약한 것, 재입장 불가) |
| 14\~20분 | 채집·운반·현장 사용·핑 |
| 20\~26분 | 물때 변화·급조·철수 판단 |
| 26\~30분 | 반출 정리·정산·에다의 실제 사용 결과·다음 목표 |

- 첫날에 모든 룬을 가르치지 않습니다. 새 룬은 배우는 날 현장에서 짧게 안내합니다.
- 긴 설명은 출발 전과 귀환 후에만. 던전에서 도움말이 물때를 멈추지 않습니다.
- 2회차부터는 "처음부터 / 핵심만 / 건너뛰기"를 고를 수 있습니다.
- 첫날은 공방 14분 `+` 원정 최대 12분 `+` 귀환 4분입니다. 무료 시험은 개인 완료를 기록하고 한 명이 모두 대신 끝내지 않습니다. 붙어라 손 해제는 선택 연습이며 아직 안 한 사람은 2일차에 이어갑니다.
- 선택 프롤로그 2분은 별도입니다. 함께 보면 도입·첫날 약 32분, 건너뛰면 본편 첫날 약 30분입니다.
- M01 수거 때 에다의 실제 사용이 첫 결과가 되고, 정식 후기는 다음 아침입니다. 고객 장면은 10\~25초·카메라 강제 고정 없이 기존 장면을 재사용합니다.

## 근처 음성 채팅 ✅

| 항목 | 규칙 🧪 |
| --- | --- |
| 들리는 거리 | 3m까지 원래 크기, 25m에서 0. 3D 방향으로 들림 |
| 벽 | 벽·문 너머는 먹먹하게 |
| 공방 ↔ 던전 음성 | 목소리는 서로 안 들림. 6일 이후 **실전화 컵**으로 연결. 기본 핑·수량 요청은 첫날부터 전달 |
| 쓰러짐 | 속삭임 거리(8m)로 줄어듦. 가까이 와서 들어 줘야 함 |
| 게임 영향 | **없음. 몬스터는 목소리를 듣지 않습니다.** 마이크 없는 사람도 똑같이 플레이 |
| 방식 | 기본 "항상 켜짐 `+` 목소리 감지", 설정에서 누르고 말하기. 사람별 음소거, 스트리머 모드 |
| 초대 | Steam 친구만. 1.0에 공개 매칭 없음 |

**상태가 목소리를 바꿉니다** (끄기 가능): 여과막 → 마스크 목소리 · 먹막 → 입 가린 목소리 · 튕기는 중 → 높낮이 출렁 · 끌려감 → 지나가며 음이 휨 · 물때에 떠밀림 → 보글보글 1.5초.

**실전화 컵:** 종이컵 두 개를 되감이풀 실로 이은 장난감 전화. 6일 이후 골목 수리가 실제 완료된 뒤 아침에 받는 보린의 선물. 공방 벽의 본 컵 `+` 각자 허리의 작은 컵으로, **먼저 귀환한 동료(공방)와 던전 동료가 대화**합니다. 컵을 드는 동안엔 양손 찢기를 못 합니다.

첫날부터 먼저 귀환이 가능하므로 컵 이전 1\~5일도 핑·수량 요청으로 소통합니다. 컵은 음성의 거리감·역할극을 더하는 장치이며 주문·재고 정보의 필수 장비가 아닙니다.

**외치기 연출:** 찢는 순간 소리 내어 외치면 룬 글자가 두 배로 번쩍입니다. 효과는 같습니다. 음성 인식 발동은 1.0 밖입니다.

## 입력 취소·손 수습 경계
손 작업→메뉴→든 도구→현장 행동 순서로 입력을 처리합니다. 취소/닫기가 찢기·던지기로 이어지지 않습니다. 자기 몸 막은 발/등 조준 없이 선택합니다. 손 해제는 놓기/취소·거리 이탈·대상 소멸 때 중단, 잠깐 시선 이탈은 유지하며 재시도는 처음부터입니다. 보통2초·강한 접착만3초, 같은 막 재도장으로 진행 시간을 초기화하지 않습니다. 급조6초에 원재료 갈기 포함, 취소 전에 난 소음/시간은 유지합니다.
