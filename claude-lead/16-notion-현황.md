- 시작점: https://app.notion.com/p/222428b239a08093aca9d4930d6137d2
- 총계: **페이지 66개 = 일반 문서 33개(메인 포함) + 데이터베이스 항목 페이지 33개**. **데이터베이스 2개는 별도**이며, 트리에 표시한 객체는 총 68개다. 같은 페이지를 가리키는 본문 링크·보기·데이터 소스는 중복 집계하지 않는다.
- 탐색: 실제 자식 페이지/데이터베이스 → 모든 DB 항목 → 각 항목의 자식 순서로 끝까지 확인했다. 추가로 본문·URL 속성의 Notion 링크를 대조했으며 모두 이 트리 안의 조회 완료 대상으로 연결됐다. 메인 본문에는 직접 자식 링크 8개 외에 별도 Notion 페이지 참조가 없다.
- 시각: ‘마지막 수정’은 API `page_last_edited_at`(항목은 대응 자동 속성도 대조)을 한국 시각으로 변환했다. DB 컨테이너의 수정 시각은 API가 제공하지 않아 미제공으로 표시한다. 자식의 수정 시각으로 부모 시각을 추정하지 않는다.
- 대략 분량 [추정]: API 전체 본문 문자 수(표·링크 등 서식 포함)로 짧음 <1,500자 / 보통 1,500~5,999자 / 김 ≥6,000자. 본문 속성값은 제외한다. DB 자체는 본문 분량을 분류하지 않고 항목을 각각 표시한다.
- 근거의 한계: 모든 대상 조회는 성공했고 잘림 표시·`<unknown>` 블록은 발견하지 못했다. 다만 `truncated`·`unknown_block_count`·`unknown_block_ids` 필드는 응답에 미제공이므로 ‘서버가 0으로 명시했다’는 뜻은 아니다. 제목·URL·부모·수정 시각은 조회 사실, 한 줄 요약·분량 분류는 조사자가 정리한 내용이다.

## 사용자와 확인한 핵심
- 의뢰가 들어오면 필요한 스크롤을 제작해 판매한다.
- 의뢰 외에도 다른 스크롤을 만들어 자유롭게 판매하고 돈을 모은다.
- 부족한 제작 재료는 돈으로 구매할 수 있다.
- 재료를 얻으러 가기 전에 탐험에 필요한 마법 스크롤을 구매할 수 있다.
- 던전에서 재료를 모으며, 몬스터에게서 얻는 재료도 있다.
- 주문서 사용이 사고와 구조로 이어지는 협동 소동을 주요 재미로 삼는다.
## 공방과 던전이 이어지는 흐름
**의뢰·만들 상품 확인 → 재료 확인 → 부족분 구매 또는 던전 탐험 → 스크롤 제작 → 의뢰 납품·자유 판매 → 수입으로 재료·탐험용 스크롤 마련.**
직접 만든 스크롤도 팔거나 탐험에 가져갈 수 있는 안을 제안한다. 생활용과 탐험용이 같은 성질을 가진 상품이어서, 수레를 밝히는 등불을 동료의 가방에 붙이고 수리공의 고정 도장을 던전 발판에 쓸 수 있다.
돈은 공방에 쌓여 다음 구매로 이어지는 자원이다. 공용 재고·공방 자금으로 운영하는 안을 먼저 검토하며 가격·구매 권한·실패 손실은 실제 시험 뒤 조정한다.
## 이번에 제안하는 무대와 첫 이야기
**물레목 마을의 ‘여백 공방’과, 재료를 구하러 들어가는 오래된 ‘물레종이소’.**
제지소의 종이·먹·풀을 먹고 사는 생물이 마법 재료의 원천이 된다. 빛을 머금는 이끼, 늘었다가 돌아오는 풀, 접착제를 녹이는 딱정벌레의 턱처럼 소재의 성질이 완성품의 기능으로 이어진다.
첫 이야기는 **‘밤마다 젖는 골목’**이다. 배달부의 조명, 수리공의 고정 도구, 관측원의 여과 도구 주문을 해결하다가 제지소에서 거꾸로 흐르는 수증기의 원인을 알아낸다. 마지막에는 만든 스크롤로 수리 작업을 돕고, 손님과 마을 풍경의 변화를 확인한다.
손님이 필요한 이유를 말하고, 제작자가 재료와 도구로 답하며, 실제 사용 후기가 다음 주문으로 돌아오게 한다.
