## 0. 결론
1. 고유 의뢰 32건을 문장별로 다시 계산했다. **1·2·3·4인 순서로 68·112·136·180장, 동사 먹 112·186·224·298회분, 보상 2,900·4,340·4,940·6,380G**다(\[추정\], 대표 문장 기준).
2. 납품 장수에 하루 전체 판매 상한을 씌우지 않는다. 자유 판매 정상 수요만 **2·3·4·5장**이다. 계약은 발주 수·주문별 수량·분할 납품으로 관리한다.
3. 상인의 몬스터 원료·먹·완제품은 같은 한도를 쓴다. **하루 2회분 + 5일 주간 5회분**, 파티 공용이며 필요한 품목을 항상 살 수 있다는 뜻은 아니다.
4. 부풀달팽이는 개체당 하루 1회 떨군다. 2개체의 최대 탄성 먹이 8회분에서 **4회분**으로 줄므로 예전 공급 충분 판정을 폐기한다.
5. 선택 지출처 약 **3,960G**와 저축 허용은 유지한다. 기존 말일 잔액·매출 외삽은 새 규칙의 목표로 쓰지 않는다.

## 1. 문장별 가격
\[추천\] 동사 먹 소비 `m = 잠깐 1 / 다른 수식 2 / 주변 대상이면 +1`이다. 표준 원가 `C = 종이 2G + 기본 먹 1G + m × 동사 먹 1회분 구매가`, 자유 판매가 `F = ceil((1.25C + 8) / 5) × 5G`다.

| 동사 | 먹 1회분 구매가 | m=1의 C / F | m=2의 C / F | m=3의 C / F |
| --- | --- | --- | --- | --- |
| 빛나라 | 3G | 6 / 20G | 9 / 20G | 12 / 25G |
| 붙어라 | 4G | 7 / 20G | 11 / 25G | 15 / 30G |
| 당겨라 | 5G | 8 / 20G | 13 / 25G | 18 / 35G |
| 걸러라 | 6G | 9 / 20G | 15 / 30G | 21 / 35G |
| 튕겨라 | 24G | 27 / 45G | 51 / 75G | 75 / 105G |
| 달궈라 | 28G | 31 / 50G | 59 / 85G | 87 / 120G |
| 가려라 | 32G | 35 / 55G | 67 / 95G | 99 / 135G |

m=1은 주변 이외 대상+잠깐, m=2는 주변+잠깐 또는 주변 이외+다른 수식, m=3은 주변+다른 수식이다. 채집 원료로 만들어도 비교용 C는 같지만 **현금 지출에는 실제 구매만** 기록한다. 무료 시험은 판매품·공방 재고를 만들지 않으며 재료 소비도 없다.

## 2. 의뢰 32건 — 인원별 재계산
\[추천\] 인원 배수는 **1 / 1.5 / 2 / 2.5**다. 주문 수락 때 인원을 확정하고, **각 문장 줄의 기본 q에 배수를 곱한 뒤 올림**한다. 접속 변화·이름 변경·다음 날 이월로 수량을 다시 늘리지 않는다.
- 아래 수량·먹·보상 열의 순서는 모두 **1인 / 2인 / 3인 / 4인**이다.
- 동사 먹은 각 문장 장수×m의 합이다. 빛 먹과 가열 먹을 교환 가능한 한 종류로 취급하지 않는다.
- 총보상은 `Σ(수락한 문장 줄의 장수 × 제시 F) + B`. **B는 주문당 한 번**이며 인원 배수를 곱하지 않는다.
- 대표 문장은 계산 예시다. 주문 조건을 만족하는 다른 문장도 받지만 대금은 §3.1대로 수락 때 고정한다.

### 3.1 수락 전에 보상을 확정
\[추천\] 조건 변경으로 더 비싼 문장이 필요하면 **수락 전** 발주 문장 줄의 F와 총보상을 다시 계산해 표시한다. 수락 후 조건을 만족하는 다른 문장을 내도 **표시된 계약 총보상은 고정**이다. 비싼 대체품이라고 추가 F를 주거나 싼 대체품이라고 숨은 감액을 하지 않는다. 주문 변경을 원하면 아직 소비·납품하지 않은 상태에서 취소·재발주하며, 이미 납품한 상자와 새 주문을 중복 완료로 처리하지 않는다.

제품 대금, 조건 보너스, 화제 보너스를 포함한 총액을 완료 때 한 번 지급한다. 자유 판매나 고객 사용 장면으로 같은 제품 대금·공방 재료를 다시 더하거나 빼지 않는다. 산 완제품은 탐험용이며 자체 제작 의뢰의 제작 실적·보너스 대상이 아니다.

이 가격식의 q는 수락한 **대표 견적 장수**다. 대안은 같은 기능 작업을 충족해도 종이·먹 실제 소비량이 달라진다. A05의 잠깐3장 대안에 F를 세 번 곱해 계약금을 올리지 않는다. 대표 합계68/112/136/180장은 대표 도안 계산으로 유지하고 대안 실제 장수는 별도 소비 칸에 기록한다.

조건·수락 묶음·대안의 자세한 내용은 [의뢰 판정·납품 규격](W14-의뢰판정-납품규격.md)에 있습니다.

### 3.2 재고 예약의 경계

| 상태 | \[추천\] 다른 용도로 쓸 때 |
| --- | --- |
| 주문·탐험의 계획 예약 | 표시와 확인용. 한 번 확인하면 실제 재고와 두 계획의 부족량을 함께 갱신 |
| 이미 시작한 인쇄 묶음의 확정 예약 | 다른 작업이 소비할 수 없음. 시작한 도안과 재료를 유지 |
| 묶음 취소 | 아직 소비하지 않은 몫만 예약 해제. 소비분은 복사 반환하지 않음 |
| 납품 상자 속 적합품 | 해당 계약에 귀속. 아직 완료 전이면 꺼내어 이월 계획 갱신 가능 |
| 현장 신규 재료 | 반출 전에는 공방 재고가 아님. 조기 반출 때부터 공방 작업 가능 |
| 종료 안전 회수 | 획득한 물에 강한 잔류품을 종료 때 공동 회수. 기존 휴대품 귀환은 새 공급으로 세지 않음 |

같은 원료를 주문과 탐험 양쪽에 예약하면 합산 부족량을 표시한다. 예약 자체는 소비·구매·매출이 아니다. 자세한 물때·운반 판정은 W05와 기준 설계를 따른다.

### 6.3 몬스터 먹 상한과 떨굼 1회의 영향
\[추천\] 리네의 몬스터 원료·먹·완제품은 **하루 합계 2회분, 5일 주간 합계 5회분**이다. 1\~4인 파티 공용이며 세 종류를 합친다. 원료 1개는 2회분, 완제품은 실제 m만큼 두 한도에서 차감한다. 주간 신문 구간 시작 때 주간 한도를 갱신하고 하루 마감 때 일일 재고를 갱신한다. 재접속·인원 교대·조기 귀환·상인에게 되팔기로 한도를 복원하지 않는다.

| 점검 | \[추정\] 산술 결과·한계 |
| --- | --- |
| 기존 1인 3\~4주 예시 수요 | 고유 6\~7 + 탐험 6 = **12\~13회분/주**. 이 예시에는 몬스터 먹을 쓰는 선택 판매·재주문이 없음 |
| 상인 최대 보충 비중 | 필요한 종류와 돈이 있을 때 `5÷12~13` = **약 38\~42%**. 실제 구매율이 아님 |
| 필요한 던전·이전 재고 | 위 예시에서 적어도 **7\~8회분**. 필요한 동사 종류가 맞아야 함 |
| 부풀달팽이 2개체 | 개체당 하루 1회·탄성점액 1개: **원료 2개 = 먹 4회분** |
| 이전 2회 채취와 비교 | 원료 4개 = 먹 8회분에서 **최대 4회분 감소**. 5일 내내 두 개체를 확보했다면 최대 감소 20회분이나 실제 획득 감소는 실측 |
| 물레종이소 1인 최대 예시 | B01 2개체·B02 2개체·B03 1개체를 전부 성공·반출하면 몬스터 원료 5개 = **10회분**. 지역별 배치 변경 시 다시 계산 |
| 보상 단위 | 단독 생물은 개체 ID당 그날 1회, 책먼지나방은 **3\~5마리 무리 ID당 숨털뭉치 1개**. K13·K20는 먹으로 환산하지 않음 |

최대 출현·회수 가능량을 매일 실제 반출량으로 사용하지 않는다. 서로 다른 지역의 개체 수를 하루 원정에 합산하지 않는다. 탄성 먹의 최대치가 줄었다고 다른 원료가 자동으로 탄성을 대체하지 않는다. 시간이 모자라거나 종류가 부족하면 인원별 개체 기회·경로·주문 이월·재주문 빈도·탐험 사용을 먼저 점검한다. 공급이 충분하다는 결론은 플레이 전에는 내리지 않는다.

### 6.4 전체 재고 보존과 안전 반출 수급을 구별
\[추천\] 종이·기본 먹은 각각, 동사 먹은 동사별로 같은 단위로 환산한다. 모든 위치의 소유 재고가 보존되는지 확인하는 장부와, 공방에 새로 확보한 공급률은 다른 지표다.

| 기록 | 세는 시점·범위 | 제외 |
| --- | --- | --- |
| 전체 소유 유입 | 자연 자원을 최초 확보하거나 실제 구매할 때1회 | 반출·회수·공방 이동·갈기·인쇄 |
| 전체 외부 소비 | 납품·판매·찢기·실제 파손 때1회 | 원료→먹→제품의 내부 전환 |
| 전체 보유량 | 공방+가방+손+현장 확보품+계약 상자. 원료·먹·제품에 담긴 양 환산 | 미채집 자원·계획 숫자 |
| 안전 반출 수급 지표의 분자 | 새 채집이 정상 반출·종료 안전 회수로 공방에 들어온 양+실제 구매 | 기존 휴대품 귀환·현장 획득 자체·내부 전환 |
| 안전 반출 수급 지표의 분모 | 3일 동안 실제 외부 소비. 현장 사용·파손도 포함 | 공방에서 만든 것을 현장 급조로 다시 센 가공량 |
| 목표 | 기존3일 전체/동사별1.0\~1.15를 유지. 시작 비축과 현장 보유도 함께 해석 | 비율만으로 재고 보존을 증명하지 않음 |

전체 보유량 변화=전체 소유 유입−전체 외부 소비다. 안전 반출 수급률은 이 등식의 유입과 같은 변수로 쓰지 않는다.

예: 수지1개를 현장에서 확보하면 전체 유입+4먹회분·현장 보유+4,안전 반출0이다. 그중1회분을 급조해 사용하면 외부 소비1·현장 보유3이다. 나머지3을 반출하면 전체 유입 추가0·공방 보유3·현장 보유0·안전 반출+3이다. 처음 얻은4와 돌아온3을 더해 공급7로 기록하지 않는다. 취약품을 반출 전 잃으면 전체 유입과 파손은 기록되지만 안전 반출은0이다.

비축을 쓰거나 현장에서 새 재료를 바로 사용하는 구간은 안전 반출 비율이1보다 작을 수 있다. 그 원인을 전체 장부로 확인한 뒤 다음 구간 구매·채집량을 조정한다. 납품량을 접속 변화로 다시 늘리지 않는다.
