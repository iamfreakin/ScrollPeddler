# T6. 이야기 — 만든 물건이 사람의 생활로 돌아오는 구조

2026-10-07 · 설계 v2.2 동기화 · 설계 개정 2026-10-06

**스크롤을 쓰는 영웅보다, 그 물건을 만드는 행상단의 이야기다.** [사실] 악당·보스전 없이 여러 세대의 공동 수정 기록을 복원한다. 대본 원문은 W08a·W08b·W08c 한 곳씩에서 관리한다.

통합 기준은 [설계 정리본 v2.2](../설계-정리본-v2.2.md), 동기화 원문은 Notion [06 이야기·인물](https://app.notion.com/p/3e4428b239a081ea8fbfe601a96b1438)과 [대본② 인물·장면·신문](https://app.notion.com/p/3e4428b239a081eba8ffcb4c2415375b)이다. D1~D8은 기존 결정 기록이며 새 D9는 만들지 않는다. [사실]은 확인된 규칙, [추천]은 적용 설계, [추정]은 검증 전 수치다. 날짜·장면 길이·빈도는 시작값이며 달력만으로 실제 사건을 만들지 않는다.

[추천] 공개·수락·납품·사용·보상·기록을 다른 상태로 관리한다. 날짜는 최소 소개일이며 미완료 사건을 완료 대사로 먼저 보여 주지 않는다.

### 2.1 실제 사용과 다음 부탁

새 대사는 기존 완료 대사의 대체본이다. 장면을 덧붙여 집필량·플레이시간을 부풀리지 않는다.

| 사용 장면 | 손님의 실제 작업 | 다음 부탁의 한 가지 변화·판단 |
|---|---|---|
| M01 에다 | 납품한 물건 조명으로 짐을 밝히고 양손으로 수레를 잡음 | 완료3~5일 뒤 오래 활자를 배웠으면 구간180초로 변경. 잠깐60초 부족·오래360초 적합 |
| M04 보린 | 접착이 버티는 동안 나사를 조임. 영구 고정은 나사가 담당 | 얇은 받침에12초 고정. 오래24초 판은 재사용 가능 |
| A16 카엘 | 자기 자리를 먼저 설명하고 건너편 도구를 밝혀 진입 전 점검 | 거리가3m로 바뀌어도90초 조건 유지. 멀리120초 재사용 가능·잠깐60초 부족 |

10~25초는 장면 편성 시작값이며 효과의 지속시간이 아니다. 고객 재고의 실제 문장·버전 한 장을 한 번 쓰고 공방 재고를 다시 빼지 않는다. 장면이 끝나도 효과는 원래 시간대로 남는다. 강제 단체 카메라는 없고 장면을 못 본 사람에게 개인 목격을 주지 않는다. 재사용으로도 통과하는 판을 일부러 실패 처리하지 않는다.

## 3. 잔향과 결말

| 항목 | 기준 |

| 잔향14 | 새 룬12 + 복습 E13·E14, 방11개 재사용·필수 위치 고정. 새 룬은 의미 추정→해당 수습→탁본3초로 지식 안전 기록→귀환 후 활자. 복습은 이미 아는 문장 비교 |

| 공동 발견 | 사건 때 던전에 참여 중인 사람의 공동 발견과 직접 해독자를 구분. 먼저 귀환자는 공동 도감만 열람 |
| 마지막 여백 | 실제 확인한 작업 조건 한 줄을 파티 인장 옆에 남김. 준비된 허구 사건을 플레이 사실처럼 넣지 않음 |
| 엔딩 뒤 | 기존 시험·분실물·도안·인물 활동 중 미완료 항목을 보여 줌. 결말 이후 새 무한 성장 없음 |

E08은 떼어 낸 받침을 작업대 아래 세워 지지, E10은 공급 중단·아는 당김/손 회수 뒤 받침 홈에 손으로 놓기, E14는 눈앞 막 제거 뒤 가루 길목을 처리해 읽는 면을 확보한다. 배우려는 벽·세게 룬을 먼저 쓰게 하지 않으며 E14는 새 룬이 아닌 복습이다. 상세 복구·탁본 조건은 [W05](W05-공간-잔향.md)에 둔다.

마지막 줄은 A20의 접착 중 나사 조임, E10의 회수 뒤 손 놓기, E14의 실제 판독처럼 확인된 조건에서 고른다. 시험하지 않은 예시는 “옛 기록의 메모”이며 우리 확인란에 넣지 않는다. 보린 스승의 드라이버가 없으면 공방의 보통 드라이버로 결말을 진행한다.

### 3.1 후기·신문·축제의 사실 경계

[추천] 사고 없는 주도 실제 납품·무료 시험·고객 작업·마을 변화로 쓴다. 아무 기록이 없으면 중립 공지를 쓰고 허구 사고나 화제 보너스를 만들지 않는다. 집계 없는100건·100가설·고정43회 사건은 폐기하며 실제 집계가 있을 때만 그 숫자를 사용한다. 수리·행사·복원이 미완료면 완료 기사 대신 현재 진행 상태를 쓴다.

화제는 정상 작업의 문장·대상·이전 상태·결과와 수습/새 용도가 연결된 실제 기록에서 고른다. 반복 동료 구속·전원 시야 방해·피해 인원 가산을 보상하지 않는다. 정확한 문장 틀은 [W08c](W08c-대본-남은글.md), 기사와 인물 반응은 [W08b](W08b-대본-인물-장면-신문.md) 한 곳씩에서 관리한다.

축제는15일이 최초 가능일이다. 골목 수리·오래 활자·행사 준비가 끝난 선택 저녁에 최초1회 개최하고, 미루기·엔딩 뒤 참가도 가능하다. 미개최 기사·사진을 만들지 않으며 기록 재열람으로 소비·보상을 반복하지 않는다. 공연은 반응 다양성·작업 완료·손 수습·정리를 심사한다. 실제 설치 등불 기부와 일시 조명 마법을 구분한다. 상세는 [W06](W06-10시간-채우기.md)을 따른다.

## 4. 집필과 검수

기존 대본 약670문장은 [추정] 최초 편성 규모이며 완성된 게임 텍스트 실측값이 아니다. v2.2의 조건 재주문·짧은 사용·수첩/엔딩 문구는 기존 대사·인물·장면을 대체·재사용한 양과 별도 구현량을 나눠 다시 센다. 새 지역·새 인물·새 분기 엔딩을 추가하지 않는다. 집필·교정·영어·게임 안 줄바꿈 검수는 제작 공수에 포함하며, 동일 문장을 이 문서와 대본 양쪽에서 관리하지 않는다.

검수 기준: 각 납품의 필수 작업과 대안을 설명 가능, 사건 기록 없는 기사는 실제 사건처럼 발행하지 않음, E08/E10/E14 복구 결과와 대사 일치, M16/A14의 김은 송풍기·가루는 여과막·고정은 접착으로 처리. 열량·물기·접착 임계값·반발 속도·가루 포집량은 아직 미결이며 대사로 검증 완료를 선언하지 않는다.

v2.2 동기화에서 네 막·인물9명·의뢰32건을 보존하고 실제 선행·사용/재주문·복습·기록·축제 보류를 현재 Notion과 맞췄다. 시간·물리·집필 총량의 실측이 남아 있으며 이 동기화는 플레이 검증이나 새 팀장 결정이 아니다.
