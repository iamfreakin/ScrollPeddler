# T2. 조작·화면·온보딩·접근성

2026-10-07 · 설계 v2.2 동기화 · 설계 개정 2026-10-06 · D8 유지

**명령을 입력한 결과와 실패 이유를 같은 화면에서 읽게 한다.** [사실] 기존 입력·접근성 규칙을 유지한다. [추천·v2.2 적용] 최신 Notion의 공정·의뢰·접속·저장 표시를 동기화했다. 아래 시간은 검증 전 시작값이다.

현재 기준은 [설계 정리본 v2.2](../설계-정리본-v2.2.md)이다. 상세 입력·화면은 [W11](W11-화면설계.md), 첫날은 [W01](W01-플레이어와-첫날.md), 소리·음성은 [W03](W03-음성채팅-소리-음악.md), 의뢰의 필수·선택 작업은 [W14](W14-의뢰판정-납품규격.md)를 따른다.

## 1. 입력과 발동

| 단계 | 입력·판정 |
|---|---|
| 집기·작업 | 세계 물건은 들고 건네며, 물건/설비와 상호작용. 키는 W11 조작표 한 곳에서 관리, 재지정 지원 |
| 조립 | 동사·대상·수식 활자3개. 기본 결과42개에 수식 하나를 같은 계산으로 적용. 현재 문장·먹 비용·봉인·물 취약 표시. 이상한 문장도 제작 가능, 수식 두 개 중첩은 문법에 없음 |
| 시험·저장 | 시험 후 판 저장·묶음 인쇄. 새 판을 강요하지 않고 기존 판의 조건 적합성을 비교. 완료한 장·미완료 장·예약 재료를 구분하며 취소는 미완료 예약만 해제 |
| 찢기 | 양쪽 클릭 동시 기본, 한 손 입력 대체·재지정 필수. 승인 순간1장 소비·대상 잠금 |
| 준비·발동 | 지연 시간을 표시. 단일 생물/물건/표면은 찢을 때 잠금, 주변 중심은 발동 시 시전자 위치, 넓게 대상 목록은 발동 때 계산 |
| 당김 | 찢기 승인 위치가 고정 기준점. 지연 뒤 사거리도 그 자리에서 측정. 선이 시전자를 따라가지 않음 |
| 무효 결과 | 문장 허용과 대상 부재를 구별. 이미 소비한 문장이 효과 없이 끝나면 잠금/사거리/접촉 조건을 원인 카드에 표시 |

## 2. 정보 화면

| 화면 | 보여 줄 판단 |
|---|---|
| 주문지·판 | 목적·대상·최소 지속·시작 거리·피해야 할 결과·수량·가격·봉인 필요. 대표 도안 견적과 대안 문장의 실제 장수/먹 소비를 구분. 재주문의 변경 조건을 이전 판과 비교, 수락한 계약 총액은 인원 변화나 대안으로 다시 계산하지 않음 |
| 출정 준비 | 주문용·탐험용·여유 재고·부족. 계획상 남겨두기와 실제 인쇄 예약을 서로 다른 표시로 |
| 작업 요청 핑 | 1일차부터 물품명·수량·위치. 최대3요청, 발신2초 간격. 음성과 게임 판정 분리 |
| 던전 | 물때 단계·취약 물품·현재 문장·버팀·동료 위치. 미봉인은 공방 미포장품과 현장 급조품 모두 표시. 음성 없이도 경고 읽기 |
| 원인 카드 | 문장→이전 상태→반응→결과→행동자. 젖음→김→남은 열→접착 해제를 실제 순서로 |
| 작업 수첩 | 개인 도안·기여·공동 참여 발견·직접 해독. 공동 도감 열람과 개인 목격을 혼동하지 않음 |
| 정산·신문 | 실제 소비·파손·판매·고객 결과. 확인한 세계 사건/고객 사용과 조건에서 추정한 후기는 별도 표기 |
| 엔딩 뒤 | 미완료 기존 시험·분실물·도안·인물 활동 안내. 새 반복 숙제를 만들지 않음 |
| 재접속 | 자리 예약90초와 원정 참여 종료를 별도 표시. 빈자리/온라인4인·원정 진행/종료에 맞는 안내, 주문량·대금 고정 |
| 저장 | 저장 요청·저장 중·검증한 성공·실패를 구분. 성공 전 성공 문구/효과음 없음. 실패 공동 중단·마지막 정상 시점·재시도·저장되지 못한 구간 표시 |

## 3. 첫날 30분

| 구간 | 경험 |
|---|---|
| 공방14분 | 선택 프롤로그2분은 별도. 각자 문장 조립·찢기·한 룬 바꾸기. 판틀2개로 병렬 시험. 공동 M01 묶음 인쇄2·3·4·5장 |
| 탐험최대12분 | 재료 핑·물 취약·맨손 수습·함께 출발/자유 귀환 학습 |
| 마감4분 | 에다가 납품 문장을 사용하는 짧은 장면·정산. 서면 후기는 다음날 |

개인에게 자원을 복제하지 않는다. 숙련자는 먼저 시험해도 다른 사람의 입력을 대신하지 않는다. 프롤로그를 포함한 첫 진입은 약32분이며 본편 첫날은30분이다. 공개 데모는 별도 편집으로 약36분(프롤로그 포함38분), 시작7룬에 탐험 중 넓게1룬을 더한다. 넓게를 못 얻어도 시작7룬으로 M01·고객 사용·마감을 완료할 수 있다. 본편 시작6룬과 스파이크1 정식7룬을 바꾸지 않는다. 내부 2일 비교판55~57분은 공개 데모 기준으로 사용하지 않는다.

## 4. 접근성과 소리

| 항목 | 기준 |
|---|---|
| 색 | 색+룬 기호+문장 글자. 보호·봉인·먹막·가루·김은 형태/표시로도 구별 |
| 입력 | 한 손 찢기·누름/유지 전환·키 재지정·감도 조절 |
| 화면 | UI 확대·자막·카메라 흔들림 조절. 고객 장면은 주변에서 보며 강제 단체 시점 없음 |
| 소리 | 경고 자막/표시, 근처 음성+개별 음소거. 음성·핑을 생물 청각·룬 인식에 쓰지 않음. 저장 성공 소리는 검증한 성공 뒤만 재생하며 요청/실패 소리를 성공과 구별 |
| 동시 진행 | 공방/던전 화면·시간 분리. 먼저 귀환해도 동료 플레이를 강제 관전하지 않음 |

## 5. 검증

스파이크2에서는 클릭 시간과 판단·왕복·설비 대기를 따로 잰다. 도안 조립30초 같은 T4 시간은 선택·설명·이동이 섞인 작업 예산이며 클릭 애니메이션 길이가 아니다. 첫날1·2·4인에서 각자 문장 변경, 도움 없는 주문 완료, 핑만으로 전달, 소리 없이 위험 인지를 확인한다. 정식 회차와 개발자 유도·학습 회차는 분리한다.

튜토리얼 안내를 건너뛰어도 해금·주문 완료·재료를 추가 지급하지 않는다.

## 6. 입력 우선순위와 취소

| 항목 | 기준 |
|---|---|
| 우선순위 | 진행 중 손 작업→열린 메뉴→든 도구→현장 행동. 작업 취소/메뉴 닫기를 찢기·던지기로 이어 실행하지 않음 |
| 자기 막 선택 | 발·등을 조준하지 않고 자기 몸에 붙은 막을 선택·제거 가능 |
| 손 해제 중단 | 버튼 놓기/취소·거리 이탈·대상 소멸 때 중단. 잠깐 시선 이탈은 유지, 재시도는 처음부터 |
| 해제 시간 | 보통2초, 강한 접착만3초. 같은 종류 재도장으로 진행 시간을 초기화하지 않음 |
| 현장 급조 | 6초에 원재료 갈기 포함. 완료 전 취소는 소비/완제품 없음, 이미 발생한 소음·시간은 유지 |
| 현장 도안 | 저장한 완성 문장2개만 사용. 현장 문장 편집/교체·봉인 없음, 완성칸 먼저 확보 |

키 배치는 W11 최신 표를 따른다. 이전 원문의 옛 단축키를 이 의미 규칙에 다시 붙이지 않는다.

## 7. 공통 판정과 화면의 경계

[추천·v2.2 적용] 몸 효과는 몸·옷 외곽에 표시하며 가방 속 재고 전체에 복사하지 않는다. 표면 접착·탄성·열은 실제 접촉으로 작용하고, 빛·먹막·여과는 밟은 몸에 새 도장으로 복사하지 않는다. 걸러라는 부유 가루만 처리하고 김은 송풍으로 수습한다. 가열 원인 카드는 S6 물기 소모·김 → 남은 열 → S2 접착 해제 판단을 보여 준다. 당김은 찢기 기준점·막힘 이유를 표시하며 준비 중 움직인 나도 그 기준점으로 당겨질 수 있다.

저장 실패는 공방·던전을 같이 멈추는 T1 정책을 표시한다. 새 거래는 보류/거부하며 소비·성공을 먼저 보여 주지 않는다. 이미 메모리에 확정한 거래를 취소된 것처럼 표시하지 않는다. 검증한 공동 저장 뒤 재개하고 개인 기록을 전달한다. 이 문서는 화면·소리의 구분을 정하며, 열/물기 단위·해제 열량·힘 상한 같은 미결 수치는 통합본의 검증 목록에 남긴다.
