## 1. 1인칭 조작

### 1.1 공통 입력과 상태 구분

마우스로 정밀하게 끌거나 패드로 작은 커서를 쫓게 하지 않는다. 도안판에서는 칸과 룬 사이로 선택 표시가 붙고, 현장에서는 시선과 조준점으로 대상을 고른다. 아래는 기본 배치안이며 모든 행동을 다른 키·버튼으로 바꿀 수 있게 한다. 패드는 Xbox 표기를 예시로 썼으며 실제 연결 장치의 버튼 이름을 표시한다.

| 행동 | 마우스·키보드 | 게임패드 | 공통 동작 |
|---|---|---|---|
| 이동 / 시선 | WASD / 마우스 | 왼쪽 / 오른쪽 스틱 | 작업 화면을 닫으면 즉시 이동·시선 조작으로 돌아옴 |
| 살펴보기·집기·시설 열기 | E | X | 현재 조준한 대상에 표시된 행동 하나 실행 |
| 손에 들 물건·스크롤 선택 | Q로 선택판 열기 | LB로 선택판 열기 | 선택판은 한 번 눌러 열고, 가리키거나 방향키로 고른 뒤 확인. 휠 순환도 선택 가능 |
| 선택판·장부 확인 / 뒤로 | 왼쪽 클릭 또는 Enter / Esc | A / B | 입력 한 번으로 한 단계 진행. 화면을 닫은 확인 입력이 찢기로 이어지지 않음 |
| 정밀 조준 | 오른쪽 버튼 | LT | 누르고 있기 또는 켜기·끄기 선택. 조준 버튼 없이도 가운데 조준점으로 사용 가능 |
| 스크롤 찢기 / 든 물건 던지기 | 왼쪽 버튼 | RT | 손에 든 종류에 맞는 행동명을 항상 표시. 한 번 누르면 한 번 실행하며 계속 눌러도 연속 소비하지 않음 |
| 물건 내려놓기 / 스크롤 다시 넣기 | G | B | 현장 상태의 동작. 선택판이 열려 있으면 B는 뒤로만 작동 |
| 내 몸의 상태·도장 보기 | F | Y | 자기 접착·먹막 등 선택. 등에 붙은 도장도 이 목록에서 접근 |
| 휴대 도안판 | C | 방향키 위 | 두 도안 확인·한 장 급조 진입 |
| 가방 | Tab | View | 보유품·봉인·물 취약성 확인 |
| 최근 원인 기록 | R | 방향키 아래 | 마지막 관련 사건의 원인 카드 열기 |
| 위치 핑 / 신호판 | 휠 버튼 짧게 / 길게 | RB 짧게 / 길게 | ‘여기’ 핑 또는 신호 선택. 접근성 설정에서는 신호판을 한 번 눌러 여는 방식 제공 |
| 손 작업 취소 | Esc | B | 급조·전환식 손 해제·채집 진행 중에는 작업만 먼저 취소. 같은 입력으로 설정 열기·물건 내려놓기를 함께 실행하지 않음 |
| 설정 | 다른 화면·손 작업이 없을 때 Esc | Menu | 설정 진입 시 진행 중 손 작업은 먼저 취소하고 결과 표시. 협동 세계가 개인 설정 화면으로 멈춘다고 안내하지 않음 |

입력 우선순위는 **진행 중 손 작업 → 열린 선택판 → 손에 든 도구 → 현장 상호작용**이다. 급조 중에는 찢기·던지기로 입력이 새지 않는다. 손 작업을 취소한 입력은 뒤의 행동으로 넘기지 않으며, 다음 입력부터 다시 선택판·현장 조작을 받는다. 재지정한 키와 ‘누르기/유지’ 방식은 모든 안내에 즉시 반영한다.

### 1.2 도안판에서 문장 조립

| 순서 | 손으로 하는 모습 | 마우스·키보드 | 게임패드 | 표시·오류 처리 |
|---|---|---|---|---|
| 판 펼치기 | 도안판 가까이에서 빈 종이와 세 종류 룬 받침을 봄 | E | X | 주문에서 고정해 둔 필수 효과·주의점만 판 옆에 표시 |
| 룬 집기 | 손이 받침에서 룬 조각을 집음 | 룬을 가리켜 클릭 | 방향키로 종류·룬을 이동하고 A | 룬 이름·종류·짧은 뜻. 배우지 않은 룬은 잠금 이유 표시 |
| 칸에 놓기 | 집은 조각을 종이 위의 해당 종류 칸에 맞춰 놓음 | 맞는 칸을 클릭 | 해당 칸으로 선택 표시가 이동, A로 놓기 | 칸 근처에 붙는 보조. 드래그·손 회전·타이밍 맞추기 불필요 |
| 바꾸기 | 놓인 조각을 다시 집어 받침으로 돌려놓거나 다른 조각과 교체 | 칸 클릭 후 교체 | 칸 선택 후 A, 새 룬 선택 | 종류가 다른 칸에는 놓지 않지만, 의미가 엉뚱한 완성 문장은 막지 않음 |
| 읽기·시험 | 세 조각을 종이에 눌러 문장 한 줄을 확인하고 시험용 종이를 집음 | 판의 시험 행동 선택 | 같은 행동을 A로 선택 | 문장·대상·범위·준비 시간·지속·소모 재료를 미리 확인 |
| 저장·출력 | 이름표를 붙여 도안함에 넣고 인쇄 작업으로 연결 | 저장/인쇄 행동 | 같은 행동을 A로 선택 | 이름은 문장으로 자동 제안. 키보드 입력·패드 문자 입력은 이름을 바꿀 때만 필요 |

| 속도·협동 기준 | 설계안 |
|---|---|
| 손맛 | 집기·내려놓기·눌러 찍는 짧은 손 연출과 접촉음으로 전달. 입력 사이에 강제 관람 시간을 붙이지 않고 연출 중 다음 선택을 받을 수 있게 함 |
| 초보와 숙련자 | 처음에는 세 칸 전체를 읽고, 이후에는 저장 도안을 불러와 달라질 칸만 교체. 반복 생산마다 다시 세 룬을 끼우지 않음 |
| 시간 목표 | [추정] 룬 의미를 아는 사람이 새 문장을 놓는 데 10~15초, 저장 도안 불러오기와 출력 진입은 5초 안팎. 읽기·실험·실제 생산 시간은 별도 측정 |
| 비용 발생점 | 집기·조립·도안 저장에는 제작 재료를 소비하지 않음. 실제 인쇄의 예약·완성분 소비는 v1.2 §4.6을 따름 |
| 시험판 | 판매·반출 불가 시험품으로 같은 사용 조작을 경험. 시험 종료 때 시험 상태를 초기화하고 재료·재고 이익을 만들지 않음 |
| 공동 편집 | ‘누가 편집 중인지’와 복사본 열기를 제공. 인쇄 중인 묶음은 시작 당시 문장·도안 버전을 계속 표시. 남의 수정으로 이미 시작한 제품이 바뀌지 않음 |

### 1.3 스크롤 꺼내기 → 대상 조준 → 찢기

| 단계 | 사용자의 행동 | 화면·손 연출 | 소비와 대상 |
|---|---|---|---|
| 꺼내기 | 장비 선택판에서 보유 스크롤 선택 | 손의 종이에 문장, 남은 장수, 봉인/미봉인. 상품명보다 실제 세 룬을 우선 읽음 | 아직 소비 없음. 같은 이름이라도 문장·봉인이 다르면 구분 |
| 조준 | 시선으로 해당 대상 룬의 후보 선택 | 후보는 점선 윤곽·이름, 예상 범위는 표면 표시. 사거리 밖·대상 없음·고정체 등 이유를 글자로 표시 | 후보만 예고. 사용 중 ‘너’를 ‘물건’으로 바꾸는 기능 없음 |
| 찢기 | 찢기 입력 한 번 | 두 손이 종이를 찢고 선택 표식이 잠금 표시로 바뀜 | [사실] 정상 스크롤 한 장 소비, 대상 잠금. 대상이 없어도 사용 자체를 막지 않음 |
| 발동 준비 | 조준을 바꾸거나 움직여도 새 대상을 고르지 않음 | 잠근 대상의 이름과 ‘발동까지’ 표시가 남음 | [추천·P1] 수식별 준비 시간을 찢은 뒤의 대기 시간으로 배치. 찢기 전과 후에 두 번 더하지 않음 |
| 발동·유지 | 실제 결과를 확인하고 다른 행동으로 이어감 | 준비 표시를 끝내고 도장에 ‘효과 남음’ 표시 시작 | [사실] 기존 속성과 반응. 소멸·사거리 이탈 때 자동 재선택 없음. 소비를 되돌리지 않고 판정된 원인 표시 |

꺼내기·조준 단계의 다시 넣기는 소비 없이 끝난다. 찢은 뒤 화면을 닫거나 다른 물건을 골라도 이미 예약된 발동과 소비를 취소하지 않는다. 보유하지 않은 아이템·중복 요청의 거부는 ‘동작 확인 실패’로 구분하고 마법 실패처럼 꾸미지 않는다.

| 대상 룬 | 무엇을 고르는가·범위 | 조준 중 보여 줄 것 | 선택 확인 소리의 구분안 |
|---|---|---|---|
| 물건 | 비생물 소품 하나. 넓게는 중심 주위 2m의 노출 소품 | 물건 윤곽·이름, 고정 도구는 ‘고정됨’. 고정됨은 모든 마법의 사용 불가를 뜻하지 않음 | 짧은 물체 접촉음 + 선택 낭독 ‘물건’ |
| 바닥 | 조준 바닥 반경 0.75m, 넓게는 연결 표면 반경 1.5m | 실제 연결 바닥의 범위. ‘닿는 대상에 작용’ 표시, 생물 몸에 직접 찍는 것처럼 보이지 않게 함 | 낮은 접촉음 + ‘바닥’ |
| 벽 | 조준 벽 반경 0.75m, 넓게는 연결 벽면 반경 1.5m | 벽면에 붙는 범위와 벽의 방향. 반대편 벽 너머로 표시하지 않음 | 마른 두드림 + ‘벽’ |
| 나 | 시전자. 넓게는 주위 2m의 생물 | ‘나’와 자기 몸 상태 표시. 넓게에서는 동료·몬스터도 포함 가능함을 표시 | 몸 가까운 짧은 음 + ‘나’ |
| 너 | 조준한 생물 하나. 넓게는 그 생물 주위 2m의 생물 | ‘너: 동료 [이름]’ 또는 ‘너: [생물명]’. 진영별 안전 제외 없음 | 선택 방향의 짧은 음 + ‘너, [이름]’ |
| 주변 | 시전 위치 반경 2m의 노출 생물·소품·표면, 넓게는 4m | ‘주변: 현재 예상 범위’와 보이는 포함 후보. 이동 오라로 그리지 않음 | 주위를 알리는 짧은 음 + ‘주변’ |

범위·사거리는 [사실] v1.2 §4.3~4.4의 시작값이다. 기본 사거리 4m, 멀리는 12m이며 두꺼운 벽은 적용을 막는다. 장식물까지 전부 조작 가능하다고 표시하지 않는다. **주변·넓게의 구성원 확정 시점과 당김 기준점 시점은 P2가 해결되기 전 확정 사양으로 구현하지 않는다.** 표의 범위는 조준 당시 예고이며 최종 결과를 보장하지 않는다.

| 0~6분 | 낮은 물때·남은 시간. 환경 눈금·관 소리는 진행감을 주고 상시 큰 경고는 하지 않음 |

| 9~12분 | ‘철수 경고’와 남은 시간. ‘파손 예상’ 요약에서 손·가방·내려놓은 미반출 확보품을 위치별로 펼침. 내 목록과 공동 목록의 중복을 구분 |
| 12분 | 미귀환자 입구 복귀. 취약 원재료·미봉인품 파손과 내구 재료·봉인품 보존을 나란히 표시. 먼저 반출한 물품과 미채집 자원은 이 목록에 넣지 않음 |

출구 안내는 표지·알고 있는 입구 방향·동료의 수동 핑을 읽게 한다. ‘돌아오는 점선’을 자동 경로 추적 기능으로 바꾸지 않는다. 중간재의 물 취약성 승계는 v1.2 §5.4의 추천 상태를 그대로 두고, 확정된 품목 데이터에 따라 표시한다.

### 2.3 원인 표시: 문장 → 이전 상태 → 반응 → 결과

| 정보 층 | 언제·어디에 | 내용 |
|---|---|---|
| 현장 표식 | 조준한 대상·도장·결합부 | 동사, 실제 대상, 현재 상태, 남은 시간. 사고 직후에는 수습할 부위를 먼저 강조 |
| 짧은 원인 알림 | 내가 사용했거나 직접 영향을 받은 사건 | ‘[사용자]의 [문장] + [이전 상태] → [핵심 결과]’. 화면에는 최신 관련 사건부터 표시 |
| 원인 카드 | 최근 원인 키 또는 대상 살펴보기 | **시각·사용자·문장·대상 → 이전 상태 → 반응 순서 → 결과 → 현재 가능한 수습 행동** |
| 하루 기록 | 공방 시험 기록·정산에서 펼침 | 같은 사건 번호로 연결. 제조자·사용자·먼저 상태를 만든 사람·수습한 사람을 구분 |

| 규칙 | 구체적인 표시 방법 |
|---|---|
| 관측값과 예상 구분 | 찢기 전은 ‘예상’, 반응이 확정된 뒤는 ‘발생’. 보지 못한 상태·기록 누락은 ‘원인 일부 확인 안 됨’이며 그럴듯한 설명을 채워 넣지 않음 |
| 선행 원인 추적 | 이전 접착을 누가 만들었는지 등 기록이 있을 때만 연결. 제조자가 아닌 사용자가 찢었다면 두 이름을 바꾸어 쓰지 않음 |
| 연쇄 사고 | 한 원인의 김→시야 방해→이동 사고는 연결된 하나의 사건 묶음으로 펼침. 서로 다른 사건은 시간순으로 구분 |
| 실패도 설명 | 대상 없음, 고정체, 사거리 이탈, 열 부족 등 실제 판정 이유. ‘실패!’만 보이거나 임의로 확률 탓을 하지 않음 |
| 남은 문제 표시 | 수습 후에도 남은 열·먹막·다른 접착이 있으면 표시. ‘해결됨’으로 모두 지우지 않음 |
| 사람 탓으로 단정하지 않기 | ‘[이름]이 망침’ 대신 행동·상태·결과를 기술. 환경에서 시작된 상태는 환경으로, 출처 불명은 불명으로 표시 |

| 예시 사건 [추천·문구 예시] | 카드에서 읽는 내용 |
|---|---|
| 젖은 접착 바닥에 가열 | 문장: 민의 ‘달궈라+바닥+잠깐’ → 이전: 물기, 준이 만든 접착막 → 반응: 물기가 열을 먼저 소모해 김 발생, 접착을 풀 열 부족 → 결과: 김·접착 유지. 수습: 손으로 떼기 또는 상태를 보고 다른 조치 |
| 고정벽을 당김 | 문장: ‘당겨라+벽+세게’ → 이전: 고정벽 → 반응: 힘이 걸리지만 고정 상태 → 결과: 벽 이동 없음, 반동·큰 소음. 벽 파괴·시전자 끌어오기 효과를 새로 설명하지 않음 |
| 접착을 손으로 뗌 | 행동: [사용자]가 [대상]의 접착막 제거 → 이전: 해당 막과 결합 → 반응: 막·결합 해제 → 결과: 그 결합에서 풀림. 이미 옮겨진 물건 위치는 유지 |

위 예시는 기존 반응을 설명하는 표시 예시이며 특정 사건이 반드시 발생하게 만드는 의뢰·레벨 설계가 아니다. 기록 정보는 v1.2 §11.6의 사건 기록을 쓰고, 보존 기간·접속 복구는 T1에게 넘긴다.

### 2.4 말하지 않고 알리는 핑·신호

| 신호 | 전달 정보 | 규칙 |
|---|---|---|
| 여기 | 보낸 사람·가리킨 위치/대상 | 시야에서 고른 지점 표시. 숨은 자원을 자동 탐색하지 않음 |
| 위험 | 보낸 사람·위치·알고 있는 위험 상태 | ‘뜨거움’·‘접착’ 등 확인된 상태만 이름 표시. 불명확하면 ‘위험 주의’ |
| 도와줘 | 보낸 사람·현재 위치·이동 제한 등 상태 | 말하지 않아도 도움 대상과 이유가 보임 |
| 가져가 | 보낸 사람·놓인 물품명 | 물품을 지정할 뿐 강제 소유권 이전·공유 정책은 바꾸지 않음 |
| 돌아가자 | 보낸 사람·남은 물때 | 제안 신호이며 동료를 강제 귀환시키지 않음 |
| 준비됐어 | 보낸 사람·출발 준비 상태 | 실제 공동 출발 승인 방식은 T1이 정함 |

동일 발신자의 같은 핑은 갱신해 쌓이지 않게 하고 소리도 연속 재생을 줄인다. 완료·취소하거나 대상이 사라지면 이유와 함께 정리한다. 신호는 글자·발신자 이름·방향·선택적 소리로 전달하며 음성 대화가 필수인 절차를 만들지 않는다.

### 2.5 화면을 덮는 정도와 우선순위

| 상황 | 기본 정보판 점유 목표 [추천·시작값] | 운영 기준 |
|---|---:|---|
| 이동·탐색 | 화면의 15% 이내 | 가운데는 조준·현장 관찰에 사용. 문장·물때·긴급 상태만 간결하게 표시 |
| 사고·철수 경고 | 25% 이내 | 원인 요약과 수습 입력 먼저. 관련 없는 제작 완료·후기 알림은 보관 |
| 가방·원인 카드 | 40% 이내 | 세계와 물때·동료 도움 신호가 계속 보임. 닫기 한 번으로 복귀 |
| 도안판·장부 집중 | 60% 이내 | 실제 판·종이를 바라보는 구도. 긴 글은 페이지·펼치기로 제공 |
| 큰 글씨·확대 읽기 | 위 비율 예외 허용 | 읽을 수 있는 크기를 우선. 추가 열은 접되 핵심 경고·닫기 입력을 가리지 않음 |

점유율은 배경판·텍스트 영역의 겹침을 한 번만 세며 팔·도구·세계 소품은 제외한다. 다만 손·도구까지 포함해 실제 대상이 가려지는지도 별도로 검사한다. 이 비율을 맞추려고 글자를 줄이지 않는다.

알림 우선순위는 **즉시 수습·철수 → 내 사용 결과·동료 도움 → 제작 완료·일반 기록**이다. 핵심 자막과 원인 카드는 겹치지 않게 배치하며, 동시에 온 낮은 우선순위 정보는 기록에서 다시 읽는다. 선택판을 열어도 협동 시간이 정지한다고 전제하지 않는다.

## 3. 온보딩 — 1일차 30분

### 3.1 시간·학습 순서

**[추천] 출발 전 공방 14분 + 던전 최대 12분 + 귀환 정리 4분.** v1.2 기본일의 공방 준비 8분에 학습 6분을 더하는 안이다. 던전 물때를 늘리지 않으며, 30분은 목표 경과다. 일찍 익히거나 먼저 귀환하면 즉시 다음 행동으로 이어간다. 학습이 늦어지면 공방에서 더 연습하되 탐험을 서둘러 강제하지 않는다.

시작 룬은 T5·팀장이 확정해야 한다. 아래 예시는 v1.2의 기초 주문 예시인 ‘빛나라+물건+잠깐’, ‘붙어라+물건+잠깐’을 사용할 수 있다는 **조건부 추천**이다. 두 문장에 필요한 룬을 T2에서 지급 확정하지 않는다. 실제 손님·대사·의뢰 보상은 T6가 작성한다.

| 경과 | 배우는 것 | 주문·상황을 통한 행동 | 확인할 이해 |
|---|---|---|---|
| 0~2분 | 보기·이동·집기·내려놓기 | 공방 물품 하나를 다뤄 입력 확인. 시작 전 선택한 글자·자막·입력 설정을 바로 바꿀 수 있게 함 | 가리킨 것에 어떤 행동이 가능한지 읽음 |
| 2~4분 | 주문의 조건 | 첫 손님의 기존 기초 주문에서 필요한 효과·대상을 찾아 장부에 고정 | 상품 이름보다 기능·대상을 읽음 |
| 4~8분 | 세 룬으로 문장 만들기 | 판의 받침에서 집어 세 칸에 놓고 완성 문장을 읽음 | 동사·대상·수식이 각각 무엇을 바꾸는지 말하거나 선택으로 보임 |
| 8~10분 | 꺼내기·조준·찢기·손 수습 | 시험판에서 물건에 사용. 접착 문장을 쓸 수 있으면 접촉 후 손으로 떼어 봄 | 찢으면 한 장 소비, 대상 잠금, 접착은 기다리지 않고 수습 가능 |
| 10~12분 | 저장·반복 출력·봉인 | 시험한 도안을 저장해 실제 생산·포장 행동 연결 | 도안 지식과 제품, 시험품과 판매품, 봉인 상태를 구분 |
| 12~14분 | 원정 준비 | 휴대 두 도안과 가방을 확인하고 준비 신호. 물 취약품·조기 귀환·재입장 제한을 출발 정보로 읽음 | 두 도안 각각 세 룬임을 확인. 오늘 귀환 뒤 재입장 불가를 앎 |
| 14~17분 | 채집·운반 | 기본 왕복이 가능한 구간에서 재료를 집고 가방 정보 확인 | 재료명·물 취약성·내려놓기를 이해 |
| 17~20분 | 현장 사용·핑 | 필요할 때 준비한 문장 사용, 동료/위치에 신호. 혼자는 위치 핑 확인 | 같은 문법이 공방과 던전에서 이어짐 |
| 20~23분 | 물때 상승·급조 선택 | 물때 6분 경과 뒤 변화 관찰. 휴대판에서 도안·재료·미봉인 확인. 급조가 필요하면 실행, 없으면 취소·닫기 | 급조는 준비한 문장 한 장이며 물때 보존 수단이 아님 |
| 23~26분 | 철수 판단·귀환 | 물때 9분 경고와 파손 예상 확인. 더 모을지 돌아갈지 판단 | 물때 종료 결과와 보존 대상 구분. 새 필수 마법 설명은 넣지 않음 |
| 26~28분 | 반출·분류 | 실제 확보품·사용품·보존/파손 결과를 정리 | 모든 가방을 잃는 규칙이 아님을 확인 |
| 28~30분 | 정산·후기·다음 준비 | 사용한 문장과 결과 한 건을 되짚고 다음 주문 정보를 읽음 | 장사와 현장 행동이 같은 하루의 결과임을 이해 |

| 안내 원칙 | 적용 |
|---|---|
| 창보다 행동 | 장부의 필수 조건, 판의 빈 칸, 조준 대상 이름처럼 지금 보는 물체에 짧게 안내. 긴 설명은 ‘자세히’로 열기 |
| 실패로 교육하되 강요하지 않기 | 시험판에서 원인과 수습을 경험. 실제 판매품 낭비·침수 손실·동료 방해를 튜토리얼 완료 조건으로 요구하지 않음 |
| 급조 실습이 불필요한 날 | 선택판에서 재료·결과를 확인하는 것으로 안내 완료 가능. 재료가 부족하면 공방 시험판에서 보충 연습하도록 남김 |
| 첫날에 모두 가르치지 않기 | 나·너·바닥·벽·주변, 오래·넓게·세게·멀리 등은 실제 확보·사용 시점에 짧은 현장 안내. 미해금 룬을 첫날 필수 과제로 넣지 않음 |
| 기록 재열람 | 주문·문장·최근 원인은 언제든 다시 읽기. 안내를 닫았다는 이유로 원리 확인 수단이 사라지지 않음 |
| 탐험 중 읽기 | 도움말이 공동 물때를 멈추거나 개인 시간만 늦추지 않음. 긴 학습은 출발 전과 귀환 후에 배치 |

### 3.2 혼자·2~4인·숙련자 섞임

| 구성 | 진행 차이 | 피할 병목 |
|---|---|---|
| 혼자 | 한 사람이 장부→조립→시험→출고 흐름을 짧게 경험. 묶음 인쇄 중 다음 준비 가능. 자기 접착이 생기면 손 해제 안내를 반드시 노출 | 첫날 접착 실습은 해당 문장 사용 가능 시 진행. 동료가 눌러야 하는 장치·양손 동시 입력을 교육 조건으로 두지 않음 |
| 2인 | 서로 장부 읽기·제작 준비를 나누되 각자 문장 조립·대상 선택을 연습할 기회 제공 | 한 명이 해냈다고 다른 사람의 안내를 자동 완료하지 않음 |
| 3~4인 | 시험·재료 확인·출고 준비를 병행. 개인 시험 접근 기회가 필요하다는 요구만 T3에 전달 | 같은 판 앞에서 전원이 한 장씩 차례대로 생산해야 하는 필수 절차 금지 |
| 숙련자+초보 | 안내는 개인별. 숙련자는 실제 주문·준비를 진행하고 초보는 필요한 시험을 함 | 숙련자의 설명 건너뛰기가 타인의 안내를 끄지 않음. 출발 조건은 T1 규칙을 따름 |

### 3.3 2회차 이후 건너뛰기

| 선택 | 줄이는 것 | 유지하는 것 |
|---|---|---|
| 처음부터 안내 | 첫 사용별 단계 도움 | 실제 세계 규칙·재료·룬 해금 |
| 핵심만 | 긴 설명과 반복 강조 | 처음 보는 기능의 짧은 도움, 상태·위험 정보 |
| 안내 건너뛰기 | 유도 문구·필수 연습 확인 | 실제 주문·제작·출발 행동. 물때·대상 없음·미봉인·손 해제·재입장 제한은 일반 정보로 계속 제공 |
| 다시 배우기 | 선택한 조작을 시험판에서 재안내 | 캠페인 진행·보상을 되돌리거나 추가 지급하지 않음 |

건너뛰기는 룬 해금·주문 완료·재료 지급의 지름길이 아니다. 개인 설정의 저장 위치와 게스트에게 이어지는 범위는 T1이 정한다. v1.2 스파이크의 조작 설명과 정식 측정 10분은 이 첫날 학습 일정과 별개다.

## 5. 사운드

### 5.1 룬을 읽는 소리

동사는 효과 성질을 구분하는 음색, 대상은 선택 위치와 이름, 수식은 짧은 리듬으로 구분한다. 대상음은 1.3, 수식음은 1.4 표를 사용한다. 전체 문장을 매번 세 종류 소리로 길게 재생하지 않고, 조립에서는 바꾼 룬만, 사용에서는 찢기→준비→동사 발동을 들려준다. 필요하면 선택 읽어주기로 실제 이름을 확인한다.

| 동사 | 구분할 음색·질감의 요구 | 소리와 동시에 읽는 뜻 |
|---|---|---|
| 빛나라 | 맑게 번지는 짧은 울림 | 발광 시작. 젖음으로 강화된 경우는 반응 알림으로 구분 |
| 붙어라 | 점성 있는 눌림 소리 | 접착막 생성. 실제 접촉 결합의 소리는 별도로 재생 |
| 당겨라 | 팽팽한 줄의 당김 소리 | 힘 작용. 고정체면 당김은 들리되 이동 성공음은 내지 않음 |
| 튕겨라 | 탄력 있는 짧은 울림 | 탄성 부여. 실제 반발음은 새 충돌이 발생할 때 |
| 달궈라 | 마찰성 열음 | 열 공급. 김 발생과 접착 해제 여부는 각 반응 소리로 분리 |
| 가려라 | 부드럽게 덮이는 낮은 소리 | 먹막 부착. 실제 게임 음량을 무조건 없애는 효과로 만들지 않음 |
| 걸러라 | 입자를 붙잡는 잔잔한 소리 | 여과막 생성·포집. 만능 정화·해독 성공음처럼 쓰지 않음 |

이 표는 음원 제작 요구이며 실제 음원·멜로디를 확정하지 않는다. 가까운 대상과 먼 대상을 음량만으로 구분하지 않고 방향·자막을 함께 제공한다.

### 5.2 반응 소리로 원인 알리기

| 사건 | 소리 순서와 강조 | 화면의 대응 |
|---|---|---|
| 젖음+등심 성질 | 물 접촉 뒤 발광 강화음 | ‘젖음 → 발광 강화’. 등심 성질 없는 생물에는 같은 강화음을 쓰지 않음 |
| 젖음+열+접착 | 가열음→김 소리→충분한 열이 남았을 때만 막 풀림 | 물기가 먼저 열을 쓴 순서. 접착이 남으면 ‘접착 유지’ |
| 먹물+빛 | 먹막 덮임 뒤 감광 | 광원이 사라진 것이 아닌 ‘먹막에 가려짐’ |
| 탄성+충돌 | 접촉 순간 반발음 | 새 충돌·반발 방향. 접착을 자동 해제한 것처럼 들리지 않게 함 |
| 바람+가루 | 바람 방향에 따른 흩어짐 | ‘가루 확산’과 발생 방향 |
| 손 제거 | 작업 진행음→완료 때 막/도장 떼짐 | 제거한 도장명·현재 이동 가능 여부 |
| 효과 종료 | 낮은 우선순위 종료음 | 효과 종료 표시. 옮겨진 물건까지 복구된다는 완료음 금지 |

반응음은 확인된 상태 변화에 한 번 붙인다. 연쇄는 순서를 들을 수 있게 하되 같은 상태를 매 순간 새 사건처럼 울리지 않는다. 물때 경고·내 이동 제한·동료 도움은 일반 작업음과 배경음보다 잘 들리게 조절한다. 소리를 줄이거나 합쳐도 원인 기록은 유지한다.

| 구분 | 규칙·정보 |
|---|---|
| 물때 단계음 | 2.2의 단계 전환과 같은 시점에 관 소리·경고 신호. 단계 이름·남은 시간·필요 시 파손 예상으로 대체 가능. 일정한 큰 경보를 계속 울리지 않음 |

| 소음 예고 | 세게 사용·급조 시작 전 행동 옆에 소음 주의. 아직 정하지 않은 감지 반경을 정확한 원으로 그리지 않음 |
| 표시 방향 | 중요 소리 자막은 들릴 수 있는 사건의 대략적 방향·종류를 제공. 소리보다 먼 곳·벽 너머 숨은 개체를 추가 탐지하지 않음 |
| UI 확인음·핑 | [추천] 장부 선택·룬 선택 확인·도움말 낭독·협동 핑은 전달용 소리로 분류해 몬스터 청각을 자극하지 않음. 실제 마법·급조·물리 행동 소음과 구분 |
| 개인 음량 | 배경음·효과음·대사·안내음·낭독을 조절. 음량 0·모노 출력·진동 끔이 세계 소음 판정을 바꾸지 않음 |

[사실] v1.2의 정식 스파이크는 설명 후 10분 측정과 원인 인터뷰를 진행한다. 오래 접착 24초와 강한 접착 손 해제는 그 뒤의 별도 점검이며, 이 문서의 첫날 안내를 이유로 정식 룬 목록·측정 시간·통과 기준을 바꾸지 않는다. 공방 전체·물때·캠페인 UI 검증은 후속 하루 시험판에서 한다.

## 7. 팀장에게 제안

기준 문서는 고치지 않았다. 아래는 통합 때 선택·명확화할 항목이며 승인 전 구현 확정값으로 넘기지 않는다.

|---|---|---|
| P1 | 준비 0.2~2초를 찢은 뒤 대기로 해석해도 되는가? v1.2에는 시간값과 찢을 때 잠금은 있으나 준비의 앞뒤 순서가 명확하지 않다. | **찢기→잠금·소비→수식별 준비→발동**을 추천. 별도 찢기 전 대기를 추가하지 않는다. 찢기 전 준비로 정하면 1.3~1.4의 취소·표시 순서를 함께 바꿔야 한다. |
