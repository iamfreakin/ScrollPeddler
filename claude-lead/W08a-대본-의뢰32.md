## 0. 읽는 법
**주문 판정의 기준:** [의뢰 판정·납품 규격](W14-의뢰판정-납품규격.md)에서32건의 목적·대상·최소 지속·거리·피할 결과·작업 장수를 관리합니다. 아래 대사·의뢰 ID는 보존하며 상품명이나 대표 룬 이름 하나로 합격을 고정하지 않습니다. 적합성이 같으면 다른 문장을 납품할 수 있고 여러 작업 주문은 각 작업을 모두 검사합니다.
- **접수**: 손님이 카운터(또는 게시판 의뢰지)에서 하는 말. 한 화면에 1\~3줄.
- **주문지**: 주문 줄에 걸리는 종이의 요약(필요 효과 / 주의 / 수량). UI가 자동으로 만들고, 여기 적은 건 문구 기준이다.
- **완료**: 일반 서면 후기는 납품 다음 아침. M01·M04·A16의 직접 사용은 적합 수량 납품 뒤 먼저 볼 수 있으며 상세 대사는 [대본 ② 인물·장면·신문](W08b-대본-인물-장면-신문.md)에서 관리합니다.
- `[ ]`는 게임이 채우는 칸. 완료 대사는 해당 결과가 확인됐을 때만 쓴다(W08c §1\~2).
- \[추천·D8\] 최신 공통 기준은 [12. 결정 기록·남은 일](../노션-원고/12-결정-기록-남은-일.md)와 로컬 `설계-정리본-v2.2.md`다. 사용자 채택·반영 승인. 수치·시간은 모두 검증 전 시작값이다.
- 아래 장수는 **1인 기본값**이다. 협동은 문장별 1·1.5·2·2.5배를 각각 올린다. 보상은 수락 전에 정한 기준 상품의 F와 주문당 B 1회로 고정하며 실제 대체 문장으로 추가금·환급을 만들지 않는다. 부재료 7건은 각 1개 파티 공용이다.
- 날짜는 최소 소개일이며 필요한 활자가 없으면 수락을 보류한다. 공개·수락·납품·사용·보상·기록은 다른 상태다. 조건이 부족하면 주문 카드에 이유를 표시하고 기존 잔향을 안내한다.
- 날짜는 등장일이며 당일 강제 완료일이 아니다. 분할 납품을 이어갈 수 있고 평판·B는 완료 때 한 번 준다. 일반 완료 후기는 다음 아침; M01·M04·A16은 아래 고객 사용 장면으로 먼저 결과를 볼 수 있다.
- 화면 밖 사용은 **납품 문장·주문 조건으로 판정한 결과**다. 실제 관찰 시간·전투·반동 거리를 만들어 내지 않는다. 아래 고정 사건 대사는 그 근거가 있을 때만 쓰고 없으면 조건 기반 대체 문구로 출력한다.

## 1. 1막 — 밤마다 젖는 골목 (1\~5일)

- **접수**

	- 에다: "골목 두 군데, 짧은 구간만 밝혀 줘. 짐을 밝히는 거야. 내 얼굴 말고."
	- 에다: "얼굴은 어젯밤 너희 덕분에 충분히 밝았거든."
- **주문지**: 필요 — 짐(물건)에 짧은 빛 / 주의 — 사람에게 쓰면 눈부심 / 1\~4인 2·3·4·5장
- **완료**: 에다: "양손은 비었어. 근데 배수로 쪽이 밤마다 젖어 있더라. 가는 길에 말인데, 한번 봐 줄래?"

### M02 · 2일 · 붙잡아 줄 손 하나 — 보린
- **접수**
	- 보린: "여기 맞댄 것만 잡아 줘. 버티는 동안 고치면 돼."
	- 보린: "요새 골목 관이 자꾸 땀을 흘려. 새는 게 아니라 김이 맺혀."
- **주문지**: 필요 — 맞닿은 부품(물건) 잠깐 고정 / 주의 — 너무 오래 붙으면 다음 손질이 막힘 / 2장
- **완료**: 보린: "붙인 건 끝났고, 이제 나사가 버티는 거야. …김 말인데, 관 안을 누가 좀 봐야겠어. 도토한테 말해 둘게."

### M03 · 3일 · 기침이 먼저 들리는 길 — 도토
- **접수**
	- 도토: "관 안에 들어가 봐야 하는데, 들어가면 기침부터 나와. 종이 찌꺼기가 둥둥 떠."
	- 도토: "숨 쉴 만큼만 걸러 줘. 90초면 한 칸은 볼 수 있어. 본 것까지만 적자."
- **주문지**: 필요 — 나에게 긴 여과 / 주의 — 막이 차면 흐려짐 / 2장 / **"오래"를 먼저 배워야 함**(2일 잔향)
- **완료**: 도토: "찾았어! 막힌 관, 달팽이 둥지, 그리고 화덕딱정벌레가 관을 데우고 있었어. 김이 거기서 나온 거야." / (수첩에 줄을 그으며) "누수 가설, 삭제."

### M04 · 5일 · 동네에서 제일 작은 대공사 — 보린
- **접수**
	- 보린: "관을 새 부품으로 갈 거야. 세 군데. 맞대고 있는 동안만 붙들어 줘."
	- 보린: "24초면 나사 네 개야. 나 손 빨라."
	- 보린: "떨어진 작은 부품 줍는 건 해도 되고 안 해도 돼. 내가 기어가서 주우면 되니까."
- **주문지**: 필요 — 맞댄 관(물건) 오래 고정 / 선택 — 떨어진 부품 회수 / 3장
- **완료**: 1막 마감 장면(W08b §2.1)으로 이어짐

## 2. 2막 — 주문서 바깥의 이름 (6\~12일)

	- 무로: "바닥 세 군데. 오늘 길만 밝히면 됩니다. 내일은 내일 다시."

	- 세인: "참고로 이 파티의 등불 담당은 지금까지 등불을 드느라 검을 한 번도 뽑지 못했습니다. 본인 요청으로 기록에 남깁니다."
- **주문지**: 필요 — 짐(물건) 긴 조명 / 주의 — 발동 준비 2초 / 2장
- **완료(조건 판정 후기)**: "짐에 긴 조명을 주는 납품 문장을 확인했습니다. 유지 시간은 \[실제 문장의 지속\]초 규격입니다. 등불을 들지 않아도 된다는 조건은 충족했습니다. 전투 결과는 이번 기록에 없습니다."

| --- | --- |
| 에다 | "가는 길에 말인데, 지난번 그거 또. 이번엔 구간이 하나 늘었어." |
| 보린 | "지난번처럼만 잡아 줘. 이번엔 나사가 다섯 개야." |
| 리네 | "단점부터 말할게. 지난번 게 너무 좋아서 또 왔어." |
| 도토 | "새 가설이 생겼어. 지난번 그걸로 확인해 볼래." |
| 소미 | "빵은 빵대로. 지난번 거, 같은 걸로요." |
| 카엘 | "제가 쓸 자리는요, 지난번이랑 같은데 이번엔 조금 더 안쪽이에요." |
| 무로 | "짐부터 확인하겠습니다. 지난번과 같은 짐, 같은 수량입니다." |
| 세인 | "같은 요청이 한 번 더 들어왔습니다. 지난번 사용 보고에 문제는 없었습니다." |
| 이솔 | "지난번 기록과 같은 조건이래요. 여기까지는 기록에 있어요." |

## 6. 거절·보류 대사 (조건이 안 맞는 제품을 가져왔을 때)
벌금·평판 감소는 없다. 무엇이 안 맞는지만 말한다.

| 인물 | 대사 |
| --- | --- |
| 에다 | "음, 이건 나를 밝히는 거네. 짐 쪽으로 다시 부탁해." |
| 보린 | "이건 너무 오래 붙어서 내가 손을 못 대. 다시 해 줄래?" |
| 리네 | "단점부터 말할게. 이건 내가 주문한 게 아니야." |
| 도토 | "관찰해 보니 대상이 달라. 다시 적자." |
| 소미 | "빵은 빵대로… 이건 장부용이 아니네요." |

| 이솔 | "기록과 달라요. 여기가요." (조건 칸을 가리킴) |
