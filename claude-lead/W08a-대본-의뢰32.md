# W08a. 대본 ① — 의뢰 32건 원문

2026-09-23 · 기획 팀장(Claude) 직접 작성 · 한국어 원문(영어는 W09 규칙으로 번역)
기준 [사실]: 의뢰 제목·핵심 요구는 v1.2 6.4·6.6, T5 §5를 유지한다. 인물 말버릇은 T6 §3.1. 후기 문체는 "친구가 만든 사건을 조직이 건조하게 정산한다", 플레이어를 놀리지 않는다(T6 §5.1, D4-02). 수량·보상은 W07 §2.

## 0. 읽는 법

- **접수**: 손님이 카운터(또는 게시판 의뢰지)에서 하는 말. 한 화면에 1~3줄.
- **주문지**: 주문 줄에 걸리는 종이의 요약(필요 효과 / 주의 / 수량). UI가 자동으로 만들고, 여기 적은 건 문구 기준이다.
- **완료**: 납품 다음 날 손님이 하는 한마디 또는 후기 벽 메모.
- `[ ]`는 게임이 채우는 칸. 완료 대사는 해당 결과가 확인됐을 때만 쓴다(T6 §3.3).

## 1. 1막 — 밤마다 젖는 골목 (1~5일)

- **완료**: 도토: "찾았어! 막힌 관, 달팽이 둥지, 그리고 화덕딱정벌레가 관을 데우고 있었어. 김이 거기서 나온 거야." / (수첩에 줄을 그으며) "누수 가설, 삭제."

### M04 · 5일 · 동네에서 제일 작은 대공사 — 보린
- **접수**

  - 보린: "24초면 나사 네 개야. 나 손 빨라."
  - 보린: "떨어진 작은 부품 줍는 건 해도 되고 안 해도 돼. 내가 기어가서 주우면 되니까."

## 2. 2막 — 주문서 바깥의 이름 (6~12일)

- **접수**
  - 무로: "창고 관리인 대신 접수하겠습니다. 짐 자리가 매일 바뀌어서, 지난번 표시가 엉뚱한 곳을 가리킵니다."
  - 무로: "바닥 세 군데. 오늘 길만 밝히면 됩니다. 내일은 내일 다시."

### A01 · 6일 · 등불 담당도 검을 쓰게 해 주십시오 — 세인
- **접수**

  - 세인: "참고로 이 파티의 등불 담당은 지금까지 등불을 드느라 검을 한 번도 뽑지 못했습니다. 본인 요청으로 기록에 남깁니다."
- **주문지**: 필요 — 짐(물건) 긴 조명 / 주의 — 발동 준비 2초 / 2장
- **완료(후기)**: "조명은 6분 동안 유지됐습니다. 발동 준비 2초는 원정 시간으로 정산했습니다. 등불 담당은 이번 원정에서 처음으로 검을 뽑았다고 보고했습니다."

### M06 · 7일 · 굳은 풀 다음에 할 일 — 보린

- **완료**: 보린: "풀이 스르르 풀렸어. 옆 자재는 멀쩡하고. 이런 게 제일 좋아."

- **주문지**: 필요 — 문짝(물건) 오래 고정 / 주의 — 통행 바닥까지 붙이지 않기 / 2장

- **완료**: 세인: "해제 확인. 옆의 짐은 그대로입니다. 요청자에게 두 번 전달하겠습니다."

## 3. 3막 — 고쳐 쓴 여백 (13~20일)

### M11 · 14일 · 유리병이 계단을 무서워해서 — 리네

### A08 · 14일 · 한 번에 넘길 짐 — 무로

### M13 · 16일 · 낮잠을 파는 창가 — 소미
- **접수**
  - 소미: "빵은 빵대로, 낮잠은 낮잠대로. 오후에 창가에서 잠깐 눈을 붙이는데, 등 하나가 너무 눈부셔요."
  - 소미: "그 등 하나만요. 작업등은 켜 둬야 해요. 반죽이 부푸는 걸 봐야 하거든요."
- **주문지**: 필요 — 한 물건 긴 차광 / 주의 — 작업등·글씨까지 덮지 않기 / 1장
- **완료**: 소미: "딱 한 시간… 아니, 1분 쉬었어요. 1분도 꿀맛이었어요. 빵도 잘 부풀었고요."

### A10 · 16일 · 빛을 덮되 길은 보이게 — 카엘
- **접수**

- **주문지**: 필요 — 생물(너) 잠깐 감광 / 주의 — 얼굴 앞 시야도 가림 / 1장
- **완료**: 카엘: "10초 동안 둘이 손 잡고 걸었습니다. 들키지 않았습니다. 조금 어색했습니다."

### A11 · 17일 · 짐에 할까 바닥에 할까 — 무로

- **주문지**: 필요 — 짐 또는 부딪힐 바닥에 짧은 탄성 / 주의 — 도장 위치에 따라 튀는 쪽이 다름 / 2장
- **완료**: 무로: "상자는 이번엔 한쪽으로만 튀었습니다. 방향 확인 완료."

### A12 · 18일 · 큰짐에도 한 번의 당김 — 세인

  - 세인: "반동과 소음이 있다는 설명은 이미 전달했습니다. 요청자는 '괜찮다'고 했습니다."
- **주문지**: 필요 — 물건에 강한 당김 / 주의 — 시전자 반동·큰 소음, 고정된 것은 안 움직임 / 2장
- **완료(후기)**: "큰 상자 이동을 확인했습니다. 요청자 1명이 뒤로 1.2m 이동했습니다. 요청자는 '괜찮다'를 세 번 반복했습니다."

### M16 · 19일 · 빵은 바삭하고 장부는 무겁게 — 소미

  - 소미: "젖은 작업 바닥을 말리면 김이 올라와서 장부가 날아가요. 바닥 말리기랑 장부 붙잡기, 따로따로요."
  - 소미: "그리고 인쇄풀혹 하나. 장부 제본이 뜯어졌거든요."
- **주문지**: 필요 — ① 바닥 짧은 열 ② 주변 넓은 여과(김) ③ 장부(물건) 잠깐 고정 / 3장 + 인쇄풀혹 1
- **완료**: 소미: "바닥은 바삭, 장부는 묵직. 오늘은 두 개 다 제자리예요."

### A13 · 19일 · 검품 중 숨길 것은 없다 — 이솔

- **주문지**: 필요 — 주변 짧은 조명 / 주의 — 찢은 자리 둘레, 따라다니지 않음 / 2장
- **완료**: 이솔: "검품관 두 명이 같이 빛났대요. 숨길 게 없어서 괜찮았대요."

### M17 · 20일 · 정리 전 한눈 검품 — 무로(창고 대리)

- **주문지**: 필요 — 주변 짧은 조명 / 주의 — 가려진 면은 안 비침 / 2장
- **완료**: 무로: "짐 여섯 개, 모든 면 확인. 관리인이 처음으로 칭찬을 했습니다. 기록해 두겠습니다."

### A14 · 20일 · 젖은 작업장의 순서 — 세인

## 4. 4막 — 다음 제작자의 자리 (21~25일)

- **주문지**: 필요 — 생물(너) 짧은 당김 / 주의 — 찢은 자리로 끌려옴, 안전 보장 없음 / 2장
- **완료**: 무로: "동료 회수 확인. 도착한 자리가 안전했습니다. 찢은 사람이 먼저 서 있었기 때문입니다."

## 5. 재주문 대사 (공통 틀 + 인물별 한 줄)

재주문은 3~5일 뒤 같은 용도로 온다(W07 §3). 틀: "[말버릇]. 지난번 [상품/문장], [결과 한마디]. 이번에도 [수량]장."

|---|---|
| 에다 | "가는 길에 말인데, 지난번 그거 또. 이번엔 구간이 하나 늘었어." |
| 보린 | "지난번처럼만 잡아 줘. 이번엔 나사가 다섯 개야." |

| 소미 | "빵은 빵대로. 지난번 거, 같은 걸로요." |
| 카엘 | "제가 쓸 자리는요, 지난번이랑 같은데 이번엔 조금 더 안쪽이에요." |
