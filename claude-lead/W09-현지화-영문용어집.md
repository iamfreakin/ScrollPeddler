## 0. 결론
1. **룬 18개의 영어는 한 단어 명령형**으로: Glow · Stick · Pull · Bounce · Heat · Blot · Filter / Thing · Floor · Wall · Me · You · Around / Brief · Long · Wide · Hard · Far. 한국어와 **같은 순서**(동사 `+` 대상 `+` 수식)로 읽어도 자연스럽다: *Stick **`+`** You **`+`** Long*.
2. 지명은 뜻을 살린 영어 이름으로: 물레목 = **Spindlewick**, 여백 공방 = **The Margin Workshop**, 물레종이소 = **the Spinwheel Paper Mill**, 물때 = **the Tide**.
3. 인물 이름은 소리 그대로(Eda, Borin…), 말버릇은 영어 말맛으로 다시 쓴다.
4. 문장 틀(후기·신문)은 **엔진의 복수형·한국어 조사 처리**를 쓰고, 문자열을 이어 붙이지 않는다.
5. 번역 절차: 한국어 원문 표 → Codex 초벌 번역(이 용어집 고정) → 사용자 검수 → 게임 안 길이·줄바꿈 확인 → 출시 전 영어권 테스터 검수.

- 문장 표기: 한국어 `붙어라 + 너 + 오래` / 영어 `Stick + You + Long`.
- 활자 윗면에는 문양 `+` 해당 언어 글자. 문양은 언어와 무관하게 같다(색·모양·글자 3중 표기, T2 §4).
- 검토한 대안: 가려라 = Shade(그늘과 헷갈림), Veil(뜻은 맞으나 먹 느낌이 없음) → **Blot** 채택. 걸러라 = Sift(짧고 예쁘지만 덜 직관적) → **Filter** 채택. 세게 = Strong(형용사라 어색) → **Hard**(Stick Hard, Pull Hard가 자연스러움).

## 9. 문장 틀과 엔진 처리

| 문제 | 규칙 |
