## 2. 충돌 해소

| 항목 | 기준 |
|---|---|
| 물과 접착 | 물만으로 풀리지 않음. S6가 열로 물기를 말리고 김을 만든 다음, 남은 열만 S2 해제에 사용 |
| 여과와 김 | 걸러라는 가루를 포집. 김은 기존 송풍기·환경 바람으로 걷음. P09는 가열→기존 송풍기의 건조 작업. M16·A14에서 가루 여과·접착을 더해 기본 스크롤3장 |
| 물때 종료 | 모두 귀환하고 연결 복구 대기 인원도 없으면 남은 침수 결과를 즉시 정산. 남은 시간을 기다리거나 날짜를 자동 증가시키지 않음 |
| 운반 수레 | 물에 강한 확보 물품은 바닥에 있어도 공동 회수. 수레는 조기 가공·취약 재료 안전 반출을 위한 선택 |
| 채취 | 같은 생물 개체·나방 무리는 하루 1번. 부풀달팽이 2마리는 점액 최대 2개 = 먹 4회분. 공급 상한과 실제 반출량은 구별 |
| 납품량 | 문장별 장수에 인원 배수를 적용한 뒤 각 행을 올림. 복수 스크롤 작업을 1장으로 세지 않음 |
| 계산 결과 [추정] | 고유 의뢰 32건: 1·2·3·4인 납품 68·112·136·180장, 먹 112·186·224·298회분, 보상 2,900·4,340·4,940·6,380G |
| 구매 한도 | 몬스터 먹 주간 5회분·일일 2회분은 파티 공용 보충 상한. 몬스터 재료의 던전 주 공급 원칙 유지 |
| 날짜 | 해금일은 받을 수 있게 되는 날. 그날 모든 의뢰를 마쳐야 하는 마감일이 아님 |
| 데모 재료 8 | 기존 8칸 중 숨돌을 탄성점액으로 교체해 데모 부풀달팽이 드롭과 일치. 본편 재료·룬·생물 수량은 유지 |

## 3. 검증과 일정

**[사실] 새 언리얼 프로젝트·플레이 실측은 아직 없다.** 24분·30분·약 10시간·2초 보호·10~25초 고객 장면·재주문 비율은 모두 검증 전 시작값이다.

| 일정 [추정] | 계산·범위 |
|---|---|
| 이전 기본 | 280~440작업일 = 월 20일 기준 14~22개월 |
| D7 보강 포함 이전안 | 338~534작업일 ≈ 17~27개월. 기존 추가 예비비와 중복해서 더하지 않음 |
| D8 증분 | 조건 주문 2~4, 재고·핑·개인 기록 4~7, 고객 장면 3~6, 잔향 복구 2~4, 재부여 보호 1~2, 통합 검증 3~5 = 15~28작업일 |
| v2.1 현재 계획 | 353~562작업일 ≈ 18~29개월. 기존 인물·소품·퍼즐 재사용을 가정한 추정이며 납기 확정이 아님 |

지속 제작 여부와 출시 목표일은 슬라이스 실측 뒤 판단한다. 장식·축제·사진기부터 줄이되, 줄인 뒤에도 10시간을 지킨다고 미리 단정하지 않는다.
