# W06. 10시간 채우기 — 빠진 92분을 새 판단으로

2026-09-23 · 기획 팀장(Claude) 직접 작성
기준 [사실]: 숙련 전체 경험 약 10시간(U10), 내부 판정 9~11시간(D2-05). 축소 뒤 원안 계산을 그대로 옮기면 508분 = 8시간 28분(v2.0 §8.5). **빠진 92분을 대기·단순 왕복·필수 반복 채집으로 채우지 않는다**(v2.0 §8.5). 후속 후보를 자동 양산으로 올리지 않는다(팀장이 명시 결정할 때만).

## 0. 결론

여섯 가지 장치로 약 **89분**을 채운다. 모두 기존 문법·공간·에셋을 다시 쓰고, 매번 새로운 판단을 요구한다.

| # | 장치 | 더하는 시간 [추정] | 등급 | 제작 [추정] |
|---:|---|---:|---|---:|
| 1 | **길드 인증 시험** 3회(6·12·20일) | 21분 | 1군 | 4~6작업일 |
| 2 | **후속 의뢰 4건 복귀**(M08·A05·A16·A19) | 16분 | 1군 | 2~3작업일 |
| 3 | **분실물 8개**(던전에서 줍고 주인에게) | 16분 | 1군 | 2~3작업일 |
| 4 | **화제 상품** — 우리 사고가 다음 주 주문이 됨 | 20분 | 2군 | 4~6작업일 |
| 5 | **종이등 축제** 밤 행사(15일) | 12분 | 2군 | 5~8작업일 |
| 6 | **사진기와 신문 1면** | 4분 | 2군 | 4~6작업일 |
| | 합계 | **89분** → 508+89 = **597분(9시간 57분)** | | **21~32작업일** |

- **1군만 해도 561분(9시간 21분)**으로 내부 판정 9시간을 넘는다. 일정이 밀리면 2군부터 줄인다.
- 2군은 시간보다 **클립·공유**에 값어치가 크다(우리 게임 홍보의 주 재료). 그래서 팀장 추천은 전부 유지다.
- 모든 시간은 계산값이다. 실제 10시간은 슬라이스·데모 뒤 숙련 플레이로 잰다([사실] v2.0 §12.3).

## 1. 길드 인증 시험

### 1.1 틀

| 항목 | 내용 |
|---|---|
| 누가 | 세인(시험관)과 이솔(기록). 공방 **시험 옆방**에 길드 시험 소품을 들여와 치른다(새 공간 없음) |
| 형식 | 세 문제. 길드가 준 **시험 봉투**(시험지 5~7장)만 쓴다. 시간 제한 없음. 두 문제를 풀면 통과 |
| 실패 | 없다. 봉투를 다 쓰면 "다음 영업일에 다시 오겠습니다" — 벌금·평판 감소 없음 |
| 정답 | 하나로 잠그지 않는다. 조건을 만족하면 어떤 문장이든 인정 |
| 등급 | 1차 = 길드 **등록**(게시판 개방 조건), 2차 = **신용**(선택), 3차 = **지정**(선택). 등급 혜택은 W07 §4 |

### 1.2 문제

**1차 — 등록 인증 · 6일 아침(약 5분)** · 쓸 수 있는 룬: 시작 6 + 오래·바닥

| 문제 | 상황 | 푸는 예 |
|---|---|---|
| 1-1 상자 속 이름표 | 뚜껑 열린 어두운 상자 안의 이름표를 읽어야 한다 | 빛나라+물건+잠깐을 **이름표**에(상자에 하면 겉만 빛남) |
| 1-2 굴러오는 공 | 비탈에서 공이 굴러와 선 밖으로 나간다. 선 안에서 멈춰라 | 붙어라+바닥+잠깐을 공이 지나갈 바닥에 / 붙어라+물건+잠깐을 공에 |
| 1-3 먼지 속 팻말 | 풀무가 가루를 뿜는 가운데 팻말 글씨를 읽어라 | 걸러라+나+잠깐 / 걸러라+물건+오래를 풀무 앞에 |

세인: "확인한 항목부터 적겠습니다. 이름표 식별, 통과. 공 정지, 통과. 팻말은… 제 눈에 가루가 들어갔으므로 판정을 보류합니다."

**2차 — 신용 인증 · 12일 이후(약 7분)** · 추가: 달궈라·너·당겨라·넓게

| 문제 | 상황 | 푸는 예 |
|---|---|---|
| 2-1 둘 중 하나 | 풀로 붙은 상자 두 개. 왼쪽만 떼어라(오른쪽 상자엔 "건드리지 마시오") | 달궈라+물건+잠깐을 왼쪽에만. 넓게를 쓰면 둘 다 풀림 |
| 2-2 세인 옮기기 | 세인이 원 안에 선다. "저를 원 밖으로 1m 옮기십시오. 불편은 기록하겠습니다." | 당겨라+너+잠깐(찢은 자리 쪽으로 끌려옴). 협동이면 동료를 당겨도 인정 |
| 2-3 가운데 셋 | 여과틀 다섯 개 중 가운데 셋에만 막을 씌워라 | 걸러라+물건+넓게를 가운데 틀에(범위 2m가 셋만 닿게 배치됨) |

**3차 — 지정 인증 · 20일 이후(약 9분)** · 추가: 튕겨라·벽·가려라·세게·주변

| 문제 | 상황 | 푸는 예 |
|---|---|---|
| 3-1 두 번 튀어 바구니로 | 굴린 공이 벽에 한 번 튀어 바구니에 들어가야 한다 | 튕겨라+벽+잠깐을 알맞은 벽에 |
| 3-2 눈부신 쪽만 | 등불 두 개. 눈부신 쪽만 가리고 읽는 등은 남겨라 | 가려라+물건+잠깐/오래를 한쪽에 |
| 3-3 한 번에 검품 | 상자 여섯 개의 면을 한 번에 비춰 이솔이 읽게 하라. 단, 이솔은 빛나면 안 된다 | 빛나라+주변+잠깐을 이솔과 떨어진 자리에서(주변은 찢은 위치 둘레) |

이솔(3-3에서 빛났을 때): "…여기까지는 기록에 있어요. 제가 빛났다는 것도요."

## 4. 화제 상품 — 우리 사고가 다음 주 주문이 된다

### 4.1 흐름

1. 주간 신문(영업 5일마다)이 이번 주 **실제 파티 사건 기록**에서 "화제의 사고" 하나를 골라 기사로 싣는다(T6 N01·N06·N07 틀 + 새 틀 N13).
2. 다음 주, 손님 한 명이 그 기사를 들고 온다. **같은 문장을 전혀 다른 멀쩡한 용도로** 쓰고 싶다고 한다.
3. 행상단은 그 문장(또는 같은 효과)을 만들어 납품한다. 보너스가 붙고, 후기는 원래 사고를 다시 언급한다.

### 4.2 화제 사고 고르기 [추천]

| 점수 | 기준 |
|---|---|
| +3 | 한 사건에 영향받은 생물 수(동료·몬스터·NPC) 1명당 |
| +2 | 이어진 반응 1단계당(예: 튕김→충돌→접착) |
| +5 | 사건이 사진기로 찍혔음(§6) |
| +2 | 아군이 휘말림(피해 없이) |
| 제외 | 쓰러짐 없는 단순 실패, 같은 문장이 2주 연속 |

- 사건이 하나도 없으면(아주 조심스러운 파티) 시험실 기록으로 대체: "시험 인형 멀쩡이, 이번 주 발광 43회."

### 4.3 주문 틀

> "신문에서 봤습니다. **'[문장]'** 으로 **[사고 결과]** 했다던데요. 저희는 그걸 **[새 용도]** 에 쓰고 싶습니다. [수량]장 부탁합니다."

**새 용도 표(동사 × 대상, 일부) [추천]** — 42칸을 모두 쓴다. 대표 예:

| 문장 계열 | 신문 속 사고 | 새 용도(손님의 말) |
|---|---|---|
| 붙어라 + 너 | 동료가 천장에 붙음 | "짐꾼이 짐을 등에 붙이고 다니게 하려고요." |
| 붙어라 + 바닥 | 출입구에 모두 붙음 | "장날에 좌판이 바람에 안 날아가게요." |
| 튕겨라 + 바닥 | 상자가 통로 밖으로 날아감 | "축제 뜀틀로 쓸 겁니다." |
| 튕겨라 + 너 | 부푼 달팽이가 공처럼 튐 | "양 떼가 울타리에 부딪혀도 다치지 않게요." |
| 빛나라 + 나 + 넓게 | 파티 전원이 빛나서 나방을 끌고 다님 | "밤 합창단 조명이요. 나방은… 괜찮습니다." |
| 빛나라 + 주변 | 숨어 있던 모두가 빛남 | "숨바꼭질 대회 끝낼 때 쓰려고요." |
| 당겨라 + 주변 + 세게 | 동료와 상자가 한 덩어리로 끌려옴 | "흩어진 닭을 한 번에 모으고 싶어요." |
| 당겨라 + 나 + 오래 | 찢은 자리로 계속 끌려감 | "산책하다 길 잃는 할아버지께 드리려고요." |
| 가려라 + 너 | 동료 얼굴에 먹막 | "낮잠 자는 남편 눈가리개로요." |
| 달궈라 + 주변 | 김으로 서로 안 보임 | "목욕탕 개업 행사용입니다." |
| 걸러라 + 주변 + 넓게 | 눈앞까지 막이 참 | "꽃가루에 약한 손님들 앉는 자리 둘레요." (42칸 전체는 W08c §10) |

- 보상: 해당 문장의 q×F + B 30G + **화제 보너스 20G**(W07). 새 고유 의뢰 수(32)에는 세지 않는다(재생성되는 변주 주문).
- 호스트가 모르는 룬이 든 문장(게스트가 가져온 도안으로 낸 사고)은 건너뛰고 다음 후보를 쓴다.
- 엔딩 뒤에도 계속된다. 반복 콘텐츠의 한 축.

### 4.4 왜 넣는가

친구끼리 낸 사고가 **다음 주 장사 거리**가 되면, 사고가 손해가 아니라 이야깃거리가 된다. 공유 클립("우리 사고가 상품이 됐어")도 자연스럽게 나온다. 에셋은 들지 않고 글 틀과 사건 점수만 있으면 된다.

## 5. 종이등 축제 — 15일 밤

### 5.1 흐름 (약 12분, 전부 선택)

| 끝 | 불꽃놀이 최고 순간이 20일 신문 1면이 된다 |

심사평 예:
- 세인: "관객 중 발광 7명, 접착 2명, 비명 1회. 축제 기록으로 분류합니다. 9점."
- 에다: "가는 길에 말인데, 내 수레까지 튀었어. 10점."
- 보린: "다 끝나면 누가 치우나. 그래도 8점."

### 5.2 상품과 규칙

- 1등이든 꼴찌든 **축제 모자 "종이등 갓"** 을 받는다. 점수가 높으면 신문 1면.
- 축제지는 판매·반출 불가, 재료 소비 없음(시험지와 같은 규칙).
- 관객 NPC가 효과에 맞으면 웃으며 반응할 뿐 피해·평판 변화 없음.
- 필요한 것: 마당 장식 세트(종이등·무대·좌판), 관객 대기 동작, 점수 판정, 음악 12번(W03). [추정] 5~8작업일.
