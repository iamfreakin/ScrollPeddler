## 2. 막 장면
\[추천\] 기존9인물·32의뢰·네 막을 손님의 작업으로 잇습니다. 1막은 양손·조사·수리,2막은 상품 이름과 사용처의 차이,3막은 임시 마법 뒤 실제 작업,4막은 복원본의 현재 작업 확인입니다. 새 대형 컷씬·악당·분기 엔딩을 더하지 않습니다.

시작6룬은 빛·접착·여과/물건·나/잠깐이다. 새 활자의 최소 소개는 오래2일,바닥4일,열6일,너7일,당김8일,넓게10일,탄성13일,벽14일,차광15일,세게17일,주변18일,멀리21일이다. 복습 E13은23일,E14는24일이다. 아직 모르는 룬의 주문은 미수락으로 남기고 사용 가능 뒤 견적을 고정한다.

\[추천\] 동시에 조건을 만족한 장면은 선행 설명부터 대기열에 넣는다. 기록 재열람은 대사·확인만 보여 주고 물품을 다시 소비하지 않는다. 대기 장면을 보여 주기 위해 영업일을 강제로 추가 소모하지 않는다.

모든 장면은 **공방이나 마을 한 자리**에서, 필요한 인물만으로, 30\~60초. 건너뛰기 가능. 대사는 자막 + 옹알이(W03 §2).

아래 날짜는 **장면이 처음 가능해지는 날**이다. 관련 납품·수리·단서 비교가 실제 완료된 뒤에 재생하며, 분할 납품이 늦었다고 완료하지 않은 장면을 먼저 보여 주지 않는다. 컵 선물도 6일 이후 골목 수리가 완료된 뒤 전달한다. 해당 상태가 없으면 인물은 현재 확인한 일까지만 말한다.

| 4 | 공방 | 이솔이 펜을 내민다. 이솔: "여기, 빈칸이요. 오늘 확인한 일부터 적으면 되겠어요." — 행상단 이름·인장과 **실제로 확인한 작업 조건 한 줄**이 마지막 확인란에 찍힌다 |
| 5 | 길드 출장소 | 세인이 사용 보고를 등록한다. 세인: "복원본, 사용 확인. 이후 수정 사항은 같은 항목에 이어 적겠습니다." 잠깐 멈춘다. "…수고하셨습니다. 이건 적지 않겠습니다." |
| 6 | 골목(밤) | 에다의 수레가 마른 골목을 지난다(축제 때 기부한 등불이 켜져 있으면 더 밝다). 5일에 이어 에다가 **다시 멈춰** 말한다: "오늘은 종이가 말라 있네. 내일 쓸 것도 부탁할게." |
| 7 | 공방(다음 날 아침) | 카운터에 새 주문지 한 장. 도안함 마지막 줄: **"이후의 사용 기록은 여백 공방에서 계속한다."** 간판 옆 여백에 행상단 이름이 새겨져 있다. 영업이 이어진다 |

- 스태프 크레딧은 6과 7 사이. 크레딧 배경은 **이번 캠페인의 신문 1면 사진들**이 넘겨지는 모습(W06 §6). 파티마다 다른 크레딧이 된다.
- 엔딩은 하나. 어떤 조건에서도 같은 순서.
**복원본의 마지막 한 줄 \[추천·D8\]:** A20에서 접착 중 나사 작업이 실제 끝났다면 “접착이 끝나기 전에 나사를 조여 고정을 마쳤다.”를 쓴다. E14의 가루 길목 배치 또는 E10의 당김·손 놓기가 확인됐다면 해당 조건을 고를 수 있다. 플레이하지 않은 구조·사고는 만들지 않는다. 기존 이름·인장을 사용하고 짧은 자유 서명은 선택이다. 엔딩 뒤 게시판은 기존 미완료 과제 4종을 모아 다음 준비 목표로 연결한다(W06 §7.0).

### 3.1 실제 사용3장면과 재주문3연쇄
\[사실\] 직접 사용 장면은 M01·M04·A16,각10\~25초 시작값이다. 실제 납품 문장을 고객 재고에서1회 소비하며 공방 재고를 다시 빼지 않는다. 긴 효과는 장면 종료 뒤에도 원래 시간대로 남는다. 단체 카메라 고정은 없다.

| 연쇄 | 실제 사용 대사 \[추천\] | 다음 부탁의 한 가지 변화 | 제작 판단·후기 |
| --- | --- | --- | --- |
| M01 에다 | 짐에 조명을 쓰고 양손으로 수레를 잡음. “밝혀 달라는 건 길이었는데, 필요한 건 손이었네. 가는 길에 말인데, 이거 좋다.” | 완료 뒤3\~5일,오래를 배웠을 때만. “이번엔 골목 끝까지 가. 짐은 같고, 구간만 길어졌어. 세 분은 밝혀 줘.” | 물건 빛180초. 잠깐60초 부족/오래360초 적합. 후기는 규격 확인과 실제 소요를 구분 |
| M04 보린 | 관을 붙이는 동안 나사를 조임. “붙인 건 네 문장이고, 고친 건 나사야. 둘 다 있어야 끝나지.” | “이번엔 관이 아니라 얇은 받침이야. 열두 초면 돼. 전에 만든 판도 버티겠지?” | 기존 오래24초 판 재사용. “임시 고정 뒤 나사 작업 완료. 효과 종료 뒤 고정은 나사가 담당합니다.” |
| A16 카엘 | 건너편 도구 조명. “제가 쓸 자리는요, 여기예요. 밝혀야 할 건 저 도구고요. 이제 이 순서로 말하니까 안 헷갈립니다.” | “이번 점검대는 세 걸음 앞이에요. 물건은 그대로고요.” | 거리만3m 이내로 변경. 기존90초 조건 유지: 멀리120초 판 재사용 또는 빛+물건+넓게120초가 주변 소품 영향 조건까지 만족하는지 비교. 잠깐60초는 부족 |

카엘의 재주문에서 거리와 지속을 동시에 몰래 바꾸지 않는다. 기존 멀리도 적합하다면 재사용이 정답이며, 변경을 강요하려고 부적합 처리하지 않는다. 더 싼 잠깐을 허용하려면 별도의 지속 조건 변경 주문이어야 한다.

첫날 고객 사용은 당일, 서면 후기는 다음 아침이다. 장면을 못 본 게스트에게 개인 목격을 주지 않는다. 새 대사는 기존 완료 대사의 대체본으로 관리하며 모두 덧붙여 집필량과 플레이시간을 늘리지 않는다.

### 3.2 잔향과 마지막 한 줄
\[사실\] 새 룬 잔향은 관찰→미지 룬 하나의 의미 추정→해당 수습→탁본3초→귀환 후 활자다. 복습 E13·E14는 이미 아는 문장을 비교한다. 공급 중단·작업 복구는 해당 잔향의 조건을 따르며 E08·E10·E14는 원래 작업의 복구까지 확인한다. 새 룬 탁본 순간 공동 도감 지식은 안전하게 기록되고, 실제 사용 해금은 활자 완성으로 구분한다.

| 잔향 | 원래 작업과 복구 | 남길 문장 \[추천\] |
| --- | --- | --- |
| E08 벽 받침 | 벽에서 떼기만으로 끝나지 않음. 받침을 작업대 아래에 세워 지지 확인 | “붙일 면과 받칠 자리는 따로 확인한다.” |
| E10 틀 회수 | 공급 중단→아는 당김/손 회수→손으로 받침 홈에 놓기 | “당기는 기준점을 먼저 잡고, 회수한 틀은 손으로 내려놓는다.” |
| E14 가루 판독 | 눈앞 막 제거→길목 여과틀/바람막이→기록이 보이는 자리 확인 | “김은 바람으로, 가루는 길목에서. 읽는 면 앞은 비운다.” |
| A20 복원본 | 조명·가루 여과·접합을 지정 작업면에서 확인 | 실제 성공한 조건 한 줄을 선택하고 행상단 인장 |

E08·E10은 배우는 룬을 먼저 요구하지 않는다. E14는 복습이다. 예시 한 줄을 실제로 시험하지 않았다면 “옛 기록의 메모”로만 표시하고 우리 확인란에는 넣지 않는다. 보린의 스승 드라이버는 분실물 반환 시 쓰는 선택 소품이며, 없어도 평범한 드라이버로 결말을 진행한다.

[Heaven’s Vault 개발사 설명](https://medium.com/@inklestudios/why-does-translation-unlock-sites-in-heavens-vault-e05c4ccadf62)에 따르면 그 작품은 번역이 장소·줄거리 해금을 직접 잠그지 않는다. 여기서는 해석으로 세계 이해가 바뀌는 원리를 참고하며, 우리 활자 해금·심층부 선행 조건은 별도의 설계다.

## 7. 로딩 화면 — 행상 수칙 20
행상단이 공방 벽에 붙여 가는 수칙. 몇 개는 캠페인이 지나며 추가된다.
1. 파는 물건은 읽고 판다. (어제 만든 수칙)
2. 동그란 활자는 동그란 칸에.
3. 짐을 밝히라고 했으면 짐을 밝힌다.
4. 먹병은 던지지 않는다. 특히 탄성 먹.
5. 물방울 표시 재료는 먼저 들고 나온다.
6. 증기 기적이 세 번 울리면 돌아온다.
7. 오래 붙인다고 오래 고쳐지는 건 아니다.
8. 당긴 자리는 찢은 자리.
9. 넓게 하면 약해진다.
10. 튀는 건 부딪힐 때.
11. 꺼진 것과 덮인 것은 다르다.
12. 세게 하면 나도 밀린다.
13. 주변은 따라오지 않는다.
14. 멀리 닿는다고 세지는 건 아니다.
15. 멀쩡이는 멀쩡하지 않다.
16. 봉인 안 한 건 안 받는다. 물도 안 받아 준다.
17. 동료를 짐으로 분류하지 않는다. (무로 제외)
18. 사고가 나면 수습부터. 사진은 그다음.
19. 빈칸은 채우라고 있는 것.
20. 다음 사람을 위해 여백을 남긴다.
