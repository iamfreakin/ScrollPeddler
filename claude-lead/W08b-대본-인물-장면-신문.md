모든 장면은 **공방이나 마을 한 자리**에서, 필요한 인물만으로, 30~60초. 건너뛰기 가능. 대사는 자막 + 옹알이(W03 §2).

| 2 | 심층부 S3 | 도안판이 안정되고 **마지막 장(C11)**이 드러난다. 여러 필체의 확인란이 줄지어 있고, 맨 아래 한 줄이 비어 있다. 문구: "다음 사람은 현장에서 다시 확인할 것." 탁본 |

| 4 | 공방 | 이솔이 펜을 내민다. 이솔: "여기, 빈칸이요. 오늘 확인한 일부터 적으면 되겠어요." — 행상단 이름과 인장이 마지막 확인란에 찍힌다 |
| 5 | 길드 출장소 | 세인이 사용 보고를 등록한다. 세인: "복원본, 사용 확인. 이후 수정 사항은 같은 항목에 이어 적겠습니다." 잠깐 멈춘다. "…수고하셨습니다. 이건 적지 않겠습니다." |
| 6 | 골목(밤) | 에다의 수레가 마른 골목을 지난다(축제 때 기부한 등불이 켜져 있으면 더 밝다). 에다가 처음으로 멈춰 서서 말한다: "오늘은 종이가 말라 있네. 내일 쓸 것도 부탁할게." |
| 7 | 공방(다음 날 아침) | 카운터에 새 주문지 한 장. 도안함 마지막 줄: **"이후의 사용 기록은 여백 공방에서 계속한다."** 간판 옆 여백에 행상단 이름이 새겨져 있다. 영업이 이어진다 |

- 스태프 크레딧은 6과 7 사이. 크레딧 배경은 **이번 캠페인의 신문 1면 사진들**이 넘겨지는 모습(W06 §6). 파티마다 다른 크레딧이 된다.
- 엔딩은 하나. 어떤 조건에서도 같은 순서.

## 4. 단서 원문 C01~C12

옛 기록은 **짧은 작업 메모**다. 여러 필체가 섞인다(글꼴 3종: 반듯한 글씨·흘림체·굵은 목수 글씨).

| ID | 매체 | 원문 [추천] |
|---|---|---|
| C01 | 공방 도안판 뒷면 | (개인 표식) + (접힌 모서리 표식) "고쳐 씀." |
| C02 | 물레종이소 잔향 메모 6장 | W05 §6의 E01~E06 여백 메모. 모두 한 줄 + 다른 필체의 덧글 |
| C03 | 공방 도안함 사본 | 서로 다르게 닳은 사본 7장, 모두 오른쪽 아래 확인란에 접힌 모서리 |
| C04 | 이솔 대사 | "이 표식은 만든 사람 칸이 아니라 함께 확인한 사람 칸에 찍혀 있어요." |
| C05 | 10일 신문 자료 기사 | "옛 제지조합 반출 대장 일부 공개. 반출처: 먹돌 광산 선별소, 봉랍 양봉장 건조대, 합동 도안실(위치 미상)." |
| C06 | 양봉장 E10 방 벽의 두 번째 메모(W05 §6 E10) | "당겨서 가져왔으면 내려놓는 건 손으로. 마법이 끝나도 짐은 제자리로 안 돌아간다." |
| C07 | 양봉장 기록 홈 사본 | "— 받는 쪽 확인 후 넘길 것. 받는 쪽은 밝기와" (여기서 찢겨 있음) |
| C08 | 광산 침전·기록실 사본(E09 뒤) | "(앞장 없음) …넘겨받은 뒤 밝기 확인, 가루 확인, 그다음에 읽을 것. 덮인 등은 닦아 볼 것." |
| C09 | 이솔 대조(20일) | C07 + C08 = 한 작업. 사본 여백: "마지막 장 보관 — 합동 도안실, 건조실 아래." |
| C10 | 심층부 잔향(E12·E13) | 실패 기록과 함께 성공 조건: "멀리 닿는다고 세지 않다. 그래서 사람을 보냈다. 표시한 사람과 따라가는 사람은 다르다. 둘 다 적을 것." |
| C11 | 심층부 마지막 장(A20) | 확인란 11줄(필체 11가지), 맨 아래 빈 줄 하나. 본문 마지막: "다음 사람은 현장에서 다시 확인할 것. 여기까지가 원문." |
| C12 | 복원 납품 뒤 도안함·신문 | "복원본 첫 사용: [날짜], 확인: 세인, 제작: [행상단 이름]. 이후 수정은 이 항목에 이어 적음." |

발견 순서가 바뀌면 NPC는 확인한 부분까지만 말한다(T6 §2.2). 예: C08만 봤을 때 이솔 "이 기록의 앞장이 비어 있어요." → C07까지 보면 "두 장이 이어져요."

## 5. 인물 일상 대사

### 5.1 인사 — 평판 단계별

| 인물 | 첫 거래 | 단골 | 지정 공방·엔딩 뒤 |
|---|---|---|---|
| 에다 | "가는 길에 말인데, 새로 왔다며?" | "가는 길에 말인데, 오늘도 들렀어." | "오늘은 가는 길 아니고 오는 길이야." |
| 보린 | "공방 쓸 만해? 고칠 데 있으면 말해." | "오늘은 고칠 데 없어? …아쉽네." | "여백 공방 간판, 볼 때마다 뿌듯해. 내가 걸었거든." |
| 리네 | "단점부터 말할게. 우리 가게 좁아." | "단점부터 말할게. 오늘 새로 들어온 거 비싸." | "단점부터 말할게. …없네. 오늘은." |
| 도토 | "관측원 도토야. 본 것까지만 적어." | "오늘 가설 하나 들어 볼래? 틀릴 거야." | "너희 기록, 내 수첩보다 줄 덜 그었더라." |
| 소미 | "빵집이에요. 빵은 빵대로 사 가세요." | "빵은 빵대로, 오늘은 하나 덤." | "빵은 빵대로, 고마운 건 고마운 대로." |
| 카엘 | "안녕하세요! 길잡이 카엘입니다!" | "제가 쓸 자리는요… 아, 오늘은 그냥 인사하러 왔어요." | "다음 원정 쓸 자리, 이미 적어 왔어요." |
| 무로 | "짐부터 확인하겠습니다. …손님이군요." | "짐 없이 왔습니다. 인사입니다." | "짐보다 사람이 먼저입니다. 오늘은." |
| 세인 | "확인한 항목부터 적겠습니다. 방문 목적은?" | "오늘도 확인할 항목이 많습니다. 좋은 뜻입니다." | "방문 확인. 이유는 적지 않겠습니다." |
| 이솔 | "…여기까지는 기록에 있어요. 처음 뵙네요." | "오늘 새로 읽은 게 있어요. 조금만요." | "빈칸이 많아서 좋아요. 적을 게 많으니까요." |
