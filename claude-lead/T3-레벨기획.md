## 1. 여백 공방 내부

### 1.1 글 배치도와 4공정

남쪽 정문을 기준으로 북쪽을 안쪽이라 부른다. 본실은 약 18m × 16m, 북동쪽에는 시험용 옆방 약 6m × 6m를 붙이는 시작안이다. 크기는 실내를 채우는 목표가 아니라 통행 폭을 확보하기 위한 외곽 여유다.

| 자리 | 시설과 향하는 방향 | 주변 연결 |
|---|---|---|
| 남쪽 중앙 E | 정문·출정 준비 자리. 들어오면 북쪽 안쪽까지 보인다. | 정문에서 4m 앞 J에 도착한 뒤 좌우로 갈라진다. 문 앞에 손님·짐을 세우지 않는다. |
| 남서쪽 A | 응대·장부. 작업자는 벽 쪽을 보고 서고 손님은 남서쪽 별도 홈에 선다. | J의 서쪽 4m. 재료 준비 B와 북쪽 길로 연결. 거래처 수신기는 장부 옆 벽면에 둔다. |
| 북서쪽 B | 먹·재료. 서랍·먹 저울·종이 공급을 한 작업면에 모은다. | A의 북쪽 7m. 동쪽 길을 따라 문장·인쇄 C에 닿는다. 서랍을 연 자리와 통행선을 분리한다. |
| 북동쪽 C | 문장·인쇄. 도안판과 출력 받침을 붙이고 북동쪽 시험 옆방으로 이어진다. | B에서 동쪽 8m. D와 남쪽 길로 연결. 출력물을 꺼내는 위치는 도안을 보는 위치와 나란히 둔다. |
| 남동쪽 D | 검사·포장·출고. 봉인 자리와 판매·비축 선반을 같은 작업면에 둔다. | C의 남쪽 7m. J를 거쳐 정문으로 바로 나간다. 진열대는 통행선 바깥 남동쪽 벽면에 둔다. |
| 중앙 | A–B–C–D–A의 사각 순환길 안쪽은 낮고 비워 둔다. | 동료 위치가 보이고 돌아갈 방향을 고르기 쉽다. 가운데 거대한 장식·짐 더미는 두지 않는다. |
| 북동쪽 시험 옆방 | 시험판은 안쪽 벽을 향한다. 시험 기록대는 입구 옆에 둔다. | C에서 작업점까지 6m. 통행길과 두꺼운 벽으로 분리하고, 시험을 보려는 사람은 옆 관찰 자리에 선다. |

글로 읽는 연결은 **E —4m— J —4m— A —7m— B —8m— C —7m— D —4m— J**이다. A–D는 J를 거쳐 8m이며, C에서 시험판까지 6m를 더 간다. 작업면은 순환길의 바깥쪽에 놓아 서 있는 사람의 뒤로 지나갈 수 있게 한다.

| 시작 → 도착 | 실제 통행선 | [추정] 접근 시간 |
|---|---:|---:|
| 정문 E → A / D | 각각 8m | 각각 5초 |
| 정문 E → B / C | 각각 15m | 각각 7초 |
| 정문 E → 시험판 | 21m | 9초 |
| A ↔ B / C ↔ D | 각각 7m | 각각 5초 |
| B ↔ C / A ↔ D | 각각 8m | 각각 5초 |
| A ↔ C / B ↔ D | 각각 15m | 각각 7초 |
| C ↔ 시험판 | 6m | 4초 |

입구에서 가장 먼 핵심 시설의 계산값은 9초로, 15초 기준 안에 6초 여유를 남긴다. 공간 확장 후에도 입구→작업점 기준으로 다시 잰다.

### 1.2 1~4인의 통행

| 항목 | 배치 시작값·사용 방법 |
|---|---|
| 길 폭 | 주 순환길은 가구·서 있는 작업자를 제외하고 유효 폭 2.4m. 정문과 J는 3m, 시험 옆방 입구는 2.4m를 확보한다. |
| 작업 자리 | 각 공정의 서 있는 깊이 1.2m는 통행 폭 밖으로 빼고, 옆에 물건을 받는 홈을 둔다. 서랍·문을 열어도 주 통행길 안으로 나오지 않는다. |
| 1인 | A에서 계획 후 B→C→D로 묶음 작업한다. 출력 중 장부·재료·포장을 오갈 수 있다. |
| 2인 | 한 사람은 A·C, 다른 사람은 B·D를 오가되 소유 구역으로 고정하지 않는다. 반대편으로 돌아 지나갈 수 있다. |
| 3인 | 재료·문장·출고를 병행하고, 장부는 짧게 들른다. 중앙 시야로 빈 자리를 확인한다. |
| 4인 | 각 공정에 한 명이 서 있어도 순환길을 비워 둔다. 별도 주문을 진행하는 배치이며 한 장의 전달 순서를 강제하지 않는다. |
| 먼저 귀환한 사람 | 정문→B에서 분류하거나 정문→D에서 포장한다. 장부·시험 사용자 사이를 가로지르지 않는다. |
| 검증 경계 | 플레이어끼리 충돌하는지·겹쳐 통과하는지는 T1 몫이다. 이 배치는 충돌을 끄지 않아도 교행 가능한 폭을 목표로 한다. |

### 1.3 소품의 위치와 보이는 각도

각도는 정문 E에서 북쪽을 0도로 보고 잰 좌우 방향의 시작값이다. 실제 시야각·가구 높이 확정 후 가림을 확인한다. 물건이 보이는 것과 글씨를 읽을 수 있는 거리는 구분한다.

| 소품 | 위치 | 입구에서 보이는 방향·가까이서 보는 자리 | 배치 이유 |
|---|---|---|---|
| 진열대 | D 바깥 남동쪽 벽면 | 오른쪽 약 35~55도. J에서 오른쪽으로 보면 제품 면이 보이고 D에서 분류한다. | 입장 때 공방의 결과물이 먼저 보이며 출고 동선을 짧게 한다. |
| 건조 걸이 | B–C 북쪽 벽 위쪽 | 정면 약 좌우 15도. 작업대 사이의 높은 벽면에 걸고 머리 위 통행 공간을 침범하지 않는다. | 깊이감을 주되 중앙 동료·시험 옆방 입구를 가리지 않는다. 실제 건조 대기는 없다. |
| 후기 벽 | A 뒤 서쪽 벽 | 왼쪽 약 35~55도. A 옆 벽을 바라보는 홈에서 가까이 읽는다. | 손님 결과를 장부 확인과 이어 보되 읽는 사람이 길을 막지 않는다. |
| 재료 서랍 | B 뒤 북서쪽 벽 | 왼쪽 약 20~35도에서 서랍 구역을 식별한다. 이름·취약성은 B에서 읽는다. | 재료를 가지러 시험판까지 돌아갈 필요가 없다. |
| 시험판 | C 뒤 옆방의 안쪽 벽 | 정문 오른쪽 약 15~30도에서 옆방 입구가 보인다. 시험판 전체는 C에서 옆방을 향해 보면 드러난다. | 효과가 정문·진열대 방향으로 나가지 않도록 벽과 시험 방향을 정한다. |

시험 옆방은 넓게 수식의 최대 반경 4m를 벽·작업 위치와 대조해 확인한다. 벽이 적용을 막는 v1.2 규칙을 이용하되, 시험의 허용 대상·복구·자원 처리 방식은 T1·T2와 맞춘다. 배치만으로 시험 효과의 완전 차단이 구현되었다고 가정하지 않는다.

## 2. 물레목 마을

### 2.1 중심 마당과 이동 거리

공방은 중심 마당 P의 남쪽, 상점은 서쪽, 게시판은 동쪽, 출정길은 북쪽이다. 길을 건너기만 하면 필요한 장소가 보이는 작은 생활 구역으로 잡는다. 모든 거리는 P를 경유한 보행선이다.

| 장소 | P에서의 위치·거리 | 공방 정문에서 거리 / [추정] 이동 | 역할 |
|---|---|---|---|
| 여백 공방 | 남쪽 12m | 기준점 | 정문에서 P·출정길이 보인다. |
| 리네 상점 | 서쪽 12m | 24m / 8초 | 구매 창구는 마당을 향한다. 상점 깊숙이 들어가는 별도 이동을 요구하지 않는다. |
| 모험가 게시판 | 동쪽 9m | 21m / 7초 | 읽는 홈을 길 옆으로 빼고, 공방 응대 자리에서 정리하는 주문 정보와 연결한다. |
| 에다 수레 자리 | 북서쪽 9m | 21m / 7초 | P와 출정길 양쪽에서 수레 변화가 보인다. |
| 보린 작업대 | 북동쪽 15m | 27m / 9초 | 뒤편 골목·건조관과 한 화면에 들어오는 자리다. |
| 도토 관측 자리 | 북쪽 출정길 옆 18m | 30m / 10초 | 출발 전에 들를 수 있고 출입문을 막지 않는다. |

**글 연결:** 공방–P–G가 남북 주길이다. P의 서쪽 가지에는 리네·에다, 동쪽 가지에는 게시판·보린이 있다. 보린 작업대 뒤에는 공방 쪽에서도 입구가 보이는 짧은 골목이 붙는다. 주길 유효 폭 4m, 생활 가지 3m로 잡고 수레·대기 NPC를 폭 밖으로 뺀다.

후반 입구를 마을 안에 억지로 나란히 놓기보다 출정문 하나를 공유한다. 교통수단·전환 연출·화면은 확정하지 않는다. **함께 출발할 때 목적지를 정하고, 개인 귀환 때는 그 지역의 입구→마을→공방으로 돌아온다.** 하루 중 다른 지역으로 갈아타는 규칙은 추가하지 않는다.

마을 이동 목표는 방향 전환 여유 30초를 포함해 **하루 120초 이내**다. 24분의 약 8.3%이며, 공방·던전 몫에 이미 포함되는 시간이다. 출정 전 22초와 귀환 후 22초를 별도 분량으로 더하지 않는다. 후반 지역 전환 시간이 늘어나면 T4의 하루 시간표에서 다시 측정한다.

모든 손님을 매일 방문하는 일을 전제로 하지 않는다. 장부와 출고 기능은 v1.2의 공방 흐름을 유지하고, 납품 결과를 보러 가는 길은 출정·구매 이동에 겹치게 한다. 위 합계는 세 경로를 모두 걷는 보수적인 비교값이다.

## 3. 물레종이소 — 3구역

### 3.1 지도 개념과 연결

입구에서 마당·세척실·건조실이 안쪽으로 이어지고, 같은 구역의 낮은 작업길과 높은 점검길이 나란히 간다. 높은 길은 물때가 올라와도 12분 종료 직전까지 걷는 기본 귀환로다. 잔향 방·보조길은 아래 세 구역에 딸린 공간이며 제4구역으로 세지 않는다.

낮은 길의 폐쇄는 걸어서 건널 수 없는 구간을 뜻하며 수영·잠수 기능을 새로 요구하지 않는다. 저지대마다 높은 길로 오르는 고정 경사를 두고, 단계 전환 중 서 있는 사람을 벽이나 문 사이에 가두지 않는다. 전환 순간의 밀림·충돌 처리는 T1에 넘긴다.

### 6.1 자연스러운 공동 작업 배치 [추천]

광차 정지용 접착 바닥과 짐 내리는 접근점을 가까이 두어 두 사람의 정상 행동이 만날 수 있게 한다. 열로 접착을 풀면 광차도 다시 움직이므로 받침·정지 위치를 보고 수습한다. 다른 장면은 먹을 유도하는 채집자와 동료 작업등, 탄성 통의 당김과 새 충돌이다. 사고를 강요하거나 웃음 횟수를 보상으로 삼지 않는다.

공방 선반·작업대 옆 받침 위치는 기존 사용 가능한 칸 안에서 바꿀 수 있다. 필수 통로·가공 설비는 없애지 않는다. 컨베이어·설비 합성은 추가하지 않는다. 자세한 공정 판단은 W02를 따른다.
