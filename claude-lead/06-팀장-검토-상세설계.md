# 팀장 검토 — Codex 상세 설계 v1

2026-09-22 · 대상: `05-codex-상세설계-reply.md` (Codex 원본 스레드, 약 17분 작업)

## 결론
**채택합니다.** 룬 문법, 속성 반응, 하루 흐름, 스파이크 1 계획이 서로 맞물리고, 범위를 작게 잡았습니다. 사용자에게 물을 것은 2개로 줄였습니다(아래).

## 좋은 점
- **"문장은 모두 허용하고, 결과는 같은 규칙으로 계산한다"**는 원칙. 확률 실패 없이 원인이 보이고(`열 → 접착 해제` 표시), 이상한 조합도 거절하지 않습니다.
- 동사 7개의 기본 효과·유지시간, 대상 6개의 범위, 수식 5개의 장점·대가에 시작값까지 붙였습니다.
- 기존 스크롤 10종 중 룬 문장으로 안 되는 2종(마른 바람, 돌아오는 점선)을 숨은 기능으로 때우지 않고 솔직하게 표시했습니다.
- 표에 없는 속성 조합은 추가 반응을 만들지 않는다는 규칙으로 범위를 막았습니다.
- 하루 24분을 공방 12분 + 던전 12분으로 나눠 "중간" 포지션에 맞췄습니다. 공방은 4명이 한 장을 돌려 만지는 방식이 아니라, 서로 다른 주문을 동시에 처리하는 방식입니다.
- 후기·신문 문장 틀이 "건조한 정산 문체"를 잘 살렸습니다. 예) "반품 사유를 제품 결함에서 독해 부족으로 정정합니다."
- **팀장 리뷰의 오류를 바로잡았습니다.** 리뷰의 정산서 예시("구조에 사용 −150G")는 재료비를 이미 낸 상품의 값을 한 번 더 빼는 이중 차감이었습니다. Codex 안은 "예상 판매가 150G 포기"로 기록만 하고 돈은 다시 빼지 않습니다.
- 스파이크 1을 룬 7개 = 동사 3(붙어라·달궈라·튕겨라) + 대상 2(바닥·너) + 수식 2(잠깐·넓게), 12문장으로 좁혔고, 무엇을 "사건 1회"로 셀지까지 정했습니다.
- 옛 구현 재사용은 전부 [추정]으로 두고, 데이터 에셋이 인스턴스 상태를 관리하지 않는다는 점을 공식 문서로 확인했습니다.

## 고칠 점 / 보완 제안
1. **스파이크 1에 "구조" 동사가 약합니다.** 사용자가 고른 재미는 "사고와 구조로 이어지는 협동 소동"인데, 가장 직관적인 구조 문장인 `당겨라 + 너`가 빠졌습니다. 1차는 Codex 구성대로 하되, 결과에 따라 `튕겨라`를 `당겨라`로 바꾼 2차 회차를 권합니다.
2. **던전 12분 종료 규칙의 강도**는 사용자 결정으로 올립니다(아래 질문 1). 팀장 대안: 물때에 떠밀려 입구로 나오고, **물에 약한 재료만 망가지는** 방식. 속성 규칙(젖음)과 이어지고, 가방 전체를 잃는 것보다 부드럽습니다.
3. 붙어라 + 오래 = 24초 접착은 답답할 수 있습니다. 손으로 떼기(2~3초)가 있어 괜찮지만, 스파이크의 "답답함" 관찰 항목에서 꼭 확인합니다.

## Codex 질문 중 팀장이 정한 것 (사용자가 원하면 뒤집을 수 있음)
| Codex 질문 | 팀장 결정 | 이유 |
|---|---|---|
| `너`를 몬스터까지 확장? | **확장.** "가리킨 생물" | 공격과 구조가 같은 문법이 됩니다. 몬스터에 붙어라를 거는 장면 자체가 재미입니다. |
| 휴대 도안판 2칸의 뜻 | **완성 문장 2개 저장** | 리뷰에서 뜻이 모호했던 부분입니다. Codex 해석이 문법을 해치지 않습니다. |
| 기존 상품 기능 조정 | **조정 허용.** 임시 봉합 → 접착 중심, 마른 바람 → 조합 작업, 돌아오는 점선 → 수동 표식 | Codex가 만든 상품이라 사용자 확정 사항이 아닙니다. 나중에 새 지역에서 "불어라" 같은 룬이 생기면 되살립니다. |
| 몬스터 재료 상인 판매 | **던전이 주 공급처, 상인은 소량·고가 보충** | 리뷰 문장 자체의 모순이었고, 리뷰의 원래 뜻이 이쪽입니다. |
