## 0. 결론
1. **문장 조립 = 활자 조판.** 룬은 나무 활자, 저장한 도안은 굳힌 "판"이다. 활자를 집어 판틀에 끼우고, 판을 인쇄기에 꽂고, 손잡이를 당긴다. 조작은 전부 "가까이 가져가면 달칵 붙는" 방식이라 실패가 없다.
2. **공방의 중간물은 전부 들고 옮기는 물건이다.** 주문지, 먹병, 판, 스크롤 묶음, 납품 상자. 들고, 건네고, 던지고, 떨어뜨릴 수 있다. 협동은 "물건을 건네는 것"에서 자연스럽게 생긴다(Overcooked·Schedule I 계열의 오마주, 단 시간 제한 실패는 없음).
3. **손맛 = 짧은 손동작 + 좋은 소리 + 쌓이는 결과물.** 인쇄된 장이 출력대에 쌓이고, 봉인 밀랍이 "척" 찍히고, 돈통에 동전이 떨어진다.
4. **공방에도 사고가 있다.** 먹병이 깨지면 그 먹의 성질이 바닥에 번진다(탄성 먹이면 다 같이 튄다). 시험실에서는 공짜로 마음껏 사고를 낸다.

## 1. 공방 배치 위의 물건과 손동작

### 1.0 네 공정과 넘겨받기

| 공정 | 손으로 하는 일 | 반드시 남길 판단 | 넘겨줄 정보·소품 |
| --- | --- | --- | --- |
| 응대 | 주문지 읽기·판 선택·장수 표시 | 기존 판이 현재 사용처에도 맞나 | 주문 번호·문장·작업 단위·수량 |
| 먹 | 원료 갈기·먹병 채우기·운반 | 지금 갈 몫과 원료로 남길 몫 | 동사명·회분 눈금·주문/출정 표시 |
| 인쇄 | 활자 조립·시험·판 저장·묶음 인쇄 | 수정 후 시험할까, 기존 판으로 반복할까 | 판 버전·실제 예약 수량·완료 장수 |
| 포장 | 조건 확인·봉랍·상자/진열/휴대 분류 | 납품·판매·출정 중 어느 재고로 둘까 | 적합 표시·봉인 표시·사용상 주의 |

\[추천\] 인쇄는 **장별 완료**를 거래 단위로 삼는다. 장 하나를 완료할 때 그 장의 예약 원료를 소비하고 미봉인 완제품 한 장을 만든다. 묶음 취소는 남은 장의 예약만 풀고, 이미 완료한 장을 지우거나 환불하지 않는다. 이는 현재 “예약/소비 분리”를 더 닫는 적용안이며 W02·T8에 같은 시점으로 적어야 한다.

| 인원 | 업무량·참여 방법 |
| --- | --- |
| 1인 | 공정 순서대로 판단. 갈기·인쇄 반복은 자동 처리 가능. 시험과 적합 확인은 생략하지 않음 |
| 2인 | 응대/시험과 먹/인쇄를 병렬로 시작. 포장·출정 몫은 서로 넘겨받고 다음 날 역할 변경 가능 |
| 3\~4인 | 주문 판·개인 시험·먹 준비·포장을 병렬 진행. 두 판틀은 개인 조립을 지원하되 직업 독점 권한 없음 |
| 늦게 접속 | 그날 수락 수량은 고정. 공방 업무 가능, 출정은 다음 날. 완료한 사람의 시험을 개인 완료로 대신 기록하지 않음 |

역할과 권한은 독점하지 않는다. 주문지를 받은 사람과 판을 시험한 사람이 달라도 된다. 다음 주문의 담당 물건은 원하는 사람이 가져가고, 편집 중인 판에는 기존 이름표를 붙인다. 숙련자는 조건·시험 결과를 전달하며 다른 사람의 선택을 돕는다.

#### 계획 재고와 실제 예약
\[추천\] 선반·주문 카드의 기존 표시로 네 몫을 보여 준다. 새 창고 화면을 따로 늘리지 않는다.

| 상황 | 표시·처리 |
| --- | --- |
| 종이10장, 주문4장·출정4장 계획 | 계획 여유2장. 계획은 다른 사람의 사용을 막지 않음 |
| 주문4장 인쇄 시작 | 실제4장 예약. 다른 인쇄·급조는 이4장을 소비할 수 없음 |
| 다른 사람이 예약 밖 종이3장 사용 | 계획 여유가 부족1장으로 바뀜. 추가 구매/출정 장수 변경 중 선택 |
| 인쇄2장 완료 뒤 취소 | 종이2장·먹2장분 소비, 완료품2장 유지, 나머지2장 예약 해제 |
| 봉인 전·후 | 미봉인품은 물에 약함. 공방 포장 완료품은 물때에 보존. 봉인은 추가 마법 성능을 주지 않음 |

**배치 선택:** 기존 선반·작업대 옆 받침의 사용 가능한 칸에서 판·먹병·상자의 보관 위치를 바꾼다. 필수 통로·가공 효과는 유지한다. 자동 분류와 메뉴 보조는 혼자서도 선택 가능하며 새 컨베이어·설비 합성은 넣지 않는다.

\[사실\] 배치는 T3 §1.1: 정문 E, 교차점 J, A 응대·장부(남서), B 먹·재료(북서), C 문장·인쇄(북동), D 검사·포장·출고(남동), C 옆 시험 옆방. 아래 시간은 T4 §1.1 값에 맞춘다.

### 1.1 A — 응대·장부 카운터

#### 주문 카드 — 사용 조건과 계약
\[추천\] 주문지 앞면에는 손님의 문장과 아래 항목을 표시한다. 대표 도안은 예시이며, 합격 조건이 같으면 수락 후에도 다른 문장으로 납품할 수 있다. 수락 전에는 작업 수·사용 조건·대표 견적을 고정한다. 대안의 실제 장수와 재료량은 별도로 기록하며 계약을 다시 계산하지 않는다.

| 항목 | 카드에 쓰는 내용 | 예: M04 관 고정 |
| --- | --- | --- |
| 사용 상황 | 손님이 하려는 일 | 양손으로 나사를 조이는 동안 맞댄 관 고정 |
| 작업 한 단위 | 사람·설치물·회수 작업 중 무엇을 세는가 | 관 결합부 한 곳 |
| 반드시 필요한 결과 | 대상·효과·유지 조건 | 비생물 관, 접촉 결합, 작업 중 고정 |
| 피해야 할 결과 | 같은 효과여도 곤란한 사용 | 얼굴/몸 접착, 허공 고정, 열로 수리했다고 판정 |
| 대표 판 / 대체안 | 적합한 알려진 문장, 필요한 장수 | 붙어라+물건+오래. 대체는 작업 검증 후 목록 등록 |
| 수량·부재료·대금 | 줄별 장수·부재료·확정 총액 | 수락 인원 기준으로 고정 |
| 마감 설명 | 필수 날짜·선택 기한 구별 | 고유 의뢰는 소개일 이후 보류 가능 |

종이 시험에서는 문장·대상·지속 같은 읽을 수 있는 규격을 판정한다. 실제 물리 작업의 성공은 열·힘·충돌 계수를 정하고 검증해야 한다. “오래면 무조건 수리 성공” 같은 결과를 도안 이름으로 보장하지 않는다.

의뢰32건의 합격 조건·대표 견적·대안의 실제 장수는 [의뢰 판정·납품 규격](W14-의뢰판정-납품규격.md)에 모은다.

| 물건 | 손동작 | 시간 | 협동·재미 |
| --- | --- | --- | --- |
| **손님 종** | 손님이 오면 "딸랑". 카운터에 서면 대화 시작 | — | 누가 받으러 갈지 서로 떠밀기 |
| **주문지** | 대화가 끝나면 카운터 위 인쇄 슬롯에서 주문지 한 장이 나온다. 집어 든다 | 주문 1건 25초(T4) | 종이 한 장이 **실물**이라 들고 뛰어가 동료에게 건넨다 |
| **수락 도장** | 주문지에 "수락" 도장을 쾅. 보류하려면 "보류" 도장 | 1초 | 도장 소리가 하루의 시작 신호 |
| **주문 줄** | 조판대 위에 가로질러 걸린 줄. 주문지를 집게로 건다 → 공방 어디서든 보인다 | 2초 | T2 "조건을 도안판 옆에 고정"을 실물로 |
| **장부** | 카운터의 두꺼운 장부. 펼치면 오늘 주문·재고·지난 후기(W11 §1·2.7\~2.8 화면) | — | 한 명이 장부를 봐도 공방이 멈추지 않음 |
| **돈통** | 카운터 밑. 자유 판매 대금이 동전으로 떨어져 쌓인다 | — | 짤랑 소리, 쌓이는 높이가 곧 오늘 매출 |

- 길드 의뢰는 마을 게시판에서 **의뢰지를 떼어 와** 같은 주문 줄에 건다. 거래처 수신기 설비(1,580G)를 사면 카운터 옆 **종이관 우편**으로 의뢰 캡슐이 "퐁" 떨어진다(주문 미리보기, v1.2 6.3).

### 1.2 B — 먹·재료

| 물건 | 손동작 | 시간 | 협동·재미 |

- 맷돌에 원료를 넣지 않고 돌리면 헛돈다. 넣는 순간 원료 이름과 나올 먹 회분이 벼루 위에 뜬다.

| **판 선반** | 굳힌 판을 꽂아 두는 벽 선반. 도안 목록 화면과 같은 내용 | 꽂기 1초 | 선반이 차는 게 곧 공방 역사 |
| **인쇄기** | ① 판을 꽂는다 ② 수량 다이얼을 돌린다(1\~10) ③ **큰 손잡이를 당긴다** → 3초마다 한 장씩 출력대에 쌓인다 | 설정 4초 + 3초/장(T4) | 출력되는 동안 다른 일. 먹·종이 부족이면 해당 색 램프가 깜빡이고 이유가 뜬다 |
| **손판 2개** | 허리에 차는 작은 판(휴대 도안판 2칸). 판 선반에서 판을 대면 손판에 복사된다 | 2초 | 던전에서 급조할 두 문장(v1.2 4.6) |

**판과 도안의 관계 \[추천\]**
- 판은 도안 데이터의 "몸"이다. 판 선반과 도안 목록은 같은 목록이다. 판을 잃어버리는 일은 없다(던전에 가져가는 건 손판뿐이고 손판은 장비다).
- 판을 고치면 새 판 버전이 된다. 인쇄 중인 묶음은 시작할 때의 판 버전을 유지한다(원고09의 동시 작업).
- 판을 다른 사람에게 건네는 것 = 그 도안을 쓰라고 권하는 것. 게스트는 판 사본을 자기 공방으로 가져갈 수 있다(\[사실\] D1-04).
- 모든 손동작에는 같은 자리에서 쓰는 **메뉴 대체**가 있다(판 선반 앞에서 목록 선택 → 캐릭터가 알아서 판을 꽂음). 접근성과 숙련자 속도를 위해서다.

**새 규칙 \[추천·D7\]:** 납품·진열은 **봉인품만** 받는다. 봉인은 이미 포장 과정의 일부라 추가 비용·시간은 없다(\[사실\] v2.0 §4.4). 탐험용은 봉인하지 않아도 되지만, 미봉인품은 물때에 파손되므로 대부분 봉인해서 들고 간다.

**납품과 수거 \[추천\]**
- 마을 주문의 납품 상자는 **해 질 녘 에다**가 수레로 가져간다. 에다가 매일 공방에 들르는 이유가 된다.
- 길드 주문 상자는 **무로**가 가져간다. 무로는 창고 주문 대리 접수도 맡는다(D6-04).
- 가져간 뒤 다음 날 아침 후기 벽에 결과가 붙는다.

### 1.6 자유 판매 손님
- 이름 없는 손님 NPC 4종(마을 사람 2, 모험가 2)이 개점 중에 들어와 진열대를 둘러보고 물건을 집어 가며 돈통에 동전을 넣는다.
- 자유 판매 수요 상한은 1\~4인 2·3·4·5장이다 \[추천·D8, 검증 전\]. 계약 납품·재주문·화제 주문·반복 계약은 이 상한에 포함하지 않는다. 초과 진열품은 재고로 남는다.
- 모두 던전에 가 있어도 진열대 판매는 계속된다(돈통에 쌓여 있음). 귀환하면 동전 소리가 반긴다.

## 3. 공방 사고 — 쏟은 먹
**규칙 \[추천·D7\]:** 먹병이 1m 넘는 높이에서 떨어지거나 던져져 부딪히면 깨진다. 그 자리에 **반경 1m 먹 웅덩이**가 20초 동안 남고, 그 먹의 성질이 바닥 속성으로 적용된다. 병에 있던 먹은 잃는다. 걸레로 2초면 닦이고, 20초 뒤 저절로 마른다.

| 쏟은 먹 | 바닥에 생기는 것 | 벌어지는 일 |
| --- | --- | --- |
| 빛나라 | 빛(발광 얼룩) | 밟은 발이 빛난다. 무해 |
| 붙어라 | 끈적임 | 밟은 발·떨어진 물건이 붙는다. 손 해제 2초 |
| 튕겨라 | 탄성 | 밟거나 떨어지는 것이 튄다. 모두가 통통 |
| 달궈라 | 약한 열 | 닿으면 뜨거움(아군 원인 → 쓰러짐 없음, D1-01). 젖어 있으면 김 |
| 가려라 | 먹물 | 밟고 다니면 먹 발자국. 조명을 덮는다 |

- 설비(인쇄기·맷돌·봉인대)는 쏟은 먹·마법에 망가지지 않는다. 사고는 사람과 소품에만 난다.
- 먹병은 내려놓을 땐 절대 깨지지 않는다. **던지거나 튕기다가 떨어뜨릴 때만** 깨진다. 짜증이 아니라 "누가 던졌어!"의 웃음이어야 한다. 스파이크 2에서 웃음/짜증을 설문한다.
- 쏟은 먹 사건도 원인 기록에 남는다("\[이름\]이 던진 튕겨라 먹병 → 탄성 바닥 → 3명 튕김"). 주간 신문 소재가 된다.
**실제 스크롤 사고:** 재고 스크롤은 공방에서도 찢을 수 있다(돈이 드는 진짜 사용). 공방 소품(의자·상자·종이 더미)은 물리로 움직인다. 손님 NPC가 효과에 맞으면 다치지 않고 한마디 한 뒤, 다음 날 후기 벽에 **"공방 방문 후기"**가 붙는다. 예: "공방 방문 중 발광했습니다. 제품 설명과 일치합니다. 다음 방문은 해가 진 뒤로 하겠습니다."

### 3.1 정상 작업이 만나는 사고
\[추천\] 광차 고정과 하역, 발광 채집과 먹막, 탄성 통 회수처럼 각각 타당한 작업이 같은 곳에서 만날 때 사고가 생긴다. 사고6건의 작업·원인·수습 표는 [생물·전투 상세](W04-생물-전투.md)에 모은다. 안전하게 끝낸 작업도 성공이며 고의 사고를 보상 목표로 만들지 않는다.

스파이크1은 기존7룬의 접착·열·충돌부터 검증하고 물건·먹막·당김 조합 전체는 이후 확인한다.

### 3.2 손 수습 뒤 짧은 보호 \[추천·D8\]
동료가 만든 접착·먹막을 손으로 제거하면 **그 상태에서 풀린 플레이어**에게 같은 상태의 동료 문장 재부여를 2초 동안 막는 값으로 시작한다. 자신이 떼든 다른 동료가 대신 떼든 보호 대상은 같다. 생물·환경·자기 문장은 보호하지 않으며 같은 막 재접촉과 새 문장을 구분한다. 작은 종이 표시로 이유를 알린다. 아군 당김의 반복 방해는 별도 관찰 항목이다.

## 8. 구현 메모
- 들 수 있는 물건은 공통 `Carryable` Component 하나(서버 권한, 든 사람 표시, 던지기·떨어뜨리기). 공방 물건에 소유권은 없다(공용).
- 스테이션은 상호작용 볼륨 + 달라붙는 소켓(판틀 칸, 인쇄기 색 구멍, 봉인대 자리).
- 판 = 도안 ID를 가진 물건. 판을 들고 있어도 도안 데이터의 원본은 공방 저장에 있다(T8 §1.2).
- 쏟은 먹 웅덩이 = 기존 표면 속성 구역을 재사용(T8 §2). 새 반응 없음.
- \[추정\] v2.0·T7의 공방 기능 예산 대비 추가 6\~10작업일(물건 물리화, 쏟은 먹, 판 물건, 시험 인형).
