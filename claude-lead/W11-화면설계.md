# W11. 화면 설계 — 핵심 화면 배치와 흐름

2026-09-23 · 기획 팀장(Claude) 직접 작성
기준 [사실]: T2 §2(정보 구조·원인 카드·핑·점유율 15/25/40/60%), §4(색+형태+글자, 글자 24px·자막 32px 기준, 100~200% 확대). 그림 시안은 `기획 도면집`(HTML).

## 0. 결론

1. **UI는 종이다.** 모든 창은 종이 쪽지·장부·신문처럼 보이고, 확인은 도장, 경고는 붉은 인주, 닫기는 종이를 접는 동작.
2. **공방에서는 설비를 바라보는 게 곧 화면이다.** 조판대 앞에 서면 판틀이 가까워지고 옆에 설명 쪽지가 붙는다. 전체 화면 메뉴는 장부·신문·정산서·설정뿐.
3. **던전 화면은 네 모서리만 쓴다.** 가운데는 조준과 세계를 위해 비운다(15% 이내).
4. 별도 로비가 없다. **공방이 로비**다. 친구가 들어오면 공방 문을 두드리고 들어온다.

## 2. 핵심 화면 배치

### 2.1 조판대 (문장 조립)

```
┌──────────────────────────────────────────────────────────────┐
│ [주문 줄: 에다 M01 "짐에 짧은 빛" ✔대상 ✔수식]                │
│                                                              │
│            ┌──────────── 판틀 ─────────────┐   ┌─ 설명 쪽지 ──┐│
│   활자     │  (●빛나라)  [■물건]  (✿잠깐)  │   │ 빛나라+물건+잠깐│
│   서랍     └───────────────────────────────┘   │ 대상: 조준 소품 1│
│  ●●●○○○○                                        │ 준비 0.2초      │
│  ■■□□□□                                         │ 지속 60초       │
│  ✿○○○○                                          │ 먹: 빛 1회분    │
│  (빈 칸 = 아직 모르는 룬)                          │ 원가 6G · 판매가 20G│
│                                                  │ 주의: 사람에 쓰면 눈부심│
│   [시험지 뽑기]  [판 굳히기]  [판 선반에서 불러오기] └────────────┘│
└──────────────────────────────────────────────────────────────┘
```

- 활자 서랍은 왼쪽에 실제 서랍으로 보이고, 빈 칸은 반투명 빈 활자.
- 주문 줄의 조건은 판틀 위에 계속 보이고, 세 칸이 차면 조건 옆에 ✔ 또는 ✘가 찍힌다. **엉뚱한 문장도 굳힐 수 있다.**
- 편집 중인 사람 이름표가 판틀 모서리에 붙는다(공동 편집, T2 §1.2).

### 2.2 던전 표시

```
┌────────────────────────────────────────────────────────────────┐
│ 행상단                       물때 ◔ 07:42  "물때 상승"          │
│ ● 준(세척실) 휘청임           ─────●───── (6·9·12 눈금)         │
│ ● 민(건조실)                                                    │
│ ◌ 서(공방·오늘 재입장 불가)                                      │
│                                                                │
│ 내 상태                               +                         │
│ [붙음 3.2초 ·E 떼기]              [대상: 부풀달팽이 · 너]         │
│                                                                │
│                                                                │
│                                         손판 ①빛+물건+오래 ②붙+너+잠깐│
│ 핑 ▸ 여기·위험·도와줘·가져가·돌아가자·준비됐어    [손: 되감는 손 ×2]  │
│                                          등짐 ▮▮▮▮▯▯ (4/6)      │
└────────────────────────────────────────────────────────────────┘
```

- 물때 시계는 **물레 바퀴 모양**. 6·9분 눈금을 지날 때 증기 기적 소리와 함께 한 번 흔들림(W03 §3.3).
- 동료 목록의 상태는 글자 + 모양(● 정상 / ◐ 휘청임 / ✖ 쓰러짐 / ◌ 귀환).
- 조준 중앙에는 대상 이름과 **예상 범위**(옅은 원). 찢은 뒤 확정 범위는 진한 선(T2 §1.3).
- 물에 약한 물건을 들고 9분이 넘으면 등짐 칸 옆에 파란 물방울 + "물에 약함 2".

### 2.3 원인 카드

```
┌───────────── 원인 카드 #1043 ─────────────┐
│ 07:12  민이 찢음: 달궈라 + 바닥 + 잠깐       │
│ 이전 상태: 물기 · 준이 만든 접착막           │
│ 반응: 물기가 열을 먼저 씀 → 김 발생           │
│      접착을 풀 열 부족                        │
│ 결과: 김 · 접착 유지                          │
│ 지금 할 수 있는 것: E 손으로 떼기(2초)         │
│ [사진기로 찍힌 사건] 📷                        │
└──────────────────────────────────────────┘
```

### 2.4 정산서

```
┌──────────── 여백 공방 · 12일차 정산 ────────────┐
│ 현금                                             │
│   의뢰 대금   M10 +70G · A06 +150G                │
│   자유 판매   +20G                                │
│   구매       −46G                                 │
│   ─────────────── 오늘 현금  +194G   [도장: 흑자] │
│ 상품 사용                                         │
│   동료 구조에 사용: '당겨라+너+잠깐' 1장            │
│   (예상 판매가 20G — 참고, 현금에서 빼지 않음)      │
│ 물때                                              │
│   보존: 등심이끼 2 · 봉인 스크롤 3                   │
│   파손: 먹주머니 1 · 미봉인 '붙어라+물건+잠깐' 1     │
│ 사건                                              │
│   발광 4 · 접착 2 · 튕김 1 · 구조 1                  │
│ 내일                                              │
│   주문 2건 대기 · 재주문 1 · 신문 발행 없음           │
│                              [접어서 닫기]         │
└──────────────────────────────────────────────┘
```

- 현금·사용·파손을 **다른 칸**에 적는다(이중 차감 금지, v1.2 10.2).
- 보존과 파손을 **나란히**(가방을 다 잃었다는 오해 방지).

### 2.5 신문

```
┌──────────────── 물레목 주간 · 제2호 ────────────────┐
│ [1면 사진 — 이번 주 찍은 사진 중 선택]                  │
│ ■ 화제의 사고                                        │
│   물레종이소 건조실에서 '튕겨라 + 너 + 넓게'가 …         │
│ ─────────────────────────────────────────           │
│ ■ 옛 제지조합 반출 대장 일부 공개(C05)   ■ 짧은 소식    │
│ ■ 다음 주 수요: 한 겹 완충 +2장          ■ 광고: 리네 상점│
│                 [신문 저장(PNG)]  [접기]               │
└──────────────────────────────────────────────────┘
```

### 2.6 출정 준비대

```
┌──────────── 출정 준비 ────────────┐
│ 목적지: [물레종이소 ▼]  상태: 서쪽 점검일 │
│ 행상단  준 ✔ · 민 ✔ · 서 … 준비 중     │
│ 탐험 선반 → 등짐: 파티 합계 6장         │
│ 손판: ①______ ②______  (판 선반에서)    │
│ 물에 약한 것: 바탕 종이 4                │
│ ⚠ 먼저 돌아오면 오늘 다시 못 들어갑니다   │
│              [준비됐어]                 │
└──────────────────────────────────┘
```

- 모두 "준비됐어"를 누르면 출정문이 열린다(함께 출발, U08). 늦게 온 사람은 공방에 남아 일할 수 있다.

## 3. 입력 기본값

| 행동 | 마우스·키보드 | 게임패드 |
|---|---|---|
| 이동 / 보기 | WASD / 마우스 | 왼쪽 / 오른쪽 스틱 |
| 상호작용·집기·놓기 | E | X |
| **찢기**(손의 스크롤) | 왼쪽+오른쪽 클릭 동시 또는 F 누르고 있기 0.2초 | RT+LT 또는 RB 누르고 있기 |
| 스크롤 바꾸기 | 휠 / 1~6 | 십자 좌우 |
| 손판 급조 | G 누르고 있기(6초) | Y 누르고 있기 |
| 던지기 | E 누르고 있다가 놓기 | X 누르고 있다가 놓기 |
| 원인 카드 | R | 십자 위 |
| 핑 휠 | 가운데 클릭 또는 Q 누르고 있기 | LB 누르고 있기 |
| 가방 | I | 보기 버튼 |
| 장부 | Tab | 십자 아래 |
| 누르고 말하기(설정 시) | V | 없음(항상 켜짐 기본) |
| 실전화 컵 말하기 | 컵을 든 채 V 또는 목소리 | 컵을 든 채 목소리 |
| 사진 찍기 | 사진기를 든 채 왼쪽 클릭 | RT |

- 모든 키는 바꿀 수 있고, "누르고 있기"는 "한 번 눌러 켜고 끄기"로 바꿀 수 있다(T2 §4).
- 찢기를 **양쪽 클릭 동시**로 둔 이유: 두 손으로 찢는 느낌. 한 손 입력 대체 필수.

## 4. 설정 수첩

| 쪽 | 항목 |
|---|---|
| 화면 | 해상도·창 모드·프레임 제한·밝기·**글자 크기(100~200%)**·자막 크기·흔들림·시야각 |
| 소리 | 전체·배경음·효과음·NPC 옹알이·안내음 |
| 음성 | 음성 채팅 켜기/끄기·말하기 방식(항상/누르고)·마이크 감도·**상태 목소리 효과 끄기**·사람별 음량·스트리머 모드 |
| 조작 | 키 재지정·누르고 있기 대체·마우스 감도·게임패드 |
| 접근성 | 색각 보정(3종)·룬 모양 강조·자막 배경·중요 소리 시각 표시·손 수습 입력 간소화 |
| 언어 | 한국어 / English |
| 공방 | 자동 분류(W02 §4)·안내 수준(처음부터/핵심만/건너뛰기) |
