## 0. 결론
1. **UI는 종이다.** 모든 창은 종이 쪽지·장부·신문처럼 보이고, 확인은 도장, 경고는 붉은 인주, 닫기는 종이를 접는 동작.
2. **공방에서는 설비를 바라보는 게 곧 화면이다.** 조판대 앞에 서면 판틀이 가까워지고 옆에 설명 쪽지가 붙는다. 전체 화면 메뉴는 장부·신문·정산서·설정뿐.
3. **던전 화면은 네 모서리만 쓴다.** 가운데는 조준과 세계를 위해 비운다(15% 이내).
4. 별도 로비가 없다. **공방이 로비**다. 친구가 들어오면 공방 문을 두드리고 들어온다.

## 2. 핵심 화면 배치

### 2.1 조판대 (문장 조립)
\[추천\] 주문지의 목적·대상·최소 지속·시작 거리·피할 결과와 판의 실제 계산값을 함께 읽습니다. 상품명은 예시이며 동일 조건을 만족하는 다른 문장도 적합합니다.32건의 판정 규격은 [의뢰 판정·납품 규격](W14-의뢰판정-납품규격.md)에서 관리하며 이 화면에 표를 다시 복사하지 않습니다.

```plain text
┌──────────────────────────────────────────────────────────────┐
│ [주문 줄: 에다 M01 "짐에 짧은 빛" ✔대상 ✔수식]                │
│                                                              │
│            ┌──────────── 판틀 ─────────────┐   ┌─ 설명 쪽지 ──┐│
│   활자     │  (●빛나라)  [■물건]  (✿잠깐)  │   │ 빛나라+물건+잠깐│
│   서랍     └───────────────────────────────┘   │ 대상: 조준 소품 1│
│  ●●●○○○○                                        │ 준비 0.2초      │
│  ■■□□□□                                         │ 지속 60초       │
│  ✿○○○○                                          │ 먹: 빛 1회분    │
│  (빈 칸 = 아직 모르는 룬)                          │ 원가 6G · 판매가 20G│
│                                                  │ 주의: 사람에 쓰면 눈부심│
│   [시험지 뽑기]  [판 굳히기]  [판 선반에서 불러오기] └────────────┘│
└──────────────────────────────────────────────────────────────┘
```
- 활자 서랍은 왼쪽에 실제 서랍으로 보이고, 빈 칸은 반투명 빈 활자.
- 주문 줄의 조건은 판틀 위에 계속 보이고, 세 칸이 차면 조건 옆에 ✔ 또는 ✘가 찍힌다. **엉뚱한 문장도 굳힐 수 있다.**
- 편집 중인 사람 이름표가 판틀 모서리에 붙는다(W02 §1.3).
- 주문 조건은 효과·대상·지속·범위·사거리로 비교한다. 수식 이름이 다르다는 이유만으로 거절하지 않는다. 변경 재주문은 이전 주문과 달라진 조건 한 줄, 기존 판의 유지·수정 이유를 먼저 보인다. 예상 원가·실제 소모는 선택 문장 기준이며 수락한 계약 보상은 따로 고정해 표시한다.

### 2.2 던전 표시

```plain text
┌────────────────────────────────────────────────────────────────┐
│ 행상단                       물때 ◔ 07:42  "물때 상승"          │
│ ● 준(세척실) 휘청임           ─────●───── (6·9·12 눈금)         │
│ ● 민(건조실)                                                    │
│ ◌ 서(공방·오늘 재입장 불가)                                      │
│                                                                │
│ 내 상태                               +                         │
│ [붙음 3.2초 ·E 떼기]              [대상: 부풀달팽이 · 너]         │
│                                                                │
│                                                                │
│                                         손판 ①빛+물건+오래 ②붙+너+잠깐│
│ 핑 ▸ 여기·위험·도와줘·가져가·돌아가자·준비됐어    [손: 되감는 손 ×2]  │
│                                          등짐 ▮▮▮▮▯▯ (4/6)      │
└────────────────────────────────────────────────────────────────┘
```
- 물때 시계는 **물레 바퀴 모양**. 6·9분 눈금을 지날 때 증기 기적 소리와 함께 한 번 흔들림(W03 §3.3).
- 동료 목록의 상태는 글자 `+` 모양(● 정상 / ◐ 휘청임 / ✖ 쓰러짐 / ◌ 귀환).
- 조준 중앙에는 대상 이름과 **예상 범위**(옅은 원). 실제 적용 범위는 발동 판정 뒤 진한 선으로 표시한다(T2 §1). 단일 잠금 대상과 넓게의 발동 시 목록을 구분한다.
- 물에 약한 물건을 들고 9분이 넘으면 등짐 칸 옆에 파란 물방울 `+` "물에 약함 2".
- 수량 요청은 기존 핑 영역에 접힌 요청 3개까지 표시하며 재료명·문양·수량을 함께 쓴다. 첫날부터 공방·던전 사이 전달되고 미발견 산지는 표시하지 않는다.
- 동료의 접착·먹막을 손으로 제거한 뒤 그 막에서 풀린 플레이어에게 “동료의 같은 상태 재부여 보호 \[초\]초”라는 종이 표시를 붙인다. 타인이 대신 손 해제해도 같으며 생물·환경·자기 문장까지 면역이라고 보이지 않는다.

### 2.4 정산서

```plain text
┌──────────── 여백 공방 · 12일차 정산 ────────────┐
│ 현금                                             │
│   의뢰 대금   M10 +70G · A06 +150G                │
│   자유 판매   +20G                                │
│   구매       −46G                                 │
│   ─────────────── 오늘 현금  +194G   [도장: 흑자] │
│ 상품 사용                                         │
│   동료 구조에 사용: '당겨라+너+잠깐' 1장            │
│   (예상 판매가 20G — 참고, 현금에서 빼지 않음)      │
│ 물때                                              │
│   보존: 등심이끼 2 · 봉인 스크롤 3                   │
│   파손: 먹주머니 1 · 미봉인 '붙어라+물건+잠깐' 1     │
│ 사건                                              │
│   발광 4 · 접착 2 · 튕김 1 · 구조 1                  │
│ 내일                                              │
│   주문 2건 대기 · 재주문 1 · 신문 발행 없음           │
│                              [접어서 닫기]         │
└──────────────────────────────────────────────┘
```
- 현금·사용·파손을 **다른 칸**에 적는다(이중 차감 금지, v1.2 10.2).
- 보존과 파손을 **나란히**(가방을 다 잃었다는 오해 방지).
- 정상 조기 반출과 종료 안전 회수를 구분한다. 예시 수입은 1인 12일차 M10 70G `+` A06 150G `+` 자유 판매 20G = 240G, 구매 46G 차감 뒤 194G다. 주문 보상·소비 수치는 실제 정산 데이터를 사용하며 협동 예시에 이 1인 수치를 복사하지 않는다.

### 2.7 재고·준비와 수량 요청 \[추천·D8\]

| 함께 보이는 줄 | 계산·조작 |
| --- | --- |
| 공방 재고 | 현재 재료·먹·봉인품의 사용 가능량 |
| 주문에 필요 | 수락한 주문의 문장별 남은 장수, 실제 선택 문장으로 만들 비용 |
| 탐험에 남길 것 | 각자 휴대 6장·손판 2문장 계획. 계획 예약 켜고 끄기 |
| 추가 필요 | 주문·탐험 목표를 함께 할 때의 부족량, 한 번 눌러 수량 요청 |
| 판매 가능 | 계획에 남긴 몫과 확정 인쇄 예약을 구분해 자유 판매 후보 표시 |

계획분을 다른 용도로 쓰면 한 번 확인하고 공용 재고·계획을 같이 갱신한다. 진행 중인 인쇄 묶음의 확정 예약은 사용 불가이며 취소하면 미소비분만 풀린다. 같은 재료의 같은 공동 목표 요청은 합치고 서로 다른 목표는 용도를 보존한다. 최초값은 동시 3개·같은 사람 2초 재전송 간격. 목표 충족·취소 상태를 표시하고 아직 모르는 산지를 자동 안내하지 않는다.

**계약/진열 수량:** 계약 납품에 진열 상한을 씌우지 않는다. 자유 판매 상한 1\~4인 2·3·4·5장. A06은 각 줄을 올려 총 5·9·10·14장, 먹 10·18·20·28회분, 계약 보상 150·240·260·350G다. 수락 전 고정한 F와 주문당 B 1회를 표시한다.

### 2.8 개인 공방일지 \[추천·D8\]
\[추천\] 업적도 실제 사건·기여와 연결합니다.1인은 자신의 수량 요청을 계획으로 등록하고 부족 재료를 확보해 완료할 수 있습니다. 음성·다른 사람의 응답·반복 당김이나 먹막 방해를 완료 조건으로 삼지 않습니다.

별도 전체 화면을 늘리지 않고 장부의 도감·공방일지 탭을 쓴다. 내가 시험한 문장 / 원정 공유 발견 / 직접 관찰·조작 / 공동 제작·납품 / 캠페인 기념을 나눠 표시한다. 사건 당시 던전 원정 참가자는 공유 발견을 받고 직접 확인한 사람은 출처로 함께 남는다. 공방 작업자·이미 귀환한 사람은 공용 도감을 열람하되 새 발견을 자신의 목격 사실로 받지 않는다.

호스트 돈·재고·설비·룬·의뢰 진행은 복사하지 않는다. 미지 룬이 있는 개인 도안은 현재 공방이 배우기 전 제작 불가다. 기록은 서버 판정 사건과 연결하며 고객 사용·조건 판정 후기를 구분한다. 엔딩 뒤 장부·게시판에 기존 미완료 과제 4종을 모아 오늘 목표 하나를 선택한다(W06 §7.0).

### 2.9 저장·중단 화면
\[추천\] 새 전체 화면을 늘리지 않고 기존 장부/확인 쪽지를 씁니다.

| 상태 | 보여 줄 내용 |
| --- | --- |
| 저장 요청/진행 | “저장 중 — \[대상 기록\]”. 아직 성공 도장 없음 |
| 저장 성공 | “저장 완료 — \[저장된 시점\]”. 성공 응답 뒤 표시 |
| 저장 실패 | “저장하지 못했습니다 — \[확인된 이유\]”. 재시도/이전 저장 확인 선택을 구분 |
| 연결 중단·원정 복귀/입구 처리 | 공방·던전 위치, 참가 자리, 진행 중 거래/제작 상태를 사실대로 표시.09의 접속15예외에 해당하는 선택지만 표시하고 새 원정·재입장·성공·새 물품 자동 지급으로 표현하지 않음 |
| 개인 기록 | 공유 열람·직접 조작·목격을 구분. 타인의 돈/진행 복사 없음 |

정확한 복귀·마감·저장 판정은 [09. 협동·저장](../노션-원고/09-협동-저장.md)를 따릅니다. 중단된 날도 아직 저장 성공을 확인하지 않았다면 완료처럼 표시하지 않습니다.

## v2.1 입력 취소·손 수습 세부
진행 중 손 작업→열린 메뉴→든 도구→현장 행동 순서로 처리한다. 취소·메뉴 닫기 입력이 찢기·던지기로 이어지지 않는다. 자기 발/등을 조준하지 않고 내 몸의 막을 선택할 수 있다. 손 해제는 버튼 놓기/취소·거리 이탈·대상 소멸 때 중단하고 잠깐 시선 이탈은 유지한다. 다시 시작하면 처음부터, 보통2초·강한 접착만3초이며 같은 종류 재도장은 진행 시간을 초기화하지 않는다. 급조6초에 원재료 갈기 포함, 완료 전 취소는 소비/완제품 없고 이미 난 소음·시간은 남는다. 현장 문장 편집/교체·봉인은 하지 않는다. 키는 위 최신 조작표를 따른다.

튜토리얼 안내 건너뛰기는 해금·주문 완료·재료 지급의 지름길이 아니다.
