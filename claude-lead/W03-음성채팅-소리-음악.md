## 0. 결론
1. **근처 음성 채팅을 기본으로 켠다.** 가까이 있는 동료 목소리만 들리고, 멀어지면 작아지고, 벽 너머는 먹먹해진다.
2. **목소리는 게임 판정에 영향을 주지 않는다.** 몬스터는 목소리를 듣지 않는다. 마이크가 없거나 끈 사람도 똑같이 플레이할 수 있어야 한다(T2 원칙 유지). 긴장은 물때와 몬스터가 이미 만든다.
3. 대신 목소리를 **웃음 재료**로 쓴다. 내 몸에 걸린 상태가 목소리를 바꾼다(여과막을 쓰면 마스크 목소리, 튕기면 목소리가 출렁). 동료가 멀리 있을 땐 **실전화 컵**으로 이야기한다.
4. 스크롤을 찢을 때 소리 내어 외치면 **글자가 크게 번쩍이는 연출**만 붙는다. 효과는 같다.

## 1. 근처 음성 채팅

### 1.1 기본 규칙 \[추천·시작값\]

| 항목 | 값·규칙 |
| --- | --- |
| 들리는 거리 | 3m까지 원래 크기, 25m에서 0으로 줄어듦 |
| 방향 | 3D 위치로 들림(왼쪽 동료는 왼쪽에서) |
| 벽 | 벽·문 너머는 고음을 깎아 먹먹하게. 완전히 막지는 않음(두꺼운 벽 2장 이상이면 0) |
| 공방 ↔ 던전 음성 | 서로 다른 공간이라 **목소리는 들리지 않는다.** 6일 이후 실전화 컵으로 연결. 기본 핑·수량 요청은 첫날부터 공방·던전 사이에 전달 |
| 쓰러짐 | 쓰러진 사람의 목소리는 속삭임 거리(8m)로 줄어든다. 가까이 와서 들어 줘야 한다 |
| 입 움직임 | 목소리 크기에 맞춰 캐릭터 입이 움직이고 모자가 살짝 흔들린다 |
| 말하기 방식 | 기본 "항상 켜짐 `+` 목소리 감지". 설정에서 "누르고 말하기"로 변경 |
| 음소거 | 사람별 음소거·음량. 로비와 게임 안에서 모두 |
| 스트리머 모드 | 이름 숨기기, 음성 표시 숨기기 |
| 초대 기본값 | Steam 친구만 참가(공개 방 없음). 1.0에 공개 매칭 없음 |

### 1.2 상태가 목소리를 바꾼다 \[추천\]
클립이 잘 나오는 곳에만 짧게 넣는다. 설정에서 "목소리 효과 끄기" 가능(접근성).

| 내 상태 | 목소리 변화 | 이유 |
| --- | --- | --- |
| 걸러라가 나에게(여과막) | 마스크를 쓴 듯 먹먹하고 코맹맹이 | 방진 마스크 쓴 동료와 대화하는 웃음 |
| 가려라 먹막이 얼굴 앞 | 입을 가린 듯 먹먹 | "뭐라고? 안 들려!" |
| 튕겨라로 튀는 중 | 튈 때마다 높낮이가 출렁 | "으아아아\~아\~아" |
| 당겨라로 빠르게 끌려감 | 짧은 도플러(지나가며 음이 휨) | 끌려가며 비명 |
| 물때에 떠밀림(12분 종료) | 보글보글 물속 목소리 1.5초 | 하루 끝의 웃음 |
| 쓰러짐 | 속삭임 거리 `+` 살짝 멀어진 느낌 | 구조 대화 |
| 빛나라·붙어라·달궈라 | 변화 없음 | 너무 많으면 피곤하다 |

- 효과는 **말하는 사람에게 걸린 상태**로만 정한다. 듣는 사람 쪽 효과는 없다(단순함).
- \[추정\] 소리 효과 체인 4종 `+` 상태 연결 3\~4작업일.

### 1.3 실전화 컵 — 멀리 있는 동료와 말하기

| 항목 | 내용 \[추천\] |
| --- | --- |
| 모양 | 종이컵 두 개를 초록 되감이풀 실로 이은 장난감 전화. 실은 보이지 않게 풀려 나간다 |
| 설정 | 되감이풀 실은 **자기 반대쪽 끝을 기억한다**(당겨라의 원료라서). 그래서 아무리 멀어도 소리가 실을 타고 간다 |
| 얻는 때 | **6일차부터, 보린의 선물.** 골목 건조관 수리가 실제 완료된 뒤 남은 부품과 되감이풀 실로 만들어 준다. 납품이 늦었으면 그 완료 뒤 아침에 전달. "관은 막히면 안 되지만, 실은 이어져 있어야 하거든." |
| 구성 | 공방 출정 준비대 벽에 걸린 **본 컵 1개** `+` 행상단 각자 허리에 차는 **작은 컵 1개씩** |
| 쓰는 법 | 작은 컵을 손에 들고(한 손 사용) 말하면 공방 본 컵과 다른 사람의 작은 컵으로 들린다. 공방 사람은 본 컵 앞에서 말하면 된다 |
| 소리 | 종이컵 특유의 얇고 좁은 소리(대역 제한 필터) |
| 대가 | 컵을 드는 동안 **양손 찢기를 못 한다**(v1.2의 찢기는 양손). 말하면서 싸울 수 없다 |
| 물때 | 장비라 파손되지 않는다 |
| 쓰임 | 먼저 귀환한 동료가 공방에서 "먹주머니 몇 개 남았어?"를 묻고, 던전 동료는 "지금 달팽이한테 붙었어 도와줘"를 외친다. U08(조기 귀환자는 공방 작업)을 **말로 이어 주는 장치** |

- Lethal Company류 무전기의 오마주. 종이·실·되감이풀로 바꿔 세계관 안에 넣었다.
- 실전화 컵이 없는 1\~5일차에도 조기 귀환은 자유다. 음성만 연결되지 않으며 기본 핑·수량 요청으로 공방 작업자와 원정자가 소통한다. 컵은 거리감과 역할극을 더하는 기존 음성 장치다.

### 1.3.1 첫날부터 수량 요청 \[추천·D8\]

| 항목 | 규칙 |
| --- | --- |
| 시작 | 1일차부터 기존 주문·재료·출정 준비 화면에서 한 번 눌러 요청 |
| 예시 | “눌림수지 2개 필요 — 주문 준비”. 재료명·문양·수량·용도를 함께 표시 |

| 합치기 | 같은 재료의 같은 공동 목표 요청은 합침. 주문·탐험처럼 다른 목표는 출처를 보존해 중복 예약량을 알림 |

| 위치·소리 | 발견한 곳을 요청할 때만 맵에 표시. 안내음은 생물을 자극하지 않음 |

\[추천\] 1인은 자신의 수량 요청을 준비 계획으로 등록하고 부족 재료를 확보해 완료할 수 있다. 타인의 응답이나 마이크 사용은 작업·업적의 필수 조건이 아니다. 문맥 핑은 요청과 확인을 글자·기호·수량으로 전달하고 실제 완료만 기록한다.

음성 없이 재료와 수량을 정확히 전달할 수 있는지를 슬라이스에서 검증한다. 기본 핑 6개를 없애거나 컵이 있어야 물류 정보가 보이게 만들지 않는다.

### 1.4 소리 내어 외치기 (연출만)
- 스크롤을 찢는 순간 앞뒤 1.5초 안에 마이크 입력이 일정 크기를 넘으면, 캐릭터가 외치는 몸짓을 하고 **룬 글자가 두 배 크기로 번쩍인다.**
- 효과·세기·판정은 똑같다. 마이크 없는 사람과 차이가 없다.
- 플레이어가 저절로 "붙어라!"를 외치게 만드는 장치다(YAPYAP·Mage Arena의 음성 주문 유행을 규칙 부담 없이 빌림). 음성 인식으로 발동하는 기능은 1.0 범위 밖 후속 실험으로 둔다.

### 1.5 구현 메모 \[추정·구현 전 확인\]
- UE의 온라인 서브시스템(Steam) 음성 기능에 **VOIP Talker 컴포넌트**를 캐릭터에 붙여 3D 감쇠·소리 효과 체인을 적용하는 방식이 일반적이다. 5.8에서 API 이름·설정 항목이 바뀌었는지 스파이크에서 확인한다.
- 벽 먹먹함은 오디오 가려짐(occlusion) 설정 또는 간단한 선 추적으로 저역 필터 값을 바꾼다.
- 실전화 컵은 "같은 채널의 모든 컵"에 거리 감쇠 없이 보내는 별도 경로. 서버는 누가 컵을 들고 있는지만 복제한다.
- 음성 데이터는 게임 저장·사건 기록에 남기지 않는다.
- \[추정\] 전체 8\~12작업일: 기본 근처 음성 3\~4, 벽·쓰러짐·입 움직임 2\~3, 상태 효과 3\~4, 실전화 1\~2. 스파이크 1이 끝난 뒤 슬라이스 단계에서 만든다.

## 2. NPC 목소리 — 옹알이
- 대사 녹음은 하지 않는다(\[사실\] T7: 전체 대사 녹음 제외).
- 대신 NPC마다 **옹알이 목소리**를 둔다. 글자 수에 맞춰 짧은 음절 소리를 이어 붙여 말하는 느낌만 준다(동물의 숲·반조 계열에서 널리 쓰는 기법의 오마주. 기법 자체는 저작권 대상이 아니다).
- 인물별 음색: 에다(빠르고 높음), 보린(낮고 느긋), 리네(또박또박 중간), 도토(들뜬 높음·가끔 멈칫), 소미(둥글고 따뜻), 카엘(힘찬 중간·가끔 삑사리), 무로(아주 낮고 짧음), 세인(단조롭고 일정), 이솔(작고 부드러움).
- 한국어·영어 모두 같은 옹알이를 써서 **현지화 비용 0**.
- 플레이어 캐릭터는 옹알이가 없다(진짜 목소리가 있으니까). 판을 굳힐 때만 짧은 "흠흠" 소리.
- \[추정\] 음절 소리 소스 구매·편집 `+` 재생 규칙 2\~3작업일.

| 11분 | 물 차오르는 소리가 커지고 음악이 긴장 층으로 |
| 12분 | 큰 물살 "쏴아" → 입구에서 물에 뱉어지는 "푸하" |

- 증기 기적은 이 게임의 **대표 소리**다. 트레일러·메뉴에도 쓴다.
