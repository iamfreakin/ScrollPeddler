공개 데모 끝은 **공방 오늘 기록—공개 데모**다. 본편 주간 신문을 일일 신문으로 바꾸지 않는다. 공동 고객 사용 완료와 개인 미목격을 구분하며 소비를 재실행하지 않는다. 실제 고객 사용·사고를 보지 못했다고 가짜 결과를 만들지 않는다. 자세한 시간표와 대체 흐름은 W12에 둔다.

### 5.2 축제·업적·광고

축제의15일 밤은 최초 가능일이다. 골목 수리·오래 활자·행사 준비 뒤 선택한 저녁에 한 번 개최하며 엔딩 뒤에도 보류 개최 가능하다. 사진·점수·기부 기록을 재열람해 보상·재료·돈을 다시 지급/소비하지 않는다. 실제 설치 등불과 일시 조명 효과를 구별한다.

업적30슬롯은 W12의 현재 조건을 따른다. 모든 슬롯에1인 경로가 있고, 현재 실제 참가 기록으로 판정한다. 동료10회 당김·3명 튕김·공중30초 구속·전원 시야 방해·강제 물때·음성50회·인형100회 적중은 조건에서 제거한다. 선택 사진/축제를 컷하면 연결된 업적 슬롯도 같은 변경에서 재편한다. 마이크·타인 응답·아군 반복 방해를 강요하지 않는다.

가격$12.99 중심($9.99~14.99 비교)은 시작값. 실측 전10시간을 광고하지 않는다. 슬라이스 실제 영상·그림체·하루 흐름이 갖춰지면 스토어, 이후 비공개 외부 테스트→데모→1.0 순서. 75초 영상은 주문 조건·한 칸 비교·정상 작업 사고·원인/손 수습·고객 결과를 실제 빌드로 보여 주는 편집 예산이다. 현지화는 W09, 에셋 단가는 W10을 따른다. 플랫폼 정책·라이선스·엔진 API는 실제 등록/구현 시 공식 자료로 재확인한다.

## 6. AI 도구 사용 원칙

현재11번의 유효한 원칙을 유지한다. Meshy 초안은 Blender에서 사람이 다듬고 스타일·기능을 확인한다. 도구·생성일·원본·라이선스를 에셋 대장에 기록하고 요금제별 상업 이용 원문·Steam 최신 고지 규정을 확인한다. 프롬프트는 다른 게임/작가 이름 대신 형태·색·조명을 풀어 쓴다.

- **입력 자료와 보안:** 권한 없는 이미지·음향·코드, 타인의 개인정보·플레이테스터 기록·계정 정보, 비밀키·토큰·접속 정보·비공개 빌드, 계약·재무·외주 조건 등 비공개 사업 자료는 외부 AI 서비스에 입력하지 않는다. 미공개 소스 코드나 제작 자료는 보존·학습·접근 조건을 확인한 서비스에만 필요한 최소 범위로 입력한다.
- **출시 전 검수:** 플레이어에게 노출되거나 출시 빌드에 포함될 AI 산출물은 담당자와 중앙 검수자가 권리·보안·게임 적합성, 실제 플레이 환경의 기능·성능·접근성·재현성, 사람이 이해하고 수정·대체할 수 있는지를 확인한다. 모델·주요 입력·노출 방식·사용처가 바뀌면 재검수한다.
- **실시간 생성형 AI:** 초기 출시 범위에는 게임 실행 중 콘텐츠를 생성하는 AI를 포함하지 않는다. 도입하려면 별도 설계 문서에서 안전장치·비용·장애 대응·플랫폼 고지를 정의하고 중앙 승인을 다시 받는다.
