**353~562일은 D8까지의 추정이며 v2.2 구현 공수를 다시 셈한 결과가 아니다.** 슬라이스 뒤(TASK-70) 다음을 나눠 W12와 함께 다시 산정한다.

- 기존 대사를 대체한 양과 새로 더한 대사·번역·검수
- 신규 판정·거래 검사·예약/회계·축제 보류·데모 예외·저장 중단

증분을 0으로 가정하거나 기존 검수에 전부 포함됐다고 쓰지 않는다. 반대로 기존 총량에 예비 20%를 다시 더하거나 D8 전체 기능을 신규 공수로 중복 합산하지도 않는다. 조건부 2차 3~5일·대규모 재설계·모집 대기는 생기면 다시 계산한다. 옛 508+89=597분은 편성 비교값이며 10시간 실측 증거로 쓰지 않는다. **기획 방향을 승인했다고 이 기간이 납기로 확정되지는 않는다.**

## 4. 공개와 출시 규칙

### 4.1 공개 데모의 경계

공개 데모는 본편 첫날과 다른 한 출정 36분(선택 프롤로그 포함 38분) 편집이다. 데모 날짜·해금·소비를 본편 저장에 역수입하지 않고, 실제 고객 사용이나 사고를 보지 못했다고 가짜 결과를 만들지 않는다. 끝 화면은 "공방 오늘 기록 — 공개 데모"이며 주간 신문을 일일 신문으로 바꾸지 않는다. 룬·의뢰·흐름·통과 기준은 11번, 분 단위 시간표와 대체 흐름은 W12 §1에 있다.

### 4.2 축제·업적·광고

- **축제**: 15일 밤은 최초 가능일이다. 골목 수리·오래 활자·행사 준비 뒤 선택한 저녁에 한 번 열고, 엔딩 뒤에도 보류해 둔 축제를 열 수 있다. 사진·점수·기부 기록을 다시 열어도 보상·재료·돈을 다시 주거나 소비하지 않는다. 실제 설치한 등불과 일시 조명 효과를 구별한다.
- **업적**: 30슬롯은 W12 §5의 현재 조건을 따른다. 모든 슬롯에 1인 경로가 있고 실제 참가 기록으로 판정한다. 동료 10회 당김·3명 튕김·공중 30초 구속·전원 시야 방해·강제 물때·음성 50회·인형 100회 적중은 조건에서 뺐다. 사진기·축제 같은 선택 활동을 컷하면 연결된 업적 슬롯도 같은 변경에서 다시 짠다. 마이크·타인 응답·아군 반복 방해를 강요하지 않는다.
- **가격·광고**: $12.99 중심($9.99~14.99 비교)은 시작값이고 최종 가격은 전체 분량 실측 뒤 정한다(TASK-124). 실측 전에는 10시간을 광고하지 않는다. 75초 영상은 주문 조건·한 칸 비교·정상 작업 사고·원인/손 수습·고객 결과를 실제 빌드로 보여 주는 편집 예산이다.
- **순서**: 슬라이스 실제 영상·그림체·하루 흐름 → 스토어 → 비공개 외부 테스트 → 데모 → 1.0. 현지화는 W09, 에셋 단가는 W10을 따른다. 플랫폼 정책·라이선스·엔진 API는 실제 등록·구현 때 공식 자료로 다시 확인한다.
