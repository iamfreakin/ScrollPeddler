## 1 납품 단위
\[추천\] 기능 작업1회분은 손님이 주문한 한 사용 목적을 끝낼 수 있는 묶음이다. 대표 장수와 대안의 실제 장수를 따로 센다. 아래 기본 작업 수는 1인 기준이며, 실제 수량은 각 문장 줄에 인원 배수1/1.5/2/2.5를 적용한 뒤 각각 올린다.

| 단위 | 기록 |
| --- | --- |
| 기능 작업 수 | 조명1회·고정1곳·복수 순서 작업의 각 줄 |
| 대표 장수 | 현재 W07의 대표 문장으로 만들 때의 물리 장수 |
| 대안 실제 장수 | 같은 목적을 다른 문장·여러 장으로 납품한 실제 장수 |
| 가격 | 수락 당시 대표 견적의 확정 총액. 비싼 대안이라고 추가 지급 안 함 |
| 분할 납품 | 각 줄의 적합품·부재료를 보관. 마지막 조건 충족 때 돈·평판 한 번 |
| 자유 판매 | 기능 묶음이 아닌 실제 제품 장수. 납품품을 다시 판매하지 않음 |
| 손 도구 대안 | 탐험·시험에서 쓰는 대안. 스크롤 주문에 도구 자체를 납품한 것으로 처리하지 않음 |

아래 합격 시간·거리·시험 조건은 **\[추천·검증 전 시작값\]**이다. 고유 의뢰의 목적과 대표 문장은 현재 목록을 따른다. 대표 문장의 규격 판정과 실제 열·힘·충돌 시험을 구분한다. 대표 대안의 시험 결과는 검증 사례로 저장하되, 사례에 없는 문장도 공통 조건을 만족하면 받는다. 검증 사례를 정답만 담은 허용 목록으로 쓰지 않는다.
