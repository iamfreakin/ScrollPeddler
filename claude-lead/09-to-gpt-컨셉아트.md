# 컨셉아트 요청서 — GPT 스레드용 v1

작성 2026-09-22 · Claude(기획 팀장) · 근거: `설계-정리본-v1.1.md` + 팀장 조정 L07·L08(`claude-lead\08-팀장-검토-정리본v1.1.md`: 먹주머니도 물에 약함, 봉인된 완제품은 보존·현장 급조 스크롤은 물에 약함)

## 사용법

1. **메시지 1**을 GPT 스레드에 그대로 붙여 넣습니다. 같은 장면을 세 가지 그림체로 그린 스타일 시안 3장이 나옵니다.
2. 시안 하나를 고릅니다. 섞어도 됩니다(예: "A의 색 + B의 형태"). **사용자가 정할 것은 이것 하나입니다.**
3. 고른 뒤 이 한 줄을 보냅니다: `시안 ○로 확정합니다. 앞으로 모든 그림은 이 스타일로 그려 주세요.`
4. **메시지 2부터** 순서대로 하나씩 보냅니다. 메시지 하나에 그림 한 장입니다.
5. 받은 그림은 `스크롤페들러\art\`에 번호를 붙여 저장합니다(예: `02-룬문양.png`).

**우선순위:** 시간이 부족하면 2·3·4·5·6·7·10번 먼저. 나머지는 그다음.

## 팀장이 정한 아트 기준 (메시지 1에 포함)

| 기준 | 이유 |
|---|---|
| 형태는 단순하고 큼직하게, 실루엣으로 구분 | 1인 개발 + 언리얼 3D. 그림을 실제 모델로 옮길 수 있어야 합니다. |
| 동사 룬 7개는 **색으로 고정** (아래 표) | 재료 → 룬 먹 → 효과가 한 색으로 이어져야 게임 화면에서 읽힙니다. 모든 그림에 같은 색을 씁니다. |
| 공방 밝게, 던전 살짝 으스스, 공포·고어 없음 | 사용자 결정 |
| 검·갑옷·화염구 같은 판타지 전형 없음 | 설계 정리본 6.5: 현재 문법에 없는 제품은 넣지 않습니다. |
| 특정 작가·게임 그림체 흉내 금지 | 저작권 위험을 피하고 우리만의 그림체를 만듭니다. |

| 동사 | 재료 | 색 [추천·팀장 제안] |
|---|---|---|
| 빛나라 | 등심이끼 | 연두빛 발광 |
| 붙어라 | 눌림수지 | 호박색 |
| 당겨라 | 되감이풀 | 풀빛 초록 |
| 튕겨라 | 탄성점액 | 청록 |
| 달궈라 | 발열턱 | 주황 |

**설계에 없어서 팀장이 새로 제안한 것 [추천]:** 플레이어 캐릭터 외형(3번), 인물·몬스터 외형 세부(4·5번), 룬 틀 모양(동사 원 / 대상 사각 / 수식 도장, 2번). 그림을 보고 바꿔도 됩니다.

## 메시지 1 — 소개 + 스타일 시안 3장

```
안녕하세요. 제가 만드는 게임 "Scroll Peddler(스크롤 페들러)"의 컨셉아트를 부탁드립니다. 먼저 게임과 아트 기준을 설명드리고, 이번에는 스타일 시안 3장만 요청합니다. 스타일이 정해지면 메시지마다 에셋 그림을 한 장씩 부탁드릴게요.

## 게임 한 줄
친구들(1~4인)과 룬 문장으로 마법 스크롤을 만들어 팔고, 그 스크롤을 들고 재료를 구하러 던전에 갔다가 서로의 마법 사고를 수습하는 1인칭 공방 협동 게임입니다. PC, 언리얼 엔진 3D, 1인 개발.

## 세계
- 물레목 마을: 종이·먹·풀을 만들던 작은 마을. 요즘 밤마다 골목이 수증기로 젖는 게 문제입니다.
- 여백 공방: 플레이어들의 스크롤 공방. 밝고 생활감 있음. 종이 더미, 먹 병, 손글씨 라벨.
- 물레종이소: 첫 던전. 버려진 제지 공장이 물·어둠·생물 때문에 낯설어진 곳. 물때(물이 차오르는 주기)가 있습니다. 살짝 으스스하지만 공포는 아닙니다.

## 그림에 드러나야 하는 규칙
- 스크롤은 문장입니다. [동사 룬] + [대상 룬] + [수식 룬] 세 칸을 도안판에 끼워 인쇄합니다. 예: 빛나라 + 물건 + 오래.
- 스크롤은 찢어서 발동합니다.
- 룬 먹은 던전 재료로 만들고, 동사마다 색이 정해져 있습니다. 모든 그림에서 이 색을 지켜 주세요.
  - 빛나라 (재료: 등심이끼) — 연두빛 발광
  - 붙어라 (눌림수지) — 호박색
  - 당겨라 (되감이풀) — 풀빛 초록
  - 튕겨라 (탄성점액) — 청록
  - 달궈라 (발열턱) — 주황
  - 가려라 (먹주머니) — 먹색·짙은 남보라
  - 걸러라 (숨돌) — 회청색

## 아트 기준
- 1인칭 게임입니다. 장소 그림은 눈높이 시점을 우선합니다.
- 실제 3D 모델로 옮길 수 있게 형태는 단순하고 큼직하게, 실루엣이 잘 읽히게 그려 주세요. 잔 디테일보다 색과 모양으로 구분합니다.
- 공방과 마을은 밝고 따뜻하게. 던전은 어둡고 축축하고 살짝 으스스하게. 피·고어·공포 괴물은 없습니다.
- 세계의 주제는 종이·먹·풀·물레입니다. 검, 갑옷, 화염구 같은 전형적인 판타지 전투 이미지는 넣지 않습니다.
- 그림 속 글자는 최소로, 꼭 필요하면 짧은 한국어로.
- 특정 작가나 특정 게임의 그림체를 흉내 내지 말아 주세요.

## 이번 요청: 스타일 시안 3장
세 장 모두 같은 장면을 다른 그림체로 그려 주세요. 가로 16:9. 한 번에 못 그리면 A부터 그리고, 제가 "다음"이라고 하면 이어서 그려 주세요.

장면: 해 질 무렵 여백 공방 안. 1인칭 시점으로 작업대 앞에 서 있습니다. 화면 아래쪽에 내 두 손이 도안판을 잡고 있고, 도안판에는 룬 조각 세 개(연두빛 '빛나라', '물건', '오래')가 끼워져 있습니다. 작업대에는 먹 병, 종이 더미, 먹 저울. 뒤쪽에서 동료 한 명이 먹을 갈고, 다른 동료는 카운터에서 젖은 우비를 입은 배달부 손님을 맞고 있습니다. 창밖으로 젖어서 반짝이는 골목이 보입니다.

- 시안 A — 손그림 수채 + 먹 선: 번지는 수채 색, 붓펜 윤곽선, 종이 질감. 따뜻한 그림책 느낌.
- 시안 B — 스타일라이즈드 3D: 둥글고 단순한 형태, 손으로 칠한 듯한 단순한 텍스처, 부드러운 조명. 실제 게임 화면에 가까운 느낌.
- 시안 C — 종이 공예: 오려 붙인 종이 층, 접힌 자국, 먹 번짐. 세계의 주제(종이)를 그림체 자체로 보여 주는 느낌.

각 그림 뒤에 이 스타일의 장점과, 3D 게임으로 옮길 때 어려운 점을 한 줄씩 적어 주세요.
```

## 메시지 2 — 룬 문양 시트

```
[2/16] 룬 문양 시트
확정한 스타일로 룬 18개의 문양 디자인 시트를 그려 주세요. 가로 16:9, 밝은 종이 바탕.
- 1줄, 동사 7개: 빛나라, 붙어라, 당겨라, 튕겨라, 달궈라, 가려라, 걸러라. 정해진 색을 쓰고, 모양만 봐도 뜻이 짐작되게 해 주세요. (예: 빛나라=빛살, 붙어라=늘어지는 방울, 당겨라=갈고리와 실, 튕겨라=용수철·반원, 달궈라=불씨, 가려라=덮는 막, 걸러라=그물)
- 2줄, 대상 6개: 물건, 바닥, 벽, 나, 너(가리킨 생물 하나 — 동료든 몬스터든), 주변. 먹색 무채색.
- 3줄, 수식 5개: 잠깐, 오래, 넓게, 세게, 멀리. 붉은 인주색 작은 도장.
- 동사·대상·수식은 틀 모양으로도 구분되게 해 주세요. 제안: 동사=원, 대상=사각, 수식=작은 도장. 더 좋은 안이 있으면 바꿔도 됩니다.
- 문양 아래에 한국어 이름을 작게.
- 오른쪽에 도안판 예시 하나: 세 칸에 "빛나라 + 물건 + 오래"가 끼워진 모습.
```

```
한쪽에 비교용으로 세 개: 판매용 포장(끈과 가격표), 던전에서 급하게 만든 봉인 없는 스크롤(젖으면 번져서 못 쓰게 됨 — 젖어 번진 모습도 작게), 찢어서 쓴 뒤의 스크롤.
```
