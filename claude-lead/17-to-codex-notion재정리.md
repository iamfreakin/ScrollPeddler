## 옮기는 규칙

1. **제목과 아이콘:** 원고 첫 줄 `# 🎯 01. 게임 개요` → 아이콘 🎯, 제목 `01. 게임 개요`. 첫 줄(H1)은 본문에 넣지 않습니다.
2. **서식 변환:** 마크다운 표 → Notion 표(첫 행 머리글). `<callout icon color>` → 콜아웃. `<details><summary>제목</summary> … </details>` → 토글(안의 표·문단은 토글 안에). `> 인용` → 인용. 굵게·코드 그대로.
3. **글자는 한 글자도 바꾸지 않습니다.** 요약·재배치·표 합치기 금지. 원고가 길면 나눠서 추가하고, 그래도 안 되면 멈추고 알려 주세요.
4. **상세 하위 페이지:** 원문 파일을 그대로 옮깁니다. 첫 줄 H1은 빼고, 맨 위에 회색 콜아웃 한 줄을 넣습니다: `팀장 상세 설계 원문 (2026-09-23). 요약은 상위 페이지에 있습니다. [사실] 기존 확정 · [추천] 이번 창작 · [추정] 계산값.` 아이콘은 📄.
5. **하위 페이지 위치:** 분야 페이지 맨 끝의 "상세 설계는 하위 페이지 **"…"**에 있습니다." 문장 바로 아래에 그 하위 페이지 블록이 오게 합니다.
6. **메인 목차:** 메인 원고의 "## 목차" 아래 세 분류(🎮 게임 설계 / 🛠️ 제작 / 📋 관리)에 있는 굵은 제목을 **해당 페이지 링크(멘션)**로 바꿉니다. 01~12 하위 페이지 블록 자체는 메인 맨 아래에 01→12 순서로 둡니다(Notion이 자동으로 두는 위치). 목차 문장의 설명은 그대로 둡니다.
7. 메인 원고의 "[12. 결정 기록·남은 일]"처럼 대괄호로 쓴 페이지 이름, 각 페이지 안의 "**05. 콘텐츠 도감**" 같은 다른 페이지 이름은 해당 페이지 멘션으로 바꿔도 됩니다(선택).
8. **원문 안의 파일 링크:** W00의 `[W01 플레이어와 첫날](W01-플레이어와-첫날.md)` 같은 `.md` 링크는 위 표의 해당 하위 페이지 멘션으로 바꿉니다. `W13-기획-도면집.html` 링크는 글자 그대로 두고, 바로 뒤에 있는 https://claude.ai/artifact/… 주소를 링크로 둡니다. 그 밖의 파일 이름(예: `T4 §1.1`, `W02 §5`)은 글자 그대로 둡니다.
