## 0. 결론
1. **생물은 죽이지 않는다. "놀라게 해서 떨구게" 한다.** 도롱뇽은 꼬리를 떼고, 달팽이는 점액을 흘리고, 딱정벌레는 턱 껍데기를 벗는다. 떨군 뒤엔 달아나고 다음 영업일에 돌아온다. 밝은 공방·살짝 으스스한 던전 톤과 "악당 없음"(D4-01)에 맞춘 방식이다. 문서에서 쓰던 "처치"는 이제 **"떨굼"**이라 부른다.
2. **떨굼 조건은 모두 이미 있는 속성·반응으로 만든다.** 새 규칙이 아니라 "어떤 상태 조합을 만들면 떨구는가"를 종마다 하나씩 정한다. 플레이어는 문장으로 그 상태를 만든다.
3. **버팀 시작값을 정했다.** 숨은 체력이 아니라 3단계로 보이는 위험 게이지다(§1).
4. 제작은 **뼈대 3종**으로 6종을 만든다: 도롱뇽형(B01·B07), 달팽이형(B02·B04), 곤충형(B03·B09 비행 변형).

## 1. 버팀 — 시작값 \[추천·검증 전\]

| 항목 | 값 |
| --- | --- |
| 위험 게이지 | 0\~100. 숫자는 보이지 않고 **3단계**로 보인다: 여유(0\~49) / 휘청임(50\~99) / 쓰러짐(100) |
| 보이는 방법 | 휘청임: 화면 가장자리 붉은 종이 테두리 `+` 숨소리 `+` 모자 비뚤어짐. 동료에게도 모자가 비뚤어져 보인다 |
| 회복 | 새 위험 없이 5초가 지나면 초당 10씩 내려감 |
| 충격 등급 | 약 `+`15 / 중 `+`30 / 강 `+`45 |
| 열 노출 | 뜨거운 표면·열 상태에 닿는 동안 초당 `+`8. 젖어 있으면 김이 나는 동안 0(S6) |
| 떨어짐 | 2\~4m 약, 4m 넘으면 중 |
| 아군 직접 원인 | 게이지를 최대 **99**까지만 올린다(D1-01). 아군 때문에 휘청일 수는 있어도 쓰러지지는 않는다 |
| 보호 | 피격 뒤 1.5초, 구조 뒤 3초 새 위험 없음(\[사실\]) |
| 구조 직후 | 게이지 60(휘청임)에서 시작 → 5초 뒤 회복 시작 |
| 무해 상태 | 젖음·빛·먹물·끈적임·가루는 게이지를 올리지 않는다(행동만 바꾼다) |

**쓰러지기까지의 감각:** 여유 상태에서 중 공격 2번 `+` 약 1번(30`+`30`+`15=75, 휘청임) 뒤 중 공격을 한 번 더 맞으면 쓰러진다. 한 번에 쓰러뜨리는 공격은 없다. 스파이크 1에는 이 체계를 넣지 않는다(\[사실\] v2.0 §5.1).

## 2. 생물 공통 부품

### 2.1 상태 흐름
`쉼 → 일 → 경계 → 예고 → 확정 → 실행 → 빈틈 → (일로 복귀 | 도망 | 떨굼→도망)`

| 상태 | 뜻 | 플레이어에게 보이는 것 |
| --- | --- | --- |
| 쉼 | 제자리. 감지 거리 절반 | 눈 감음·느린 호흡 |
| 일 | 종마다 하는 일(종이 먹기, 턱 달구기 등) | 일하는 동작 |
| 경계 | 플레이어를 알아챔 | 고개를 돌리고 멈칫 `+` 짧은 소리 |
| 예고 | 공격 준비. 방향·범위가 **바닥에 옅게** 보임(T2) | 종별 몸짓 `+` 소리 |
| 확정 | 방향 고정. 이제 피할 때 | 몸이 굳음 |
| 실행 | 예고한 범위만 판정. 한 공격 한 번만 맞음 | — |
| 빈틈 | 헐떡임·어지러움. 이때가 기회 | 머리 위 빙빙 |
| 도망 | 둥지·웅덩이로 돌아감 | — |
| 떨굼 | 재료를 떨구고 도망 | 재료가 반짝이며 바닥에 남음 |

### 2.2 감지

| 감각 | 규칙 |
| --- | --- |
| 시야 | 앞 90°, 8m. 어두우면 4m. **빛나는 대상은 어두워도 8m**(빛나라에 걸린 동료가 먼저 눈에 띈다) |
| 청각 | 세계 소음만 듣는다: 걷기 3m, 뛰기 6m, 현장 급조 8m, 세게 12m, 쏟은 먹·물건 떨어짐 6m. **목소리·핑·UI는 듣지 않는다**(W03 D7-12) |
| 기억 | 놓친 뒤 6초간 마지막 위치를 살핀다 |

### 2.3 같이 쓰는 규칙
- 한 구역에서 동시에 "확정" 상태인 큰 공격은 1개까지(T1 §1 중첩 위협 조정).
- 기본 귀환길 위에 생물이 영구히 버티지 않는다. 귀환길 위에서 20초 이상 머물면 옆길로 비킨다.
- 같은 개체는 하루 1번만 떨군다. 떨군 개체는 그날 다시 나타나지 않는다.
- 단독 생물은 **개체 ID**, 책먼지나방은 **무리 ID**를 기준으로 하루 1번을 판정한다. 3\~5마리 나방 한 무리에서 숨털뭉치 1개만 얻는다.
- 떨굼은 **호스트 서버가 한 번만** 판정한다. 재료는 바닥에 떨어지고 먼저 줍는 사람 가방으로(파티 공용 재료).
- 생물은 물때 12분 종료와 함께 둥지로 돌아간다. 다음 날 같은 자리 후보에서 다시 시작한다.

### 2.4 반복 방해 보호 \[추천·검증 전\]
동료가 만든 접착·먹막을 **손으로 제거한 뒤, 상태가 제거된 플레이어**에게 같은 상태를 동료 문장으로 다시 걸기까지 2초 간격을 둔다. 자기 손으로 제거했든 다른 동료가 대신 제거했든 보호 대상은 막에서 풀려난 플레이어다. 작은 종이 표시로 재부여 제한의 이유를 보인다. 같은 접착막에 다시 닿는 상황과 새 동료 문장의 재부여를 구분해 판정한다.

생물의 접착·먹 공격, 환경 위험, 자기 문장에는 적용하지 않는다. 위험 게이지의 피격·구조 보호와도 별개다. 아군 당김의 반복 방해는 우선 예고·중복 적용을 관찰하고, 2초 제한을 임의로 확대하지 않는다. 근거와 검증은 `18-레퍼런스기반-개선설계.md` R05·§4.4를 따른다.

| B07 풀옷도롱뇽 | 열로 외피 벗기기 | K06,개체당1\~2개/일 | 일반 접착 먹 보충 | 1\~2개 지급 기준 미결. 장부는 보수적1개 가정과 추가1개를 구분 |
| B09 책먼지나방 | 빛 유인→가루 여과→막 걷기 | K20,무리당1개/일 | 가루 작업 부재료 | 한 마리당 지급 안 함. 얼굴 앞 막은 판독 방해 |

[던전밥 공식 소개](https://yenpress.com/titles/9780316473064-delicious-in-dungeon-vol-1)의 “보급 부족을 생물 활용으로 해결”하는 관계를 비살상 떨굼에 옮겼다. 같은 행동을 읽고 원료를 얻으며, 우리의 생물6종·재료16종을 유지한다.

생물별 재료 지급은 개체/무리당 하루1회다. B07의1\~2개 지급 조건은 **미결**이며, 보수적1개와 추가1개를 구분한다. 생물 원료의 고객 목적은 [의뢰 판정·납품 규격](W14-의뢰판정-납품규격.md), 공식 비교 근거는 [레퍼런스 36작품·적용 근거](W15-레퍼런스36-적용근거.md)에 있다.

### B01 먹물도롱뇽 — 물레종이소 세척실 / 잉크 광산 침전실

| 항목 | 내용 |
| --- | --- |
| 크기·속도 | 길이 1.2m, 무릎 높이. 걷기 2m/s, 잉크 웅덩이 안에서 4m/s |
| 일 | 잉크 웅덩이에 잠겨 눈만 내밀고 종이 부스러기를 먹는다 |
| 성질 | **빛을 싫어한다.** 빛나는 대상이 4m 안에 오면 경계 |
| 공격 ① 먹 분출 | 예고 1.0초(목이 부풀고 "꾸르륵") → 확정 0.3초(입 방향 고정) → 실행: 앞 60° 부채꼴 6m에 먹 → 빈틈 3.0초(헐떡임) |
| 맞으면 | 먹물 상태: 얼굴 앞 먹막 8초(손으로 닦기 2초) `+` 위험 **`+`15**. 맞은 광원은 S3로 어두워짐 |
| 먹 소진 | 두 번 뿜으면 30초 동안 못 뿜고 웅덩이로 도망 |
| **떨굼 — 꼬리 떼기** | 몸이 **어딘가에 붙은 상태로 3초**가 지나면 꼬리를 떼고 도망간다(실제 도롱뇽의 꼬리 자르기 오마주). 떨어진 꼬리 = **먹주머니(K07) 1개**. 꼬리는 다음 날 다시 자란다 |
| 떨굼 만드는 법 | 붙어라`+`너`+`잠깐(다음 접촉 → 바닥에 붙음) / 웅덩이 가장자리에 붙어라`+`바닥`+`잠깐을 깔아 두기 / 당겨라`+`너로 끌어내 마른 바닥(느려짐 1m/s)으로 옮긴 뒤 붙이기 |
| 쫓아내기 | 빛나라`+`너`+`잠깐 → 싫어서 웅덩이 깊이 숨는다(길을 비킬 때) |
| 웃긴 사고 | 넓게로 붙이면 옆 동료도 같이 바닥에 붙는다. 뿜은 먹이 동료의 따라가는 등불(P11)을 덮어 캄캄해진다 |
| 혼자 | 웅덩이 입구에 붙어라`+`바닥을 깔고 빛으로 몰아내면 나오다 붙는다 |
| 소리 | 꾸르륵(예고), 퓻(분출), 쩝쩝(먹기), 뽁(꼬리 떼기) |

### B02 부풀달팽이 — 물레종이소 건조실

| 항목 | 내용 |
| --- | --- |
| 크기·속도 | 평소 지름 0.8m, 부풀면 2.4m(통로를 꽉 막음). 0.5m/s |
| 일 | 젖은 종이를 갉아 먹는다. **종이 부스러기를 던지면 그쪽으로 간다** |
| 공격 없음 | 먼저 공격하지 않는다. 놀라면 부푼다 |
| 부풀기 | 놀람(세게 소음·충격·당겨라에 맞음) → 예고 1.2초(더듬이 움츠리고 "뽀오옹" 음 상승) → 1초 동안 부풂: 주변 1.2m를 **밀친다**(위험 `+`15, 벽·화덕으로 밀리면 그 위험 추가) → 10초 부푼 채 유지(당김에 버팀, 통로 봉쇄) → 쪼그라들며 3초 빈틈 |
| **떨굼 — 점액 웅덩이** | 그날 처음 쪼그라들 때 **탄성점액 웅덩이**를 남긴 뒤 도망간다. 운반통으로 떠 담으면(6초) **탄성점액(K08) 1개**. 개체당 하루 1회이며 다시 놀라게 해도 재료를 더 주지 않음 |
| 점액 웅덩이 | 20초 동안 탄성 바닥(S4). 밟으면 튄다 |

T4 §3.1의 "몬스터 원료 기회 1\~2개/구역"은 배치 기회의 시작안이며 실제 획득량이 아니다. 위 "하루 최대"는 해당 원정의 모든 개체가 떨궜을 때의 **상한**이다. 실제 수급은 W07 §6에서 안전 반출·종료 회수·실제 소비로 맞춘다.

\[추정\] 위 최대는 해당 원정에서 만날 수 있는 개체를 기준으로 다시 계산해야 한다. 여러 지역의 상한을 하루 공급으로 합산하지 않는다. 실제 공급은 안전 반출·종료 회수에 성공한 재료만 세며, 물때에 파손된 먹주머니는 공급에서 뺀다.

\[추정\] 물레종이소 1인 배치 B01×2·B02×2·B03×1이면 몬스터 원료 최대 **5개·먹 10회분**이다(원료 1개=먹 2회분). B02를 하루 2회로 계산했던 점액 8회분은 **4회분**으로 줄어 최대 4회분 감소한다. 공급 기회만으로 수요를 감당한다고 확정하지 않는다.

| 회수·급조 | 빈칸만큼 꾸러미 분배. 급조 완성칸 사전 예약. 초과 줍기 거절, 기존품 자동 삭제 금지 |

세부 권한·저장은 T1 §6, 입력 취소는 T2 §6, 표시/조작 키는 W11을 따른다.

## 10. 정상 작업이 만나는 사고와 수습

| 작업 | 뜻밖의 사건 | 읽을 원인 | 수습 |

## 11. 상태 판정과 검증 경계
젖은 접착은 **S6→S2**다. 물기 말림에 쓴 열을 다시 접착 해제에 쓰지 않는다. 등심 성질이 있는 대상은 **S1→S3**로 발광을 계산한 뒤 먹막으로 차광한다. 새 충돌에서만 탄성이 반응하며 같은 접촉을 반복 충돌로 세지 않는다.

\[추천\] 물기 일부만 마름 / 전부 말랐지만 해제 열 부족 / 말림 뒤 접착 해제의 세 사례를 나눠 검증한다. 열량·물기 단위·접착 임계값·반발 속도 상한·가루 포집량은 아직 미결이다. ‘한 장이면 항상 구조’나 ‘탄성이 언제나 완충’으로 쓰지 않는다.
