# T1. 시스템 — 전투·피해·구조·저장·협동

2026-10-07 · 설계 v2.2 동기화 · 설계 개정 2026-10-06 · D8 유지

**세계·경제는 호스트 공방에, 학습·기여 기록은 개인에게 남긴다. 사고를 수습할 수 있고, 같은 물건을 두 번 주거나 빼지 않는 것이 기준이다.** [사실] 기존 사용자·팀장 결정과 D8 방향을 유지한다. [추천·v2.2 적용] 최신 Notion의 접속·거래·저장 경계를 아래에 동기화했다. 수치는 검증 전 시작값이며 구현·실행 검증은 하지 않았다.

현재 기준은 [설계 정리본 v2.2](../설계-정리본-v2.2.md)이다. 세부 화면은 [W11](W11-화면설계.md), 생물·수습은 [W04](W04-생물-전투.md), 의뢰의 필수·선택 작업과 실제 납품 규격은 [W14](W14-의뢰판정-납품규격.md)를 따른다.

## 1. 피해와 구조

| 항목 | 적용 규칙 |
|---|---|
| 버팀 | 0~100 내부값, 여유 0~49·휘청임 50~99·쓰러짐 100. 숫자 대신 단계·원인을 표시 |
| 회복 | 새 위험 없이 5초 뒤 초당 10 회복. 젖음·빛·먹물·끈적임·가루 자체는 버팀 피해 없음 |
| 충격·열 | 충격 약15·중30·강45, 지속 열 초당8. S6로 물기를 소모하는 동안 열 피해보다 말림·김 반응 먼저 |
| 아군 피해 | 아군 직접 원인은 최대99. 아군이 만든 바닥·소품을 거친 피해도 같은 제한. 끌려가 기존 화덕·생물 공격에 맞은 것은 별도 위험 |
| 피격·구조 보호 | 손 구조 작업3초 / 피격 뒤1.5초·구조 완료 뒤3초 보호. 구조 직후 버팀60. 상태와 바닥 위험을 자동 삭제하지 않음 |
| 쓰러짐 | 제한45초. 손 구조·맨손 끌기 가능. 제한 안에 구조 못하면 몸만 입구로, 물품은 현장 공동 회수 꾸러미 |
| 혼자 | 혼자 출발한 원정에 한해 자력 회복8초 1회. 재접속으로 충전하지 않음 |
| 손 해제 | 접착·먹막은 보통2초, 강한 접착만3초. 가열은 S6에서 물기를 먼저 소모하고 김을 만들며, S2는 남은 열로만 접착 해제를 판단 |
| D8 반복 방해 보호 | 동료 원인 접착·먹막을 손으로 떼면 풀려난 사람에게 같은 상태의 새 동료 재부여를2초 제한. 자기/동료의 손 제거 모두 해당. 생물·환경·자기 문장과 당김에는 자동 확대하지 않음 |
| 생물 | 예고→방향 확정→실행→빈틈. 죽이지 않고 조건을 만들어 재료를 떨구게 함. 종별 조건·공급 상한은 W04 |

숫자 체감은 슬라이스에서 확인한다. 스파이크1에는 버팀·생물 AI·영구 저장을 넣지 않는다. 김은 송풍기로, 가루는 여과막으로 처리하며 만능 치료 스크롤을 만들지 않는다.

## 2. 출발·귀환·실패

| 상황 | 결과 |
|---|---|
| 출발 | 함께 출발. 출발 명단·원정 ID 확정. 스크롤6장과 재료8칸×칸당10은 별도 |
| 먼저 귀환 | 자유. 그날 재입장 불가, 공방 작업 가능 |
| 물때 | 던전 입장 승인부터12분. 남은 사람은 입구로 떠밀림. 미반출 확보 물품 중 바탕 종이·말린 되감이풀·먹주머니와 원료 취약성을 잇는 당김/차광 먹, 모든 미봉인 스크롤(공방 미포장품·현장 급조품)이 파손. 봉인품과 이미 안전 반출한 재고는 보존 |
| 바닥·수레·꾸러미 | 확보한 물품은 손/가방과 같은 판정. 물에 강한 것은 입구 공동 회수. 미채집 지도 자원은 회수 안 함 |
| 모두 귀환 | 연결 복구 대기도 없으면 남은 침수 결과 즉시 확정. 물때를 기다리거나 하루를 자동 마감하지 않음 |
| 정산 | 소비·파손을 각각1회 기록. 소비한 스크롤의 원재료·포기 판매가·실패 벌금을 추가 차감하지 않음 |

## 3. 호스트와 개인 기록

| 저장 범위 | 내용·경계 |
|---|---|
| 호스트 공방 | 돈·재고·설비·룬 제작 해금·공동 도감·의뢰·평판·날짜·출입·물때·세계 상태 |
| 개인 작업 수첩 | 본인의 시험 도안·명시적으로 복사한 도안·실제 제작/구조/납품 기여·참여 발견 기록 |
| 공동 발견 | 사건 시점에 아직 던전 원정에 참여 중인 출발자. 먼저 귀환한 사람과 이후 합류자는 개인 목격 기록에서 제외 |
| 직접 해독자 | 직접 행동한 사람을 별도 기록. 공동 발견 참가자와 구분 |
| 일시 단절 | 원정 참여가 유지된 연결 복구 대기자는 공동 참여 기록 가능. 화면을 실제로 보았다고 기록하지 않음 |
| 공동 도감 열람 | 공방·먼저 귀환한 사람도 새 공동 지식을 열람. 개인 발견 기록 지급과 별개 |
| 다른 공방 | 도안 사본·기록만 가져감. 돈/물품/해금 복사 없음. 방문 공방이 모르는 룬의 제작·현장 급조 불가 |

## 4. 접속과 공동 지출

| 상황 | 규칙 |
|---|---|
| 출발 뒤 신규 합류 | 공방 일을 하며 다음날 출발. 기존 주문 수량은 수락 당시 인원으로 고정 |
| 던전 자발 이탈 | 참여 종료, 짐은 현장에 남고 당일 재접속은 공방. 무료 반출 없음 |
| 일시 단절 | 몸은 새 버팀 피해·경직을 받지 않지만 원래 상태 종료·구조 제한·물때는 진행. 짐을 공동 회수하면 원래 가방에서도 동일 수량 이동 |
| 자리 예약 | 90초 시작값. 만료는 자리만 개방하며 원정 기록·물품 소유를 삭제하지 않음. 온라인4인 상한, 자동 추방·5번째 조작자 없음 |
| 90초 이후 참여 [추천·v2.2 적용] | 일시 단절자의 참여·같은 몸은 그 원정 물때 종료까지 유지. 빈자리로 복귀하면 같은 출입·짐·자력 회복 상태를 이어받고, 원정이 끝났으면 공방. 단절 대기자가 있으면 전원 온라인 귀환만으로 즉시 종료하지 않음 |
| 호스트 종료 | 정상 종료는 두 공간을 같은 시점 저장 후 중단. 비정상 종료는 마지막 정상 공동 저장 복원. 자동 호스트 이전·전용 서버 없음 |
| 공동 구매 | 호스트가 정한 파티 공용 운영 예산. 큰 지출·예산 초과는 거래별 승인. 소비 때마다 호스트 승인을 요구하지 않음 |
| 재고 계획 | 주문/원정 계획은 경고용 남겨두기. 실제 인쇄 작업의 예약만 이중 소비를 차단. 계획을 넘는 판매·사용은 부족량을 알려 다시 판단하게 함 |
| 장별 인쇄 완료 | 한 장 완료마다 그 장의 재료 소비·제품 생성·완료 번호를 함께 확정. 취소는 미완료 장의 예약만 해제. 완료한 장·소비를 되돌리지 않고, 일시 단절·호스트 중단은 취소로 취급하지 않음 |

## 5. 저장과 복구

| 시점·자료 | 기준 |
|---|---|
| 거래 확정 | 자금·재고·보상 반영 번호·소유권을 한 스냅샷으로 저장 요청. 중복 요청은 같은 결과 반환 |
| 진행 확정 | 출발·귀환·해독·물때·마감·자력 회복 사용을 같은 세계 기록에 저장 |
| 정기 저장 | 활동 중15초 간격 시작값. 두 공간·남은 물때·발동 대기·인쇄 작업/예약·단절자의 자리 예약과 참여·몸/짐·개인 전달 대기 사건 포함 |
| 개인 전달 | 호스트가 사건 저장 성공 후 개인 기록 전달. 사건 ID로 중복 방지, 개인 쓰기 실패는 다음 접속에 재전달 |
| 복원 | 최신 게스트 가방과 옛 호스트 재고를 섞지 않음. 저장된 남은 시간을 복원해 시간 초기화 방지 |
| 쓰기 실패 [추천·v2.2 적용] | 마지막 정상 세대 보존. 실패를 확인하면 두 공간 공동 일시 중단: 물때·효과·공정·새 거래 승인을 함께 멈춤. 메모리에 이미 확정한 거래는 환불·재실행하지 않고 현 상태의 공동 저장을 재시도 |

기술 형식은 [T8 §5](T8-기술설계.md), 원인/수첩 화면은 W11, 생물·버팀은 W04를 따른다. 의미 있는 검증은 동시 사용·인쇄 취소·귀환 직후 종료·호스트 장애·개인 기록 재전달에서 수량·시간·권리가 일치하는지 확인하는 것이다.

저장 요청·저장 중·검증한 성공을 구분한다. 성공 시 같은 공동 시점·개정을 확인한 뒤 남은 시간을 이어 재개하고 개인 기록을 전달한다. 계속 실패하면 마지막 정상 시점과 저장되지 못한 구간을 보이며, 정상 종료 재시도 또는 마지막 정상본 다시 읽기를 선택한다. 강제 종료는 마지막 정상본까지만 보존한다. 자동 저장 API가 이 복구를 보장한다고 가정하지 않는다.

## 6. 세부 실행 경계

| 행동 | 기준 |
|---|---|
| 쓰러진 몸 | 느린 기기·위치 핑·자기 몸의 막 벗기기 가능 |
| 손 구조 중단 | 구조자 이동·자발 취소·실제 위험 피해만 중단. 소리·먹 묻음 자체는 중단 안 함. 여러 명이 잡아도3초를 단축하지 않음 |
| 동시 종료 | 같은 시점이면 도달한 물때 종료 우선. 먼저 구조 완료가 확정됐으면 구조 인정 |
| 응급 복귀 선택 | 본인은 구조를 기다리지 않고 몸만 입구로 갈 수 있음. 동료가 강제로 포기시키지 않음 |
| 같은 막 재도장 | 진행 중인 손 해제 시간을 초기화하지 않음. 완료 때 결합과 해당 막 함께 제거 |
| 재료 칸 | 손에 꺼낸 재료도 기존 칸 점유. 같은 원료라도 가공 상태가 다르면 별도 묶음 |
| 스크롤6장 | 손/가방·봉인/미봉인 모두 합산. 손에 들었다고7번째 장 허용 안 함 |
| 회수 꾸러미 | 기존 물품 표시. 동료 가방의 빈칸만큼 나눠 회수, 용량 보너스 없음 |
| 급조·초과 | 완성 스크롤 칸 먼저 예약. 초과 줍기는 이유를 보이고 거절하며 기존품 자동 삭제 금지 |

T8의 물품 ID·작업 예약·거래 번호로 위 경계를 검사한다. 역할 입력·손 해제 중단은 T2, Notion 던전 요약과 W04에 연결한다.

## 7. 접속·거래·저장 예외 15개

[사실] 기존 소유·출입·단일 거래 규칙을 유지한다. 아래의 참여 유지와 저장 실패 공동 중단은 [추천·v2.2 적용]이며 실제 재접속·복원은 아직 검증하지 않았다.

| 번호 | 상황 | 처리·확인할 경계 |
|---:|---|---|
| EX01 | 같은 물품 동시 줍기 | 먼저 승인된 한 명에게만 이동. 전체 수량 유지, 다른 화면에는 최신 위치 |
| EX02 | 소비 응답 유실 뒤 같은 요청 재전송 | 같은 요청 ID·같은 내용은 기존 결과. 재소비·재발동 없음, 처리 확인 중 표시 |
| EX03 | 같은 요청 ID·다른 내용 | 거부하며 원래 거래 유지. 정상 재고 경쟁과 다른 이유 |
| EX04 | 계획 몫을 다른 작업에 사용 | 계획은 경고, 실제 예약만 소비 차단. 관련 계획 부족량 같이 갱신 |
| EX05 | 인쇄 완료·취소 동시 | 장별 확정 상태를 한 번 적용. 완료품 유지, 미완료 예약만 해제 |
| EX06 | 찢기 승인 전 물품 없음 | 요청 거부·무소비. 최신 재고·예약 이유 표시 |
| EX07 | 찢기 승인 뒤 대상 무효 | 소비 유지, 자동 재선택·환불 없음. 요청 거부와 문장 무효 구분 |
| EX08 | 출발 뒤 새 게스트 | 공방 가능·당일 신규 원정 불가. 수락한 주문량·대금 고정, 다음 출발 안내 |
| EX09 | 자발적 퇴장·재접속 | 참여 종료, 짐 현장, 당일 복귀는 공방. 무료 반출 없음, 과거 발견 유지 |
| EX10 | 일시 단절90초 안 복귀 | 같은 몸·짐·출입·자력 회복 상태. 물때·효과·구조 제한은 계속, 새 재고 생성 없음 |
