## 1. 위협과 피해 — Q4 해결안

### 1.1 체력과 상태 표현의 선택

| 선택지 | 작동 방식 | 장점 | 주의점 |
|---|---|---|---|
| 체력 중심 | 숫자 체력을 깎고 별도로 젖음·접착 등을 적용 | 위험량 비교가 쉬움 | 회복 자원·수치 관리가 소동보다 앞설 수 있음 |
| 상태만 사용 | 붙음·시야 가림·열 등으로 행동이 불편해짐 | 원인과 수습이 직접 연결됨 | 상태 개수로 쓰러짐을 정하면 젖음+빛 같은 무해한 조합도 처벌하게 됨 |
| **상태 + 버팀 단계 [추천]** | 상태는 행동·반응을 바꾸고, 실제 충격·과열 노출만 버팀에 누적. 숫자 대신 위험 단계를 읽게 함 | 동료가 불편을 풀어 주는 재미와 쓰러짐 경계가 함께 생김 | 버팀이 보이지 않는 체력이 되지 않도록 상승 원인·현재 단계·회복 조건을 알려야 함 |

‘버팀’은 쓰러질 위험을 나타내는 판정값이다. 새 룬 속성이나 별도 성장 능력치가 아니다. 내부 누적값·문턱은 T4 검증 대상으로 남기고, 맞는 횟수와 피해량은 확정하지 않는다.

| 단계·상태 | 결과 | 수습과 회복 |
|---|---|---|
| 여유 | 정상 행동 가능 | 무해한 상태만으로 버팀이 줄지 않음 |
| 휘청임 | 위험 누적을 알림. 반복 조작 잠금이나 강제 연속 넘어짐은 없음 | 위험에서 벗어나 피해 없이 숨을 고르면 버팀이 서서히 회복. 이 구간에서도 이동·손 해제·도움 요청 가능 |
| 쓰러짐 | 위험 문턱 도달. 걷기·제작·스크롤 시전·새 채집 중지 | 느린 기기·위치 알림·자기 몸의 막 벗기기는 가능. 손 구조 또는 1인 자력 회복을 시도 |
| 젖음·먹물·끈적임 | 기존 속성에 따른 열 소모·감광·시야 가림·접촉 결합 | 물에 한 번 맞았다고 가방 재료 삭제 금지. 먹막·접착은 기본 제거, 물기는 기존 환경 반응으로 처리 |
| 열·충격 | 남은 열의 지속 노출이나 읽을 수 있는 강한 충격이 버팀에 영향 | 젖음+열은 물기 소모와 김 발생이 먼저. ‘그을림’은 열 피해의 흔적 표현이며 아홉 번째 속성이 아님 |

[추천] 휘청임은 강제 이동 속도 저하를 계속 겹치는 벌칙으로 쓰지 않는다. 회복 대기는 위험을 피한 뒤 **5초**부터 시작하는 안을 시험한다. 상태 제거와 버팀 회복은 별개이며, 동료를 일으켰다고 주변의 열·김·접착면까지 사라지지 않는다.

### 1.2 몬스터 위협 — 예고 → 확정 → 실행 → 빈틈

| 단계 | 공통 규칙 | 피격자가 읽어야 할 정보 |
|---|---|---|
| 예고 | 몸짓·방향·소리로 공격 종류와 영역을 먼저 알림. 색이나 소리 하나에만 의존하지 않음 | 무엇이, 어느 방향에, 어떤 상태·충격을 줄지 |
| 확정 | 공격 직전 방향·영역을 고정. 발동 뒤 끝까지 따라붙는 급회전은 피함 | 지금 피하면 벗어날 방향과 공간 |
| 실행 | 예고한 영역의 실제 접촉만 판정. 짧은 공격 한 번이 여러 신체 접촉으로 중복 피해를 내지 않음 | 맞은 원인, 적용 상태, 버팀 변화 |
| 빈틈 | 공격 후 숨 고르기·빈 자세를 둠. 회피·동료 수습·반격 중 선택 가능 | 다음 공격 전 할 수 있는 행동 |
| 중첩 위협 | 여러 몬스터의 큰 제압 공격을 동시에 확정하지 않도록 조정 | 가장 임박한 위험과 다른 위험의 수·방향. 화면 구성은 T2 담당 |

| 기존 몬스터를 이용한 예시 [추천] | 예고와 회피 | 맞은 결과·수습 |
|---|---|---|
| 먹물도롱뇽 | 몸을 부풀리고 입 방향을 고정한 뒤 먹 분출. 옆으로 벗어나거나 가림물 이용 | 먹막으로 시야·빛이 가려짐. 먹물 자체를 지속 피해로 만들지 않음. 본인·동료가 막을 제거 |
| 부풀달팽이 | 부풀어 오르는 몸과 밀려날 방향을 먼저 보여 줌. 밀집된 통로에서 거리 확보 | 부푼 몸의 접촉이 밀침·충돌로 이어짐. 단순 스침마다 피해를 주지 않음. 당김 저항은 부푼 모습으로 설명 |
| 화덕딱정벌레 | v1.2의 밝아지는 턱에 준비 자세·소리를 더해 가열 방향 예고 | 열 노출·접착 해제·젖음에서 김 발생을 같은 순서로 처리. 냉각·거리 벌리기·공격 빈틈 이용 |

[사실] v1.2의 몬스터 처치와 재료 확보는 유지한다. [추천] 회피·구속·냉각으로 생긴 빈틈에 기존 가열·충돌 규칙으로 처치할 수 있게 하며, 접착 성공 자체를 즉시 처치로 계산하지 않는다. 몬스터 내구·처치 횟수·종별 수치와 새 공격 목록은 T4·T5 담당이다.

### 1.3 쓰러짐과 구조

| 항목 | 추천 규칙 |
|---|---|
| 기본 손 구조 | 누구나 처음부터 가능. 다가가 위험을 제거한 뒤 **3초** 동안 일으키기. 회복 아이템·특정 룬·소모 돈 불필요 |
| 구조 중단 | 구조자가 이동·자발 취소하거나 실제 위험 피해를 받으면 중단. 소리·먹물 묻음만으로 무조건 취소하지 않음. 여러 명이 붙어 구조 시간이 무한히 짧아지지 않음 |
| 구조 시간 제한 | 쓰러진 순간부터 **45초**. 새 피격으로 시간을 줄이거나 쓰러짐을 중복시키지 않음. 시간이 끝나면 영구 사망 대신 입구 응급 복귀 후 공방 활동 |
| 일어난 결과 | 즉시 다시 쓰러지는 문턱 아래로 버팀을 회복하고 짧은 피해 보호를 부여. 실제 회복량은 미정. 상태·바닥 위험·남은 물때는 그대로 |
| 직접 구조가 어려울 때 | 맨손 끌기로 위치를 옮길 수 있음. 구조자는 느려지고 양손 사용. 이동은 소생이 아니며, 끌리는 사람의 가방을 자동 반출하지 않음 |
| 룬으로 돕기 | **당겨라 + 너 + 잠깐**으로 시전 순간의 시전자 위치 쪽에 당긴 다음 손 구조. 벽·거리·질량·접착에 막힐 수 있고 안전한 도착점을 보장하지 않음 |
| 다른 수습 문장 | 가열로 접착을 풀거나 여과로 김을 줄여 구조 여건 개선. 젖었으면 김이 먼저 생김. 붙어라로 생물 치료, 걸러라로 만능 치료를 추가하지 않음 |
| 시간 경합 | 같은 판정 시점에 물때 종료가 이미 도달했다면 물때 정산 우선. 그 전에 손 구조가 완료됐으면 구조 인정. 어떤 경우도 물때 시계 초기화 없음 |
| 의도적인 구조 포기 | 본인이 응급 복귀를 선택할 수 있음. 정상 귀환과 운반물 결과가 다름을 먼저 알려 줌. 동료의 강제 포기는 허용하지 않음 |

[추천] 기기·끌기·당김 중에는 쓰러짐 제한 시간이 계속 흐른다. 구조 동작 시작만으로 시간을 무한히 멈출 수 없게 한다. 판정은 호스트 서버의 사건 순서를 기준으로 한 번만 처리한다.

### 1.4 전멸·응급 복귀·물때 종료의 구분

**[추천] 전멸은 ‘던전에 남은 사람에게 손 구조나 허용된 자력 회복으로 다시 활동할 길이 없는 상태’다.** 공방에 먼저 돌아간 동료는 구조 인원에 포함하지 않는다. 접속 장애만으로 생긴 부재는 전멸 판정에서 제외하고 2.3을 따른다.

| 상황 | 사람·원정의 결과 | 잃는 것·남는 것 |
|---|---|---|
| 한 사람 쓰러짐 후 구조 성공 | 같은 원정 계속 | 구조에 실제 쓴 스크롤만 소비. 운반물·기존 지식 보존 |
| 개인 구조 실패·응급 복귀 | 해당 인원은 입구를 거쳐 공방으로. 동료 원정은 계속. 본인은 당일 재입장 불가 | 손·가방의 운반물을 현장 회수 꾸러미로 남김. 남은 동료가 물때 전에 반출하면 전부 보존 |
| 전멸 | 쓰러진 전원을 응급 복귀. 장시간 관전 없이 공방 작업 가능 | 몸과 짐을 분리해 짐은 미반출 상태. 전투 순간에 돈·설비를 차감하거나 물품을 바로 침수 처리하지 않음 |
| 물때 종료 | 아직 던전에 있는 사람은 상태와 무관하게 입구 복귀 | 0장의 확정 취약성에 따라 미반출 확보 물품만 한 번 파손·보존. 원래 공방 재고와 먼저 반출한 물품은 제외 |
| 정상 조기 귀환 | 가진 물품과 함께 공방 복귀 | 운반물 전부 보존. 현장에 놓고 온 물품은 아직 반출한 것이 아님 |
| 접속·호스트 종료 | 2.3의 연결 복구 또는 공동 중단 | 전멸 벌금·즉시 침수·날짜 증가 없음. 진행 중인 다른 사람의 세계 결과와 저장 복구는 별도 |

| 회수·정산 세부 | 추천 규칙 |
|---|---|
| 회수 꾸러미 | 기존 물품의 수량·소유권·봉인 여부를 옮겨 담는 표시. 새 아이템이나 용량 보너스 아님. 다른 사람이 자기 가방의 빈칸만큼 나눠 회수 가능 |

| 호스트가 자리를 비움 | 호스트가 저장 후 나가면 모두 중단 | **본편 기본안은 자동 호스트 이전 없음.** 원래 호스트가 다시 열어야 같은 공방을 계속함. 다른 사람이 소유권을 넘겨받는 기능은 별도 팀장 판단 |
| 일부 동료 없이 재개 | 준비 대기 중에는 세계 시간을 멈추고, 호스트가 재개하면 부재자는 연결 복구 대기로 유지 | 부재자의 짐을 복제·삭제하지 않음. 신규 인원을 그 출발자의 대체 원정자로 만들지 않음 |

| 연결 복구 대기의 세부 [추천] | 규칙과 절충 |
|---|---|
| 잠깐 끊긴 몸 | 이동·채집·시전 불가 상태로 보관하고, 원인과 무관하게 새 버팀 피해·피격 경직을 중지. 기존 열·환경의 지속 노출도 이 보호에 포함. 주변 물품과 다른 사람은 막지 않으며 기존 버팀을 회복시켜 주지 않음 |
| 상태와 시간 | 상태의 원래 종료 시각, 이미 쓰러진 사람의 구조 제한, 물때는 호스트의 진행을 따름. 접속이 끊겼다는 이유로 구조 성공·정상 귀환을 지급하지 않음 |
| 물품 회수 | 가방은 현장 공동 회수 대상으로 접근 가능. 누가 회수하면 해당 수량을 원래 가방에서 차감. 돌아온 사람에게 회수 전 가방을 다시 지급하지 않음 |
| 재접속 위치 | 원정이 열려 있고 귀환이 미확정이면 같은 참가자의 현재 원정 상태로 복구. 위치가 막혔으면 같은 구역의 가까운 유효 위치로만 보정. 입구 이동·버팀 회복을 보상으로 주지 않음 |

| 예약 이후 | 예약 만료만으로 응급 복귀·파손을 일으키지 않음. 원정이 아직 열려 있으면 원래 상태 연결 복구 가능. 실제 물때·구조 제한 종료·명시적 참여 포기로 귀환이 확정되면 이후 공방 복구 |
| 대기 인원만 남음 | 접속 장애를 전멸로 판정하지 않음. 호스트는 저장하고 중단하거나 세계 진행을 계속할 수 있음. 계속한 세계에서 실제 물때가 끝나면 기존 미반출 판정 적용 |
| 악용 여지 | 고의 단절도 짧은 피격 회피가 될 수 있음. 새 공격 보호와 재료 안전 반출은 분리하고, 물때·기존 상태·출입 기록은 유지. 보호 방식을 악용 억제만으로 가혹하게 정하지 않고 시험 |

[추천] 자리 예약은 재접속 편의를 위한 값이지 소유권 삭제 시한이 아니다. **공방 식별값 + 날짜·원정 번호 + 참가자 식별값**에 출발·귀환·물품 이동을 연결해 저장한다. 옛 120초 슬롯은 비교 후보로만 두며, 짧은 세션에서 자리 회복률과 새 참가자의 기다림을 측정해 결정한다.

### 2.4 공용 자금·재고 사용 권한

| 구분 | 기본 권한과 사고 방지 |
|---|---|
| 새 게스트 | 제작·정리·구조는 가능. 공용 돈을 쓰는 구매는 호스트가 운영 예산을 열기 전에는 요청만 가능 |

| 보호할 자금 | 운영 예산 밖의 금액은 일반 구매에 사용 불가. 호스트도 한 거래의 명시적 확인 없이 보호 금액을 소모하지 않음. 금액·비율은 T4 담당 |

| 동시 구매 | 서버가 잔액과 예산을 함께 예약·차감. 두 사람이 각각 화면의 옛 잔액 전부를 쓰는 요청은 둘 다 통과시키지 않음 |
| 인쇄·판매 | 주문·출정 준비에 예약한 재고는 다른 인쇄·판매에 못 씀. 예약 밖 재고도 선택 수량과 총 소모를 확인한 뒤 확정. ‘전부’가 즉시 실행되지 않게 함 |

| 권한 회수 | 호스트는 이후 지출 권한을 거둘 수 있음. 이미 확정된 거래를 거짓으로 되돌리지 않음. 취소 가능한 미완성 예약만 정리 |

[추천] 탐험 중 스크롤을 쓸 때마다 호스트 허락을 요구하지 않는다. 준비 단계의 소지 한도와 재고 예약으로 물자 노출을 제한하며, 사용 한 장은 v1.2대로 한 번 소비한다.

## 3. 가방·스크롤·캠페인 실패 규칙

### 3.1 들고 다닐 수 있는 양

아래 수량은 **[추천] 검증 전 시작값**이며 가격·재료 환산량이 아니다. 재료마다 무게·습도·품질 수치를 추가하지 않는다.

| 항목 | 시작안 | 경계 |
|---|---|---|
| 재료 가방 | **8칸**, 같은 품목·가공 상태끼리 **칸당 10개**까지. 빈칸이 있으면 같은 품목을 다른 칸에 더 담을 수 있음 | 최대 80개는 작은 재료 단위의 이론상 합계. 여러 품목·중간재를 섞으면 남는 칸·수량이 달라짐 |
| 손에 든 재료 | 가방에서 꺼낸 재료도 원래 칸의 점유를 유지 | 손에 들었다 놓기를 반복해 한도를 늘리지 않음 |
| 무게 | 재료 가방의 무게·과적 이동 감속 없음 | 기존 소품의 질량·고정 여부는 마법 이동 판정에 그대로 사용. 운반 가능한 재료와 큰 장식 소품을 같게 취급하지 않음 |
| 스크롤 | 재료와 별도 공간에 **총 6장**. 문장 종류와 무관하게 한 장씩 셈 | 손에 든 것·봉인품·미봉인품 포함. 봉인은 방수 판정만 바꾸며 소지 한도를 늘리지 않음 |
| 휴대 도안판 | v1.2의 완성 문장 2개 유지 | 실제 스크롤 6장과 다른 제한. 도안은 소모품이 아니며 재접속으로 현장 도안 교체 불가 |
| 가방이 가득 참 | 초과 줍기를 거절하고 필요한 수량만 회수 가능. 기존 물품 자동 삭제 없음 | 내려놓은 확보 물품은 원정 장부에 남아 물때 동일 판정 |
| 현장 급조 | 완료할 스크롤 공간을 먼저 예약. 공간이 없으면 시작 불가 | 완성 때 재료 한 번 소비, 취소 때 예약만 해제. 스크롤을 만들었다는 이유로 봉인되지 않음 |
| 동료 짐 회수 | 자기 빈칸·스크롤 여유 안에서 나눠 옮김 | 꾸러미째 들었다고 모든 내용물이 자기 가방 한 칸이 되지 않음 |
| 공방에 돌아옴 | 물품을 공동 공방 소유로 반출 확정. 안전 반출품이 공방 수용량 부족만으로 자동 삭제되거나 다시 침수되지 않아야 함 | 초과 재고 보관 방식·상한·공방 서랍과 설비 영향은 T4 결정. 보관 위치가 바뀌어도 가방·재고에 중복 지급하지 않음 |

[추정] 1~4인에게 같은 개인 한도를 쓰면 협동 총 운반량은 늘어난다. 이를 이유로 물건 가격이나 수락한 주문 수량을 즉시 바꾸지 않는다. 혼자의 필수 재료 구색, 인원별 실제 회수량, 초과 짐 때문에 버린 시간은 T4가 비교해야 한다.
