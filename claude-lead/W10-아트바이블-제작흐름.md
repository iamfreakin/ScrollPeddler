## 0. 결론
1. **그림체 규칙 4개:** ① 두툼하고 단순한 형태 ② 질감은 그리지 않고 색 면으로 ③ 공방은 따뜻한 낮빛, 던전은 어둠 속 강한 광원 ④ **룬 7색이 화면에서 가장 진한 색** — 환경은 채도를 낮춘다.
2. **AI 모델의 들쭉날쭉함은 "팔레트 스냅"으로 잡는다.** Meshy가 만든 모델의 색을 Codex가 짠 Blender 스크립트로 우리 팔레트 칸에 강제로 맞춘다. 모든 에셋이 같은 색 목록을 쓰니 한 게임처럼 보인다.
3. **벽·바닥·계단 같은 조립 부품은 AI로 만들지 않는다.** 1m 격자에 딱 맞아야 해서 Codex가 Blender 스크립트로 생성한다. AI는 소품·인물·생물처럼 모양이 자유로운 것에 쓴다.
4. **1인칭 손 애니메이션 5개**(찢기·끼우기·굳히기·인쇄 손잡이·봉인)가 아트 최우선 작업이다.

## 2. 제작 흐름 — Blender + Meshy AI + Codex
\[사실\] 사용자가 직접 만든다. \[추정\] 아래는 1인 제작용 권장 흐름이고, Meshy의 현재 기능·요금제·약관은 **구매 전 공식 문서로 확인**한다.

```plain text
① 컨셉 그림(GPT 스레드) ─▶ ② Meshy: 그림 → 3D 초안 ─▶ ③ Blender 정리(Codex 스크립트)
      ─▶ ④ 뼈대·애니메이션 ─▶ ⑤ UE 가져오기(Codex 스크립트) ─▶ ⑥ 게임 안 확인
```

| 단계 | 누가 | 할 일 |
| --- | --- | --- |
| ① 컨셉 | 사용자(GPT 스레드) | §5의 고정 문구로 그림. 물건은 정면·옆면 두 장 |
| ② Meshy | 사용자 | 그림 → 3D 초안. 사람형은 A자세로 |
| ③ 정리 | **Codex가 Blender 파이썬 스크립트 작성·실행** | 아래 §2.1 |
| ④ 뼈대 | 사용자 + Codex | 사람형: 자동 뼈대 도구 결과를 스크립트로 이름 정리. 생물: 뼈대 3종을 한 번 손으로 만들고 재사용(W04 §6) |
| ⑤ UE | Codex | UE 파이썬으로 일괄 가져오기, 재질 인스턴스 연결, 충돌·LOD 확인 |
| ⑥ 확인 | 사용자 | 크기·색·실루엣·성능 |

### 2.1 Codex가 만들 Blender 스크립트

| 스크립트 | 하는 일 |
| --- | --- |
| `sp_cleanup.py` | 가져오기 → 크기 맞춤(UE 센티미터) → 원점 바닥 중앙 → 앞쪽 +X → 떨어진 조각·안쪽 면 제거 |
| `sp_retopo.py` | 면 수를 목표치로 줄임(쿼드 리메시 또는 줄이기). 목표: 작은 소품 300\~1,500 / 큰 소품 1,500\~4,000 / 사람 4,000\~7,000 / 생물 3,000\~6,000 삼각형 |
| **`sp_palette_snap.py`** | Meshy 텍스처에서 면마다 색을 뽑아 **팔레트 표(256×256, 칸마다 한 색)의 가장 가까운 칸으로 UV를 옮긴다.** 결과는 텍스처 하나를 모든 에셋이 같이 쓰는 모델. 얼굴처럼 꼭 필요한 부분만 작은 손그림 텍스처 허용 |
| `sp_normals.py` | 부드러운 음영 각도·가중 법선 정리 |
| `sp_lod.py` | LOD 2단계(50%·25%) |
| `sp_collision.py` | 볼록 충돌체(`UCX_` 접두어) 생성 |
| `sp_export.py` | 이름 규칙 검사(`SM_`·`SK_`·`T_`·`M_`) → FBX 내보내기 |
| **`sp_kit_*.py`** | **조립 부품 생성기.** 1m 격자의 벽·바닥·계단·난간·관·들보·레일·수로를 매개변수로 찍어 낸다(AI 사용 안 함) |
| `ue_import.py` | UE에서 폴더 규칙대로 가져오고 공통 툰 재질 인스턴스를 붙임 |

- 실행: `blender --background --python sp_cleanup.py -- 입력.glb 출력.fbx`처럼 명령 한 줄. Codex가 폴더 하나를 통째로 처리하게 한다.
- 스크립트는 프로젝트 `Tools/Blender/` 폴더에 두고 Git으로 관리.

### 2.2 약관·권리 \[확인 필요\]
- Meshy 결과물의 **상업적 사용 가능 여부와 조건은 요금제마다 다를 수 있다.** 출시 전에 약관 원문을 확인하고, 사용한 요금제·날짜를 기록해 둔다.
- 이미지 생성 문구에 실제 게임·작가·브랜드 이름을 넣지 않는다.
- 구매한 에셋(소리·음악·글꼴)은 영수증과 라이선스 파일을 `Docs/Licenses/`에 모은다.
