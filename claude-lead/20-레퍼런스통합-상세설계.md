## 2. 공방의 하루와 손으로 판단하는 제작

### 2.1 현재 하루를 실제 업무로 연결

| 경과 [추정] | 행동 | 다음 구간을 바꾸는 판단 |
|---|---|---|
| 0~2분 | 주문·신문·재고를 한 자리에서 읽음 | 저장 판 재사용 / 조건 하나 변경 / 이번에는 보류 |
| 2~6분 | 조립·무료 시험·먹 준비·인쇄 병렬 진행 | 한 장 시험 뒤 묶음 수량 확정, 주문과 출정 몫 분리 |
| 6~8분 | 적합 검사·봉인·상자·출정 준비 | 판매할 것 / 휴대할 것 / 공방에 남길 것 |
| 8~11분 | 가까운 구역에서 단서·채집 | 부족한 동사 원료와 부재료를 우선 선택 |
| 11~17분 | 생물 행동·잔향·협동 수습 | 추가 채집의 값과 취약품 반출 위험 비교 |
| 17~20분 | 9분 경고·귀환 | 먼저 나온 사람이 분류·추가 인쇄 시작 |
| 20~22분 | 공동 재고 합류·포장 | 새 반출량으로 부족 계획 수정 |
| 22~24분 | 납품·자유 판매·정산·다음 준비 | 돈을 번 원인과 다음 원정 목적 확인 |

공방 약12분·원정 최대12분은 대표 흐름이다. 20~40분 한 세션, 첫날 공방14+원정12+마감4=30분, 5일 한 주100~130분은 현재 목표를 유지한다. 먼저 귀환한 사람의 공방 시간을 원정 시간에 다시 더하지 않는다. 준비가 오래 걸리면 물때를 줄여 맞추지 않는다.

### 2.2 주문 카드 — 대사와 판정을 같은 조건으로

[추천] 주문지 앞면에는 손님의 문장과 아래 항목을 표시한다. 대표 도안은 예시이며, 합격 조건이 같으면 수락 후에도 다른 문장으로 납품할 수 있다. 수락 전에는 작업 수·사용 조건·대표 견적을 고정한다. 대안의 실제 장수와 재료량은 별도로 기록하며 계약을 다시 계산하지 않는다.

| 항목 | 카드에 쓰는 내용 | 예: M04 관 고정 |
|---|---|---|
| 사용 상황 | 손님이 하려는 일 | 양손으로 나사를 조이는 동안 맞댄 관 고정 |
| 작업 한 단위 | 사람·설치물·회수 작업 중 무엇을 세는가 | 관 결합부 한 곳 |
| 반드시 필요한 결과 | 대상·효과·유지 조건 | 비생물 관, 접촉 결합, 작업 중 고정 |
| 피해야 할 결과 | 같은 효과여도 곤란한 사용 | 얼굴/몸 접착, 허공 고정, 열로 수리했다고 판정 |
| 대표 판 / 대체안 | 적합한 알려진 문장, 필요한 장수 | 붙어라+물건+오래. 대체는 작업 검증 후 목록 등록 |
| 수량·부재료·대금 | 줄별 장수·부재료·확정 총액 | 수락 인원 기준으로 고정 |
| 마감 설명 | 필수 날짜·선택 기한 구별 | 고유 의뢰는 소개일 이후 보류 가능 |

종이 시험에서는 문장·대상·지속 같은 읽을 수 있는 규격을 판정한다. 실제 물리 작업의 성공은 §4 계수를 정하고 검증해야 한다. “오래면 무조건 수리 성공” 같은 결과를 도안 이름으로 보장하지 않는다.

| 응대 | 주문지 읽기·판 선택·장수 표시 | 기존 판이 현재 사용처에도 맞나 | 주문 번호·문장·작업 단위·수량 |

| 인쇄 | 활자 조립·시험·판 저장·묶음 인쇄 | 수정 후 시험할까, 기존 판으로 반복할까 | 판 버전·실제 예약 수량·완료 장수 |

[추천] 인쇄는 **장별 완료**를 거래 단위로 삼는다. 장 하나를 완료할 때 그 장의 예약 원료를 소비하고 미봉인 완제품 한 장을 만든다. 묶음 취소는 남은 장의 예약만 풀고, 이미 완료한 장을 지우거나 환불하지 않는다. 이는 현재 “예약/소비 분리”를 더 닫는 적용안이며 W02·T8에 같은 시점으로 적어야 한다.

| 인원 | 업무량·참여 방법 |
|---|---|
| 1인 | 공정 순서대로 판단. 갈기·인쇄 반복은 자동 처리 가능. 시험과 적합 확인은 생략하지 않음 |
| 2인 | 응대/시험과 먹/인쇄를 병렬로 시작. 포장·출정 몫은 서로 넘겨받고 다음 날 역할 변경 가능 |
| 3~4인 | 주문 판·개인 시험·먹 준비·포장을 병렬 진행. 두 판틀은 개인 조립을 지원하되 직업 독점 권한 없음 |
| 늦게 접속 | 그날 수락 수량은 고정. 공방 업무 가능, 출정은 다음 날. 완료한 사람의 시험을 개인 완료로 대신 기록하지 않음 |

### 2.4 계획 재고와 실제 예약의 예

[추천] 선반·주문 카드의 기존 표시로 네 몫을 보여 준다. 새 창고 화면을 따로 늘리지 않는다.

| 상황 | 표시·처리 |
|---|---|
| 종이10장, 주문4장·출정4장 계획 | 계획 여유2장. 계획은 다른 사람의 사용을 막지 않음 |
| 주문4장 인쇄 시작 | 실제4장 예약. 다른 인쇄·급조는 이4장을 소비할 수 없음 |
| 다른 사람이 예약 밖 종이3장 사용 | 계획 여유가 부족1장으로 바뀜. 추가 구매/출정 장수 변경 중 선택 |
| 인쇄2장 완료 뒤 취소 | 종이2장·먹2장분 소비, 완료품2장 유지, 나머지2장 예약 해제 |

### 7.4 전체 재고 보존과 안전 반출 수급을 구별

[추천] 종이·기본 먹은 각각, 동사 먹은 동사별로 같은 단위로 환산한다. 모든 위치의 소유 재고가 보존되는지 확인하는 장부와, 공방에 새로 확보한 공급률은 다른 지표다.

| 기록 | 세는 시점·범위 | 제외 |
|---|---|---|
| 전체 소유 유입 | 자연 자원을 최초 확보하거나 실제 구매할 때1회 | 반출·회수·공방 이동·갈기·인쇄 |
| 전체 외부 소비 | 납품·판매·찢기·실제 파손 때1회 | 원료→먹→제품의 내부 전환 |
| 전체 보유량 | 공방+가방+손+현장 확보품+계약 상자. 원료·먹·제품에 담긴 양 환산 | 미채집 자원·계획 숫자 |
| 안전 반출 수급 지표의 분자 | 새 채집이 정상 반출·종료 안전 회수로 공방에 들어온 양+실제 구매 | 기존 휴대품 귀환·현장 획득 자체·내부 전환 |
| 안전 반출 수급 지표의 분모 | 3일 동안 실제 외부 소비. 현장 사용·파손도 포함 | 공방에서 만든 것을 현장 급조로 다시 센 가공량 |
| 목표 | 기존3일 전체/동사별1.0~1.15를 유지. 시작 비축과 현장 보유도 함께 해석 | 비율만으로 재고 보존을 증명하지 않음 |

전체 보유량 변화=전체 소유 유입−전체 외부 소비다. 안전 반출 수급률은 이 등식의 유입과 같은 변수로 쓰지 않는다.

예: 수지1개를 현장에서 확보하면 전체 유입+4먹회분·현장 보유+4,안전 반출0이다. 그중1회분을 급조해 사용하면 외부 소비1·현장 보유3이다. 나머지3을 반출하면 전체 유입 추가0·공방 보유3·현장 보유0·안전 반출+3이다. 처음 얻은4와 돌아온3을 더해 공급7로 기록하지 않는다. 취약품을 반출 전 잃으면 전체 유입과 파손은 기록되지만 안전 반출은0이다.

비축을 쓰거나 현장에서 새 재료를 바로 사용하는 구간은 안전 반출 비율이1보다 작을 수 있다. 그 원인을 전체 장부로 확인한 뒤 다음 구간 구매·채집량을 조정한다. 납품량을 접속 변화로 다시 늘리지 않는다.

### 13.1 90초 이후의 참여 유지안

[추천] 자리 예약 만료와 원정 참여 종료를 분리한다. 일시 단절은 해당 원정 물때 종료까지 참여 기록·같은 몸을 유지한다. 빈자리로 복귀하면 같은 진행을 이어받으며 자력 회복 횟수를 초기화하지 않는다. 원정 종료 뒤에는 공방으로 돌아온다.

자발적 퇴장은 참여 종료다. 새 게스트가4인 자리를 채우면 단절자는 연결해 조작할 수 없지만,그 사람의 확보품은 현장/종료 판정을 따른다. 새 게스트는 공방에 있으므로 그날 던전 발견의 참여자로 바뀌지 않는다. 단절자의 몸·회복·피해는 기존 단절 규칙을 따르며 무적 보관함을 새로 만들지 않는다.

물때 끝에 취약품/강한 확보품을 한 번 정산하고 참여를 종료한다.90초 자리 해제만으로 몸·짐을 지우거나 “전원 귀환”을 판정하지 않는다. 실제 몸의 대기 표현·공방 복귀 위치는 T1/T8에서 동일 상태로 구현할 검증 항목이다.

### 13.2 영속 저장 실패의 추천 정책

[추천·새 예외 정책] 디스크 저장 실패를 확인하면 두 공간을 공동 일시 중단한다. 물때·효과·공정·새 거래 승인을 함께 멈추고,기존 메모리의 확정 거래를 임의 환불하지 않는다. “저장 문제로 잠시 멈춤 / 마지막 정상 저장 시점 / 재시도”를 표시한다.

| 구분 | 처리 |
|---|---|
| 이미 메모리에 확정 | 같은 거래를 재실행하거나 뒤집지 않음. 현 상태의 공동 저장 재시도 |
| 승인 전 새 거래 | 중단 중 보류·거부. 소비와 성공 화면 없음 |
| 저장 성공 | 공동 시점·개정 확인 뒤 재개,개인 기록 전달 |
| 계속 실패 | 마지막 정상 시점과 보존되지 못한 구간 표시. 정상 종료 재시도 또는 마지막 정상본 다시 읽기 선택 |
| 강제 종료 | 마지막 정상본 복원. 그 이후 메모리 상태까지 보존됐다고 약속하지 않음 |

이는 현재 “실패 안내·재시도”의 구체적인 추천 변경안이다. 저장 실패 중에도 물때와 거래를 계속 진행시키는 안보다 정산 경계가 명확하다. 실제 저장 성공·원자성·복구 성능을 문서만으로 보장하지 않는다.

## 18. 작성 기록

현재 v2.1·D8·T/W 분야 원문과 공식 조사 자료를 바탕으로 행동·판정·이야기를 한 흐름으로 썼다. 의뢰32조건·42기본 결과·재료/생물 연결·첫5일 장부·업적30·데모·저장15예외를 추가했다. 기준과 다른 축제·상태 배정·업적·짧은 데모·저장 실패 정책은 추천 변경으로 구별했다.

문서 검토에서 대안 견적과 실제 장수,현장 확보와 안전 반출,재주문의 거리와 지속,복습 잔향의 범위를 대조해 수정했다. 의뢰·재료·생물·업적·예외의 항목 수와 첫5일 산술을 확인했다.

이 문서는 문서상 정합성과 산술을 검토한 작성본이다. 실제 재미·물리 반응·저장 안전·제작 기간·약10시간 분량은 검증 전이다.
