### 1.1 계산 기준과 행동 한 번의 시간

[추정] 대표일은 **숙련 1인, 판매 4장 + 탐험 준비 4장, 새로 검토할 문장 2개**다. 출발 전 6장, 귀환 후 2장을 만든다. 탐험 준비량과 실제 사용량은 다르며, 남은 봉인품은 다음 날 재사용한다. 긴 효과의 종료를 매번 기다리지 않고 저장 도안을 반복 이용하는 날을 계산했다.

### 1.2 공방 12분 — 출발 전 8분 + 귀환 후 4분

|---|---|---:|
| 출발 전: 주문·재고 | 주문 2건×25초 + 신문 20초 + 재고 25초 + 오늘 계획 25초 | 120초 |

[추정] 자동 출력은 출발 전 18초 + 귀환 후 6초 = 24초다. 출력 중 주문 대조·다음 배합 준비·부족분 확인을 하므로 위 표에는 설정 시간만 더했다. 각 묶음의 출력 완료 뒤 포장하는 순서를 지킨다. **동시 작업이 불가능하면 744초, 즉 12분 24초**가 된다. 능숙하게 빨리 끝낸 사람에게 남은 시간을 기다리게 하지 않는다.

### 1.4 1~4인이 같은 일을 했을 때

[추정] **모두 총 8장·주문 2건·같은 탐험 목표**를 수행하는 비교다. 이동·관찰·공동 판단까지 인원수로 나누지 않는다. 공방은 공동 순서 480초 + 분담 가능 작업 240초, 던전은 공동 진행 600초 + 분담 작업 120초로 근사한다. 소통은 추가 인원당 공방 20초·던전 10초를 더한다.

| 실제 기본일의 인원별 수량 | 1인 | 2인 | 3인 | 4인 |

보유 목표는 **파티 전체**이며 사람마다 4장을 신규 지급하지 않는다. 휴대 도안판의 두 칸은 저장 문장 수이지 완제품 휴대 한도가 아니다. 다음 날에는 실제 사용·파손분만 보충한다. 한 장의 원가·판매가·효과는 인원에 따라 바꾸지 않는다.

[추정] 실제 기본일은 추가 주문·재료·생산량에 절약한 시간을 쓰므로 같은 물량 표보다 길어진다. 추가 주문 1건의 확인·대조 40초, 추가 판매품 2장의 먹 준비·설정·포장 24초를 분담한다면 추가 공방 시간은 2인 32초, 3인 약 43초, 4인 48초다. 이는 **추가 판매분의 부분 예산**이며, 탐험품 보충 증가·추가 납품·이동·새 문장 시험은 별도다. 따라서 **같은 일의 표만으로 모든 인원에서 정확히 24분·10시간이라고 보장할 수 없다.** 실제 인원별 목표는 22~26분 중심, 세션 20~40분 이내로 검증한다.

[사실] 함께 출발하고 개인 조기 귀환은 허용하지만 당일 재입장은 금지다. 귀환자가 공방에서 작업하는 시간과 남은 동료의 탐험 시간은 겹친다. 하루 경과 시간은 두 시간을 단순 합산하지 않고 마지막 필요한 작업이 끝나는 시점으로 잰다.

## 2. 경제 수치

### 2.1 통화·원료·환산 단위

[추천] 통화는 **G**, 최소 단위 1G다. 시작 공용 자금은 인원별 120·180·240·300G다. 아래 구매가는 플레이어가 상인에게 지불하는 가격, 판매가는 상인이 원료를 사 주는 가격이다. 원재료와 먹 소분은 같은 환산 비율을 쓰며, 판매 총액의 1G 미만은 거래 끝에서 버린다. 가공·합치기로 판매액이 증가하지 않게 한다.

| 재료 | 원재료 구매가 | 원재료 판매가 | 원재료 1개→동사 먹 | 먹 1회분 구매가 | 물때 파손 |
|---|---:|---:|---:|---:|---|
| 등심이끼 | 12G | 4G | 4회분 | 3G | 아니요 |
| 눌림수지 | 16G | 6G | 4회분 | 4G | 아니요 |
| 말린 되감이풀 | 20G | 8G | 4회분 | 5G | **예** |
| 숨돌 | 24G | 10G | 4회분 | 6G | 아니요 |
| 탄성점액 | 48G | 16G | 2회분 | 24G | 아니요 |
| 발열턱 | 56G | 20G | 2회분 | 28G | 아니요 |
| 먹주머니 | 64G | 24G | 2회분 | 32G | **예** |
| 바탕 종이 | 2G/장 | 1G/장 | 해당 없음 | 해당 없음 | **예** |
| 기본 먹 | 1G/회분 | 0G/회분 | 동사 먹을 대신하지 않음 | 해당 없음 | 아니요 |

[사실] 물 취약 원재료는 v1.2의 3종만 유지한다. 동사 먹으로 갈아도 원료의 취약성을 유지하는 v1.2 시작안을 따른다. 몬스터 원재료 구매가는 2회분 전체를 구할 수 있을 때의 환산가이며, **모든 품목을 매일 원재료 단위로 살 수 있다는 뜻이 아니다.** 상인 물량은 3.3절에서 정한다.

### 2.2 원가·판매가·의뢰 보상

| 항목 | 계산 규칙 |
|---|---|
| 동사 먹 소비 m | 잠깐 1회분, 나머지 수식 2회분. 대상이 주변이면 +1회분 |
| 표준 원가 C | 종이 2G + 기본 먹 1G + m×해당 동사 먹 구매가 |
| 정상 수요 자유 판매가 F | **1.25×C+8G를 5G 단위로 올림** |
| 제작 의뢰의 총보상 | **납품 수량 q×F + 조건 보너스 B**. 제품 대금과 의뢰 보상을 별도 중복 지급하지 않음 |
| 조건 보너스 B | 입문 10G / 단일 환경 판단 20G / 조건 조합 30G / 후반 복합 조건 40G, 의뢰 한 건 기준 |
| 정상 수요를 초과한 제품 | 임시 매입가 C×0.6의 정수 내림. 그 가격으로 팔거나 다음 날 보관 |
| 상인의 탐험용 완제품 가격 | F+10G. 즉시 정상가 F에 되팔아도 이익 없음 |

### 2.5 사서 해결할지 직접 채집할지

구매와 채집은 **추가로 필요한 재료 한 묶음** 기준으로 비교한다. 이미 예정된 잔향 탐험 전체 12분을 재료 하나의 비용으로 붙이지 않는다.

| 계산 항목 | 뜻 |
|---|---|
| 필요한 재료의 절약액 | 직접 쓸 양×상인 구매가. 남는 재료는 실제 판매가 또는 다음 날 필요한 양의 가치만 인정 |
| 채집 순이점 | 기대 절약액 + 실제 처분 가능한 잔여 가치 − 추가 스크롤 원가 − 추가 시간×시간 가치 |
| 손익 분기 시간 | (기대 절약액 + 잔여 가치 − 추가 스크롤 원가) ÷ 시간 가치 |
| 시간 가치의 시험값 | 0.3G/초, 즉 18G/분. 실제 환전 규칙이 아닌 대체 작업의 가치 가정. 0.1·0.3·0.6G/초로 민감도 비교 |
| 취약 원료 | 안전 반출 가능성×가치를 사용. 파손 확률을 시스템에 새로 넣는다는 뜻이 아니라 플레이 실측 비율 |

| 상황 | 계산 예 | 판단 |
|---|---|---|
| 지나가는 길의 등심이끼 1개를 전부 사용 | 12−8초×0.3 = **+9.6G** | 채집 유리 |
| 같은 이끼 1개 때문에 70초 우회·8초 채집 | 12−78×0.3 = **−11.4G** | 구매 유리. 분기점 40초 |
| 발열턱 1개, 먹 2회분 모두 필요 | 56−수습 원가13−90초×0.3 = **+16G** | 채집 유리. 분기점 약 143초 |
| 가열 먹 1회분만 필요, 남은 1회분은 판매 | 28+10−13−90×0.3 = **−2G** | 상인 재고가 있으면 1회분 구매 유리. 나머지를 구매가로 과대평가하지 않음 |
| 먹주머니 1개, 반출 성공 80% 가정 | 64×0.8−13−96×0.3 = **+9.4G** | 숙련된 안전 귀환이 가능하면 채집 유리 |
| 같은 먹주머니, 반출 성공 55% 가정 | 64×0.55−13−96×0.3 = **−6.6G** | 부족량이 상인 한도 이내면 구매 유리 |
| 이미 귀환했는데 1회분 부족 | [사실] 당일 재입장 불가 | 상인 소량 구매 또는 다음 날 이어서 납품 |

[추천] 재료 판매액과 구매비 절감을 같은 재료에 함께 더하지 않는다. 시간 절약으로 처리할 다른 주문·탐색이 없다면 시간 가치는 낮아진다. 반대로 잔향 학습이 목적이라면 돈으로 환산하지 않아도 탐험할 이유가 있다. 어느 선택도 항상 정답이 되게 맞추지 않는다.

### 2.6 파산 방지와 현금 과잉 억제

| 문제 | 시작안 | 확인할 지표·한계 |
|---|---|---|
| 0G라 종이도 못 삼 | 의뢰인 지급 재료로 **2장 가공·납품, 보상 12G, 전체 약 90초** | 종이·기본 먹까지 지급. 하루 파티 최대 2건, 잔액 30G 미만 또는 일반 제작 불가일 때 제시 |
| 비상 재료·제품 되팔기 | 지급분과 결과물을 해당 주문에 묶음. 취소·납품 후 남은 지급분 회수 | 비상 제품은 자유 판매·다른 주문·개인 탐험에 전용하지 않음. 소유 재료는 회수하지 않음 |
| 구제 주문만 반복 | 일반 판매보다 낮은 수익, 하루 한도, 다음 영업일 재개 | 12G로 빛 또는 붙임 잠깐 한 장을 다시 제작 가능. 기본 왕복 경로는 스크롤 없이 이용 가능 |
| 같은 비싼 상품 무한 판매 | 정상 가격 수요는 의뢰+자유 판매 합쳐 **4·6·8·10장** | 도안 이름을 바꿔도 같은 요구 효과의 남은 수요 공유. 남는 제품은 낮은 매입가 또는 보관 |
| 신문 수요가 총매출을 계속 증가 | 예고한 효과의 배분을 바꾸고 기본 총량은 유지 | v1.2의 추가 수요를 시험할 때는 선택 +1장만 별도 표시하고 시간·수입 다시 계산 |
| 채집과 구매를 모두 최대로 함 | 동사별 재고가 다음 1~2일 사용량이면 그 재료 구매·선택 채집을 줄임 | 정상 3일 평균 수급/사용량 1.0~1.15를 목표로 측정. 숨은 재료 소멸 없음 |
| 돈으로 시간을 사고 싶음 | 기존 탐험 완제품 구매 F+10G, 일반 재료 구매, 실제 사용분 보충 | 직접 만든 빛·붙임 2장을 구매로 바꾸면 하루 추가 지출 47G, 준비 노동을 줄이는 선택 |
| 물때 실패를 돈으로 이중 벌줌 | 돈·설비 손실, 추가 벌금, 필수 수리비 없음 | 원료·제품 파손과 현금 거래를 별도로 한 번씩만 처리 |

**[추정] 현금 과잉은 아직 해결 완료라고 볼 수 없다.** 2.3절의 다섯 기준일 사이를 직선으로 이어 25일을 근사하면 매출 5,962.5G, 구매 1,752G, 영업 현금 증가 4,210.5G다. 실제 거래의 소수 G가 아니라 계산 평균이다. 시작금과 설비 2,500G를 반영한 마지막 잔액은 1인 약 **1,831G**, 같은 구성이 2.5배인 4인은 약 **8,326G**다. **4인 값은 상인 한도를 반영하지 않은 단순 외삽 참고치**다. 12·20·25일 구매표의 몬스터 먹 1회분을 2.5배로 사면 파티 한도 2회분을 넘으므로 실제로는 던전·전날 재고를 더 써야 한다. 이를 못 구해 납품이 줄면 현금도 줄고, 구매를 재고로 대체하면 더 남을 수 있다. 재료 판매 증가 역시 별도다.

[추천] 인원 배수로 나눈 현금이 후반 구매 예산 3일분을 넘고 구매 판단도 사라지는지를 과잉 신호로 본다. 먼저 자유 판매 수요·고보너스 주문 비중·실제 탐험 소모를 조정하고, 선택 완제품 구매가 시간을 절약하는지 확인한다. 의뢰만으로 총량을 채우는 후반에는 자유 판매 한도를 낮춰도 효과가 없으므로 **후반 B 40→30G 비교**도 함께 한다. 재료 가격을 올리는 것만으로 채집 수익까지 키우지 않는다.

**팀장에게 제안:** 공유 설비 3개·각 1단계만으로 모든 인원의 현금을 계속 소진시키기는 어렵다. 위 조정 후에도 남으면 추가 선택 지출을 별도 승인해 설계할지, 후반 저축 자체를 허용할지 결정이 필요하다. T4에서는 새 세금·강제 빚·추가 설비 단계를 도입하지 않는다.

## 3. 재료 수급률

### 3.1 지역·구역별 공급 상한

|---|---|

| 중반 8장 생산 | 잠깐 4장×1 + 나머지 4장×2 = **12회분**. 주변 문장이 있으면 추가 |

| 단위와 종류의 차이 | 붙임 먹 4회분이 남아도 가열 먹 1회분을 대신하지 못함. 전체 비율과 **동사별 비율을 함께 기록** |

[추천] 정상 거래가 이어지는 3일 평균에 대해 **(안전 반출 + 실제 구매) ÷ (외부 판매·납품·탐험 사용·실제 파손의 재료 환산량) = 1.0~1.15**를 목표로 한다. 분자·분모 모두 원료·먹·완제품을 같은 동사 먹 회분으로 환산한다. 안전 반출은 원정에서 새로 확보한 물량만 뜻하며, 가져갔던 봉인품의 귀환·공동 회수를 새 수입으로 세지 않는다. 원료를 먹이나 재고용 완제품으로 바꾸는 공방 내부 가공은 소비로 세지 않는다. 분모가 0인 동사는 비율 대신 재고만 기록한다. 막 진입 전 준비 재고를 쌓는 날은 일시적으로 초과할 수 있다. 판매·사용·파손 때 해당 분량을 한 번만 센다.

| 인원 | 공급·소비의 계산 배수 | 중반 일반/몬스터 원료 목표 | 중반 동사 먹 확보 |
|---:|---:|---:|---:|
| 1 | 1.0 | 2개/2개 | 12회분 |
| 2 | 1.5 | 3개/3개 | 18회분 |
| 3 | 2.0 | 4개/4개 | 24회분 |
| 4 | 2.5 | 5개/5개 | 30회분 |

[추천] 배수는 파티 합계다. 개인마다 같은 드롭을 복사 지급하지 않는다. 한도에 0.5개가 나오면 날짜별로 내림·올림을 교대하는 등 평균으로 맞출 방법을 T1에 넘긴다. 인원 변화로 당일 공급·주문이 다시 늘어나지 않게 수량 확정 시점은 공동 출발·주문 수락과 연결해야 한다. 세부 접속·저장 처리는 T1 담당이다. 협동에서 이 물량을 시간 안에 확보 가능한지는 1.4절과 함께 측정한다.

| 학습 직후 다음 날 | 새로 제시할 주문 조건을 1단계 낮추고 최소 1건은 기존 도안으로 해결. 높은 몬스터 수급 요구도 미룸 |
| 해금이 연속되는 경우 | 새 룬을 쓸 기회와 익힐 시간을 먼저 확보. 해금 순서·간격 변경은 T5에 요청 |
| 숙련 25일 | 5일×24 + 7일×24 + 8일×24 + 5일×24 = **600분 = 10시간** |
| 초보 시간 추정 | 공방의 추가 관찰·조립·복습 7~14분이면 25×31~38분 = **12시간 55분~15시간 50분**. 던전은 12분 유지하고 못 마친 해독·수습은 다음 날 재시도 |
| 초보 40분을 넘는 경우 | 복습·실패 다음 날을 추가해 마감. 한 세션을 늘리기보다 진행 일수가 늘어날 수 있음 |

**[추정] 600분은 예산 합계이지 모든 콘텐츠를 볼 수 있다는 검증 결과가 아니다.** 모든 콘텐츠의 범위를 T5·T6가 확정해야 한다. 210개 가능 문장 전체를 각각 제작·시험하는 것까지 포함하면, 문장당 조립·시험 55초만으로 약 193분이 들어가므로 현재 새 문장 예산과 다르다. 이미 계획한 시험과 겹치는 분량을 빼고 다시 계산해야 한다. T0의 18룬·12~14잔향·약 40의뢰·약 30도안과 실제 25일 해금표가 맞는지 팀장 확인이 필요하다.

**팀장에게 물을 것**
