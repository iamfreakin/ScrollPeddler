## 1. 시간 예산 — 하루 24분이 성립하는 조건

### 1.1 계산 기준과 행동 한 번의 시간

[추정] 대표일은 **숙련 1인, 계약 2장 + 자유 판매 2장 + 탐험 준비 4장, 새로 검토할 문장 2개**다. 이 합계 4장은 시간 계산의 예시이지 계약과 자유 판매를 합친 한도가 아니다. 출발 전 6장, 귀환 후 2장을 만든다. 탐험 준비량과 실제 사용량은 다르며, 남은 봉인품은 다음 날 재사용한다. 긴 효과의 종료를 매번 기다리지 않고 저장 도안을 반복 이용하는 날을 계산했다.

### 1.2 공방 12분 — 출발 전 8분 + 귀환 후 4분

| 시간대 | 동작 × 횟수 | 부분합 |
|---|---|---:|
| 출발 전: 주문·재고 | 주문 2건×25초 + 신문 20초 + 재고 25초 + 오늘 계획 25초 | 120초 |
| 출발 전: 생산 | 문장 2개×30초 + 시험 2회×25초 + 먹 준비 3회×12초 + 두 장 묶음 설정 3회×4초 + 두 장 포장 3회×8초 + 주문 대조 2회×15초 + 이동 2회×14초 | 240초 |
| 출발 전: 출고·준비 | 판매·납품 2회×20초 + 탐험 목표 20초 + 휴대 도안 2개 확인×10초 + 짐 배분 2회×10초 + 준비 확인 20초 | 120초 |
| **출발 전 소계** | **120 + 240 + 120** | **480초** |
| 귀환 후: 반출·생산 | 반출·분류 40초 + 먹 준비 12초 + 두 장 묶음 설정 4초 + 포장 8초 + 납품 20초 + 이동 16초 + 부족분·재고 판단 20초 | 120초 |
| 귀환 후: 마감 | 현금·손실 정산 30초 + 후기·새 이야기 45초 + 다음 주문 25초 + 다음 계획·마감 결정 20초 | 120초 |
| **공방 합계** | **480 + 120 + 120** | **720초 = 12분** |

[추정] 자동 출력은 출발 전 18초 + 귀환 후 6초 = 24초다. 출력 중 주문 대조·다음 배합 준비·부족분 확인을 하므로 위 표에는 설정 시간만 더했다. 각 묶음의 출력 완료 뒤 포장하는 순서를 지킨다. **동시 작업이 불가능하면 744초, 즉 12분 24초**가 된다. 능숙하게 빨리 끝낸 사람에게 남은 시간을 기다리게 하지 않는다.

[추정] 급조를 실행하지 않으면 예비 6초가 남는다. 공방에서 이미 8장을 만들고 현장에서 추가 제작하면 총 9장이므로 추가 원가와 남은 재고를 별도 기록한다. 급조 1장을 탐험 사용 4장에 다시 더하지 않는다. 실제 사고가 32초보다 길면 아래 초과 대응을 적용한다.

귀환 90초는 이동 270초 안의 예산이다. T3의 75초는 기본 보행·확인 목표이며 남은 15초는 돌발 여유다. 공방↔입구와 마을 외부 동선 약 90초는 공방 운영 시간에 포함하고 던전 시계에 다시 더하지 않는다. 위 공방 세부합은 외부 방문 전부를 따로 검증한 값이 아니므로 실제 전체 동선을 포함해 재측정한다.

### 1.4 1~4인이 같은 일을 했을 때

[추정] **모두 총 8장·주문 2건·같은 탐험 목표**를 수행하는 비교다. 이동·관찰·공동 판단까지 인원수로 나누지 않는다. 공방은 공동 순서 480초 + 분담 가능 작업 240초, 던전은 공동 진행 600초 + 분담 작업 120초로 근사한다. 소통은 추가 인원당 공방 20초·던전 10초를 더한다.

| 인원 | 공방 계산 | 공방 | 던전 계산 | 던전 | 하루 합계 |
|---:|---|---:|---|---:|---:|
| 1 | 480+240 | 12분 | 600+120 | 12분 | **24분** |
| 2 | 480+120+20 | 10분 20초 | 600+60+10 | 11분 10초 | **21분 30초** |
| 3 | 480+80+40 | 10분 | 600+40+20 | 11분 | **21분** |
| 4 | 480+60+60 | 10분 | 600+30+30 | 11분 | **21분** |

| 실제 기본일의 인원별 수량 | 1인 | 2인 | 3인 | 4인 |
|---|---:|---:|---:|---:|
| [추천] 하루 작업 계획용 주문 수 | 2건 | 3건 | 4건 | 5건 |
| [추천] 자유 판매 정상 수요 | 2장 | 3장 | 4장 | 5장 |
| [추천] 탐험품 파티 보유 목표 | 4장 | 6장 | 8장 | 10장 |
| [추천] 탐험에서 실제 사용하는 양 | 2~4장 | 3~6장 | 4~8장 | 5~10장 |

보유 목표는 **파티 전체**이며 사람마다 4장을 신규 지급하지 않는다. 휴대 도안판의 두 칸은 완성 문장2개 저장이며 완제품 휴대 한도가 아니다. 스크롤은 한 사람6장, 재료는 별도8칸이며 손에 든 스크롤도6장에 합산한다. 회수 꾸러미를 새 용량으로 더하지 않는다. 상세 수납 규칙은 T1을 따른다. 주문 납품은 대표 견적의 문장별 장수를 계산하며 실제 대안의 장수·먹은 별도로 센다. 위 자유 판매 수요로 계약을 자르지 않는다. 다음 날에는 실제 사용·파손분만 보충한다. 한 장의 원가·판매가·효과는 인원에 따라 바꾸지 않는다.

[추정] 실제 기본일은 추가 주문·재료·생산량에 절약한 시간을 쓰므로 같은 물량 표보다 길어진다. 추가 주문 1건의 확인·대조 40초, 추가 판매품 2장의 먹 준비·설정·포장 24초를 분담한다면 추가 공방 시간은 2인 32초, 3인 약 43초, 4인 48초다. 이는 **추가 판매분의 부분 예산**이며, 탐험품 보충 증가·추가 납품·이동·새 문장 시험은 별도다. 따라서 **같은 일의 표만으로 모든 인원에서 정확히 24분·10시간이라고 보장할 수 없다.** 실제 인원별 대표일은 22~26분 중심, 세션 20~40분 이내로 검증한다. A06과 같은 혼합 계약·변경 재주문이 있는 날에는 실제 줄·장수·시험 시간을 더하고, 다른 선택 주문·자유 판매를 줄이거나 분할 납품한다.

[사실] 함께 출발하고 개인 조기 귀환은 허용하지만 당일 재입장은 금지다. 귀환자가 공방에서 작업하는 시간과 남은 동료의 탐험 시간은 겹친다. 하루 경과 시간은 두 시간을 단순 합산하지 않고 마지막 필요한 작업이 끝나는 시점으로 잰다.

## 2. 경제 수치

### 2.1 통화·원료·환산 단위

[추천] 통화는 **G**, 최소 1G다. 시작 공용 자금은 1·2·3·4인 순서 **120·180·240·300G**다. 제품은 장, 원료·부재료는 개, 동사 먹은 회분으로 센다. 판매 총액의 1G 미만은 거래 끝에서 버리며 내부 가공·합치기로 재료 판매액이 늘어나지 않는다.

| 재료 | 원료 구매가 | 원료 판매가 | 원료 1개→동사 먹 | 먹 1회분 구매가 | 물때 파손 |
|---|---:|---:|---:|---:|---|
| 등심이끼 | 12G | 4G | 4회분 | 3G | 아니요 |
| 눌림수지 | 16G | 6G | 4회분 | 4G | 아니요 |
| 말린 되감이풀 | 20G | 8G | 4회분 | 5G | 예 |
| 숨돌 | 24G | 10G | 4회분 | 6G | 아니요 |

[추정] 인원별 세부 장부와 검산은 **W07 §7.2~7.3 한 곳**에 둔다. 1/2/4인 시작금120/180/300G에서 첫5일 실제 구매193/292/464G·계약 수입275/395/610G를 계산하면 마감 현금은 **202/283/446G**다. 자유 판매·재주문·화제·분실물 수입은0으로 두고, 3일 별도 구매 종이2장+말린 되감이풀1개24G를 물때에 잃는 경우를 포함한다. 24G는 구매 때 이미 차감하며 파손 때 현금에서 또 빼지 않는다.

## 3. 재료 수급률

### 3.1 실제 공급의 범위

[추천] 일반 동사 원료1개는 먹4회분, 몬스터 먹 원료1개는2회분이다. 부재료7종은 먹으로 환산하지 않는다. 출현 개체 수·채집 지점·상인 상한은 **획득 기회**다. 자연 자원을 최초 확보한 양은 전체 소유 장부에 한 번, 공방에 새로 들어온 양은 안전 반출 지표에 기록한다. 두 지표를 같은 공급 변수로 더하지 않는다.

| 원정 | 공급 계산의 경계 |
|---|---|
| 물레종이소 | 원료 마당의 일반 원료와 세척·건조실 생물을 따로 셈 |
| 잉크 광산 | 광산에서 실제 접근한 재료만. 물문달팽이 K13는 부재료 |
| 봉랍 양봉장 | 눌림수지 채집·풀옷도롱뇽과 발열턱 기회를 구분. 나방 K20는 부재료 |
| 심층부 | 물레종이소에 연결된 기존 지역 깊은 구역. 네 번째 독립 지역 공급을 더하지 않음 |
| 선택·반출 | 하루 한 원정. 다른 지역 최대치를 합치지 않음. 보유품 귀환은 신규 공급 아님 |

### 3.2 전체 소유 재고와 안전 반출 지표

[추천] 종이·기본 먹은 각각, 동사 먹은 전체/동사별로 같은 단위로 환산한다. 연속3일 안전 반출 수급률의 목표는 **`(새 안전 반출+실제 구매) ÷ (고유 납품+재주문+화제·반복 납품+자유 판매+탐험 사용+실제 파손·폐기)` = 1.0~1.15**다. 이는 모든 위치의 소유 재고 보존을 확인하는 장부와 다른 지표다.

| 장부 | 따로 기록할 것 |
|---|---|
| 전체 소유 유입 | 자연 자원을 최초 확보하거나 실제 구매할 때1회. 안전 반출·종료 회수·공방 이동 때 다시 유입으로 세지 않음 |
| 전체 보유량 | 공방+가방+손+현장 확보품+계약 상자의 원료·먹·제품 환산량. 미채집 자원·계획 숫자는 제외 |
| 안전 반출 분자 | 새 채집이 정상 반출·종료 안전 회수로 공방에 들어온 양+실제 구매. 기존 휴대품 귀환·현장 획득 자체는 제외 |
| 외부 소비·수급 분모 | 고유·재주문·화제/반복·자유·탐험·실제 파손·폐기. 현장에서 새 재료를 사용한 양도 포함 |
| 내부 가공 | 갈기·인쇄·봉인·예약·상자 이동은 외부 소비가 아님 |
| 기존 재고 | 출발 전 보유 원료·먹·봉인품, 되가져온 양. 새 공급과 구분 |
| 단위 | 종이 장수·기본 먹 회분·부재료 개수·현금도 별도 기록 |
| 분모 0 | 비율 없음. 공급·재고량만 기록 |

**전체 보유량 변화=전체 소유 유입−전체 외부 소비**다. 안전 반출 분자는 이 등식의 유입과 같은 변수로 쓰지 않는다. 제품을 만들 때 먹을 외부 소비로 센 뒤 납품·사용·파손·폐기 때 다시 세지 않는다. 각 제품에 담긴 환산량은 마지막 외부 소비 때 한 번 센다. 계획 예약은 소비가 아니며 미반출 현장 재료는 공방 제작에 먼저 사용할 수 없다.

예: 수지1개를 확보하면 전체 유입+4먹회분·현장 보유+4·안전 반출0이다. 급조로1회분을 사용하면 외부 소비1·현장 보유3이다. 나머지3을 반출하면 전체 유입 추가0·공방 보유3·현장 보유0·안전 반출+3이다. **처음 확보4와 반출3을 합쳐 공급7로 기록하지 않는다.** 취약품을 반출 전 잃으면 전체 유입·파손은 기록하고 안전 반출은0이다. 비축이나 현장 확보품을 쓰는 구간의 안전 반출 비율이1보다 작으면 전체 장부로 원인을 확인한 뒤 다음 구간 구매·채집량을 조정한다.

정확한 고유 32건의 주별 수요는 W07 §6.1, 선택 활동을 분리한 **1인 예시**는 W07 §6.2를 따른다. 예시의 주 총소비는 37/57/62/66/53회분이며 정수 공급 범위는 37~42/57~65/62~71/66~75/53~60이다. 주 합계가 맞아도 3일 단위와 종류별 비율은 따로 확인한다.

협동 고유 소비는 문장별 올림으로 이미 재계산되어 단순 1.5/2/2.5배와 다르다. 중반 일반/몬스터 **회수 목표** 1인 2/2개·2인 3/3개·3인 4/4개·4인 5/5개는 접근·시간 시험값이며 실제 공급 보장이 아니다. 실제 생물 수와 경로가 그 양을 제공하지 않으면 문서상 배수를 곱해 채웠다고 하지 않는다.

### 5.2 수식·배율·사거리

| 수식 | [사실] 기준 | [추정] 검토 의견·경제 영향 |

| 잠깐 | 준비 0.2초, 0.5T, 먹 1회분 | 빠른 수습·짧은 납품에 유리. 현장 조립·이동 시간은 별도 |
| 오래 | 준비 2초, 3T, 먹 2회분 | 잠깐 대비 먹 2배·지속 6배, 즉 지속당 먹 효율 3배. 발동 전 대상·상황 변화가 대가로 작동하는지 확인 |

[사실] 넓게의 바닥·벽 반경은 0.75→1.5m, 주변은 2→4m다. 물건·나·너는 주변 2m의 해당 대상들로 넓어진다. 반경 두 배를 효과·피해 네 배라고 환산하지 않는다. **수식은 한 장에 하나이므로 오래+세게를 합쳐 24초 강한 접착 상품을 만들 수 없다.** 주변 대상의 추가 먹 1회분은 모든 수식에 적용한다.

### 5.3 팀장에게 제안할 조건부 변경

| 관찰 결과 | 팀장에게 제안 | 현재 문서의 처리 |
|---|---|---|
