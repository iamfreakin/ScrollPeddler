## 사용자 결정 (2026-09-22)
- **순서:** GPT에 그림을 맡기기 전에 레퍼런스부터 찾는다.
- **그림체:** **Lil Gator Game 같은 느낌 + PEAK 정도의 어두움과 밝음.** 요청서의 시안 B(스타일라이즈드 3D) 쪽. 시안 3장 비교 단계는 필요 없어짐.
- **일관성:** 모든 그림이 같은 스타일로 나오도록 명확한 스타일 프롬프트를 만든다.

## 내일 할 일
1. 실사 사진 후보 고르기: `commons_refs.json`(Wikimedia Commons 검색 결과, 아직 안 봄). 한지·먹 공방, 옛 제지소 건조실·초지실, 버려진 공장, 물레방아, 목판·봉랍·전각 도장, 도롱뇽·달팽이·폭탄먼지벌레(화덕딱정벌레 참고), 빛이끼.
2. 레퍼런스 보드 한 페이지로 정리: 그림체 / 밝기·조명 / 공방 / 던전 / 인물 / 몬스터 / 소품. 각 그림마다 "여기서 가져올 것" 한 줄.
3. **스타일 고정 프롬프트:** 모든 그림 요청 앞에 똑같이 붙이는 스타일 블록. 형태, 선, 칠하는 방식, 색, 조명(공방은 밝게, 던전은 PEAK처럼 어둠 속 강한 광원), 카메라, 넣지 말 것을 적는다. 동사 룬 7색은 고정. 추가로 GPT 스레드에서 첫 기준 그림을 승인한 뒤 매번 "이 그림과 같은 스타일"로 그 그림을 첨부한다.
4. 요청서 `claude-lead\09-to-gpt-컨셉아트.md` 고치기: 메시지 1을 "시안 3장"에서 "확정 스타일 기준 그림 1장"으로 바꾸고, 메시지 2~16 앞에 스타일 블록을 붙인다.
5. GPT 스레드로 보낼 방법 정하기: Claude in Chrome 연결 후 Claude가 보냄, 또는 사용자가 붙여 넣음.

**주의:** 게임 스크린샷은 우리끼리 보는 참고용입니다. GPT 프롬프트에는 게임 이름이나 작가 이름을 쓰지 않고, 형태·색·조명을 말로 풀어서 적습니다. GPT에 첨부하는 참고 이미지는 우리가 승인한 GPT 그림과, 사용 허가가 있는 실사 사진만 씁니다.
